어떤 AI 도구로 시작할까

AI와 내 과목 평가 페이지를 만드는 길은 두 갈래입니다. A. 웹 채팅은 설치 없이 브라우저로, B. 코딩 도구는 내 PC의 폴더를 AI가 직접 고치게 합니다.

두 갈래 견주기

A. 웹 채팅B. 코딩 도구
도구Gemini(Canvas) 또는 claude.aiClaude Code(Claude 유료 구독) 또는 Antigravity CLI(구글 계정. Gemini 쪽 도구)
이런 분께설치 없이 브라우저로만 가볍게 해 보고 싶은 분내 PC의 폴더를 AI가 직접 고치게 해 보고 싶은 분. 실제 수업에 올리려면 이쪽이 편합니다
준비계정 세 가지 + 대화창 로그인 (15분)계정 세 가지 + 터미널, VS Code, 코딩 도구 설치와 로그인 (25분)
실습에서 하는 일영어 수행평가 페이지를 대화창에서 작게 만들어 보고, 내 과목 것을 만들어 봄영어 수행평가 페이지 본보기 폴더를 열어 고쳐 보고, 내 과목 것으로 바꿔 봄

무엇을 할 수 있는지는 실습 페이지에 견주어 두었습니다. 두 갈래 모두 계정 세 가지가 먼저입니다.
