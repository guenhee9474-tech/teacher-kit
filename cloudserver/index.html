장단점무료 플랜만들기쓰기6개월 뒤문제 해결 핸드오프

클라우드 서버 만들기

AWS 무료 플랜으로 서울에 작은 서버(EC2)를 빌려 24시간 켜 두고, 학교 PC·집 PC·휴대폰 가운데 내가 로그인한 기기에서만 들어가 Claude Code에게 일을 맡깁니다. 최대 6개월 동안 돈이 들지 않고, 그 뒤에 계속 쓸지 정합니다.

AI에게 줄 핸드오프 파일 받기 만드는 순서

처음 설정 1시간 · 무료 플랜 최대 6개월 $0 · 계속 쓰면 월 약 $20, 더 싼 곳으로 옮기면 월 $12 (부가세 별도)

먼저 읽어 주세요

  • 학생 개인정보(성적, 상담, 출결, 연락처)는 서버에 두지 않습니다. AWS 약관도 무료 플랜 계정을 민감한 자료 처리에 쓰지 말라고 합니다. 학교·교육청 지침이 먼저입니다.
  • 가입할 때 카드를 등록하지만, 무료 플랜 동안에는 요금이 청구되지 않습니다. 유료로 바꾸는 순간부터 청구됩니다.
  • 무료 플랜은 가입 6개월 뒤 또는 크레딧을 다 쓰면 끝나고, 그때 계정이 닫혀 서버가 멈춥니다. 이 서버는 크레딧을 한 달에 약 $20씩 쓰므로, 4단계의 크레딧 활동 두 가지를 꼭 해야 6개월을 채웁니다.
  • 서버의 문(포트)은 AWS 콘솔의 브라우저 연결 하나만 남기고 모두 닫습니다. 평소에 들어가는 길은 Tailscale(내 계정으로 로그인한 기기끼리만 이어 주는 통로)입니다.

장점과 단점

여러 기기에서 늘 같은 작업실에 들어가야 할 때, 6개월 동안 돈 없이 써 볼 수 있는 길입니다. 계속 쓰려면 그 뒤 월 $12~20이 듭니다. 돈을 전혀 쓰지 않으려면 집 PC를 서버로를 봅니다.

장점단점
비용무료 플랜 동안 $0. 6개월 서버 값(약 $122)이 크레딧($100 + 활동 $40) 안에 들어갑니다.크레딧 활동을 빠뜨리면 5개월쯤에 크레딧이 떨어져 멈춥니다. 6개월 뒤 계속 쓰면 월 $12~20이 나갑니다.
상시 가동정전, 업데이트 재시작, 집 인터넷과 상관없이 늘 켜져 있습니다.무료 플랜이 끝날 때 유료로 바꾸지 않으면 멈춥니다.
성능Claude Code는 대부분 답을 기다리는 일이라 작은 서버로 돌아갑니다.메모리 2GB로, Claude Code 공식 권장(4GB 이상)보다 작습니다. 한 번에 하나씩 맡기는 것이 기본이고, 큰 빌드나 데이터 분석은 느립니다.
보안바깥 문을 닫아도 Tailscale로 들어갑니다. 집 네트워크와 분리됩니다.AWS 계정을 빼앗기면 위험하므로 2단계 인증(MFA)이 필수입니다.
접속어느 기기든 Tailscale만 깔면 같은 작업실로 이어집니다.화면(GUI)이 없는 글자 창 서버라 터미널에 익숙해져야 합니다.
배움클라우드, 방화벽, 원격 접속을 직접 다루며 이해합니다.처음 가입과 설정에 1시간쯤 듭니다. 콘솔 화면이 복잡합니다.

무료 플랜이 어떻게 돌아가나

2025년 7월 15일 이후 새로 만든 AWS 계정이 고를 수 있는 플랜입니다. 2026년 10월에 AWS 공식 문서로 확인한 내용입니다.

받는 것가입 크레딧 $100. 정해진 활동(예산 만들기, AI 놀이터 써 보기 등)을 하나 할 때마다 크레딧이 더 쌓여 최대 $100까지 늘어납니다.
쓸 수 있는 것일부 서비스만 됩니다. 서버는 EC2가 되고, 그중에서도 “프리 티어 사용 가능” 표시가 붙은 크기(t3.micro, t3.small, t4g.micro, t4g.small 등)만 고를 수 있습니다. 더 쉬운 서버 서비스인 Lightsail은 무료 플랜에서 막혀 있습니다.
기간가입 6개월 뒤 또는 크레딧을 다 쓴 때 가운데 먼저 오는 날까지.
요금무료 플랜 동안에는 청구되지 않습니다. 서버를 쓰는 만큼 크레딧이 줄어듭니다.
남은 크레딧 확인AWS 콘솔 첫 화면의 비용 및 사용량 위젯에 크레딧 잔액과 남은 날이 나옵니다. 끝날 무렵에는 AWS가 이메일로도 알립니다.
끝나면계정이 닫히고 서버가 멈춥니다. AWS는 90일 동안 자료를 보관하고, 그 안에 유료로 바꾸면 그대로 돌아옵니다. 90일이 지나면 계정과 자료가 영구 삭제됩니다.
유료 전환같은 계정 그대로 언제든 바꿀 수 있고, 남은 크레딧은 이어서 쓰입니다.

크레딧 계산 (서울, 24시간 켜 둘 때)

서버 t4g.small시간당 $0.0208 → 월 약 $15.2 (2 vCPU, 메모리 2GB)
디스크 16GB월 약 $1.5
공인 IPv4 주소시간당 $0.005 → 월 약 $3.7 (서버가 인터넷에 나가는 데 씀)
합계월 약 $20, 6개월 약 $122
크레딧가입 $100 + 4단계 활동 두 가지 $40 = $140 → 6개월 뒤 약 $18이 남습니다. 활동을 빠뜨리면 $100이 4.9개월쯤에 떨어집니다.

2026년 10월 서울 리전 정가 기준입니다. 한 달에 $20 안팎씩 줄면 정상이고, 그보다 빨리 줄면 문제 해결을 봅니다.

날짜별로 할 일

가입한 날아래 1~10단계. 휴대폰 달력에 매달 확인 알림과 4개월 뒤 알림을 겁니다(3단계).
매달크레딧 잔액을 봅니다. 위 계산보다 많이 줄었으면 원인을 찾습니다.
4개월 뒤계속 쓸지 정합니다: 유료로 바꾸기, 더 싼 곳으로 옮기기, 그만두기, 집 PC로 옮기기(6개월 뒤).
6개월 뒤바꾸지 않았다면 서버가 멈춥니다. 90일 안에는 복구할 수 있습니다.

왜 EC2 t4g.small인가

교사 한 명이 무료 플랜으로 6개월을 채울 수 있고, 서울에 있는 것을 골랐습니다. 2026년 10월 각 회사 공식 페이지 기준입니다.

선택지요금판단
EC2 t4g.small 서울 (추천)무료 플랜에서 월 약 $20어치 크레딧무료 플랜에서 고를 수 있는 2GB 서버 가운데 가장 쌉니다. Arm 칩이지만 Ubuntu, Claude Code, Tailscale 모두 지원합니다.
EC2 t3.small월 약 $24어치사양은 같고 값이 더 비싸, 6개월을 채우려면 크레딧 활동을 더 해야 합니다.
EC2 t4g.micro월 약 $13어치크레딧 걱정은 없지만 메모리가 1GB라 Claude Code에는 빠듯합니다.
EC2 c7i-flex.large월 약 $75어치메모리 4GB로 권장 사양을 채우지만, 크레딧이 두 달 만에 떨어집니다.
AWS Lightsail월 $7(1GB)·$12(2GB) 월정액더 쉽고 싸지만 무료 플랜에서는 막혀 있습니다. 유료로 바꾼 뒤 옮겨 갈 곳으로 좋습니다(6개월 뒤).
Oracle Cloud 무료계속 무료: Arm 2코어, 메모리 12GB사양은 가장 좋지만, 춘천 리전에는 이 서버가 없고 서울은 자리가 없어 만들기 실패가 잦다는 보고가 많습니다. 7일 동안 거의 놀면 회수될 수 있습니다(Claude Code 상주는 대부분 노는 시간). 가입과 화면도 어렵습니다.
Google Cloud 무료계속 무료: e2-micro 1대미국 리전만 되고, 밖으로 나가는 전송이 월 1GB뿐이라 맞지 않습니다.

만드는 순서

열 단계입니다. 각 단계 끝의 확인이 되면 다음으로 갑니다. 콘솔 화면의 글자와 순서는 AWS가 바꿀 수 있으니, 다르면 비슷한 이름을 찾거나 핸드오프 파일을 AI에게 주고 화면에 보이는 글자를 알려 함께 찾습니다.

1. AWS 가입 (무료 플랜)

  1. aws.amazon.com 오른쪽 위 계정 생성(Create an AWS Account)을 누릅니다.
  2. 루트 사용자 이메일(개인 메일)과 계정 이름(예: 내이름-class)을 넣고, 메일로 온 확인 코드를 넣습니다.
  3. 루트 비밀번호를 정합니다. 다른 곳에서 쓰지 않는 긴 비밀번호로 하고, 비밀번호 관리자나 수첩에 적어 둡니다.
  4. 플랜 선택에서 무료(Free)를 고릅니다.
  5. 연락처 정보에서 개인을 고르고 주소와 전화번호를 영어로 넣습니다.
  6. 결제 정보에 개인 카드를 넣습니다. 본인 확인용으로 소액 승인이 잡혔다가 취소될 수 있습니다. 무료 플랜 동안에는 청구되지 않습니다.
  7. 전화 인증: 문자나 음성으로 온 숫자를 넣습니다.
  8. 지원 플랜을 묻는다면 기본 지원 - 무료(Basic)를 고르고 가입을 마칩니다.
  9. 루트 사용자로 콘솔에 로그인합니다. 오른쪽 위 톱니바퀴(설정)에서 언어를 한국어로 바꿔도 됩니다.

확인: 콘솔 첫 화면이 열리고, 비용 및 사용량 위젯(또는 결제 화면)에 크레딧 $100과 남은 날이 보입니다. 화면 순서는 바뀔 수 있습니다.

2. 2단계 인증(MFA) 걸기

  1. 휴대폰에 인증 앱(Google Authenticator, Microsoft Authenticator 등)을 깝니다.
  2. 콘솔 오른쪽 위 계정 이름 → 보안 자격 증명(Security credentials)
  3. MFA 할당 → 디바이스 이름(예: my-phone) → 인증 관리자 앱 → 다음
  4. 화면의 QR 코드를 앱으로 찍고, 앱에 나오는 6자리 숫자를 연달아 두 번(MFA 코드 1, 2) 넣습니다.
  5. 같은 화면의 액세스 키는 만들지 않습니다. 이 방법에는 필요 없고, 새어 나가면 위험합니다.

확인: 로그아웃했다가 다시 로그인하면 비밀번호 다음에 6자리 숫자를 묻습니다.

3. 크레딧 확인과 달력 알림

  1. 콘솔 첫 화면의 비용 및 사용량 위젯에서 크레딧 잔액과 무료 플랜 남은 날을 봅니다. 위젯이 안 보이면 위 검색창에 Billing을 넣어 결제 화면에서 봅니다.
  2. 휴대폰 달력에 두 가지 알림을 겁니다.
    매달 가입한 날“AWS 크레딧 확인”: 한 달에 $20 안팎씩 줄고 있는지
    가입일 + 4개월“AWS 계속 쓸지 정하기”: 크레딧 활동이 빠져 일찍 떨어지는 경우에도 정할 시간이 남습니다.

4. 크레딧 활동 두 가지 (+$40)

이 서버로 6개월을 채우려면 꼭 해야 합니다. 콘솔 첫 화면의 Explore AWS 위젯에서 필터를 Earn AWS credits로 바꾸면 활동 목록이 나옵니다. 둘 다 몇 분이면 끝납니다.

  1. 예산 만들기(AWS Budgets): 콘솔 위 검색창에 Budgets → 예산 생성 → 템플릿 월별 비용 예산(Monthly cost budget) → 이름(예: monthly-25), 금액 $25, 알림 받을 이메일 → 예산 생성. 무료 플랜 동안에는 청구가 없지만, 나중에 유료로 바꾼 뒤를 위한 안전장치가 됩니다.
  2. AI 놀이터 써 보기(Amazon Bedrock playground): 검색창에 Bedrock → 왼쪽 메뉴 플레이그라운드(Playground)의 채팅 → 모델 고르기에서 Amazon의 Nova 모델(예: Nova Micro) → “안녕”이라고 넣고 실행. 답이 오면 끝입니다. 쓴 만큼(1센트 안팎) 크레딧에서 빠집니다. 다른 회사 모델은 사용 신청서를 먼저 내라고 할 수 있어 Amazon 모델을 씁니다.

확인: Explore AWS 위젯에서 두 활동에 완료 표시가 나오고, 며칠 안에 크레딧이 $140이 됩니다. EC2 활동은 이 서버로 하지 않습니다. 그 안내는 끝에 서버를 지우는 데까지 갑니다. 다른 활동(Lambda, RDS)은 하지 않아도 됩니다.

5. 서버(인스턴스) 만들기

  1. 콘솔 위 검색창에 EC2. 오른쪽 위 리전이 아시아 태평양(서울) ap-northeast-2인지 보고, 아니면 바꿉니다.
  2. 인스턴스 시작(Launch instance)을 누릅니다.
  3. 이름: class-server
  4. 애플리케이션 및 OS 이미지: 빠른 시작 → Ubuntu → Ubuntu Server 24.04 LTS(“프리 티어 사용 가능” 표시) → 아키텍처 64비트(Arm)
  5. 인스턴스 유형: t4g.small(“프리 티어 사용 가능” 표시). 목록에서 안 보이면 4번의 아키텍처가 Arm인지 봅니다.
  6. 키 페어: 새 키 페어 생성 → 이름 class-key, 유형 RSA, 형식 .pem → 생성. 받은 파일은 비상용입니다. 내 PC의 문서 폴더에 두고, 저장소에 올리거나 남에게 보내지 않습니다.
  7. 네트워크 설정 → 편집:
    퍼블릭 IP 자동 할당활성화(기본값). 서버가 인터넷으로 나가는 데 필요합니다.
    방화벽(보안 그룹)보안 그룹 생성, 이름 class-server-sg
    인바운드 규칙 (SSH)소스 유형 사용자 지정 → 소스 칸에 instance-connect를 넣고 com.amazonaws.ap-northeast-2.ec2-instance-connect를 고릅니다. AWS 콘솔의 브라우저 연결만 들어오게 하는 설정입니다. 목록이 안 나오면 일단 내 IP로 두고 9단계에서 고칩니다. 위치 무관(0.0.0.0/0)으로 두지 않습니다.
    HTTP, HTTPS 허용켜지 않습니다.
  8. 스토리지 구성: 16 GiB, gp3
  9. 고급 세부 정보를 펼칩니다.
    종료 방지활성화. 실수로 서버를 지우지 않게 막습니다.
    크레딧 사양표준(Standard). 무제한(Unlimited)으로 두면 계산이 오래 몰릴 때 크레딧이 더 빠집니다.
    나머지는 기본값 그대로 둡니다.
  10. 오른쪽 요약에서 인스턴스 수 1을 보고 인스턴스 시작.

확인: 인스턴스 목록에서 class-server의 상태가 실행 중, 상태 검사가 모두 통과(예: 3/3개 검사 통과)가 됩니다(2~3분). 무료 플랜이라 “프리 티어 사용 가능” 표시가 없는 크기를 고르면 막힙니다. 탄력적 IP(Elastic IP)는 만들지 않습니다. 서버에 붙이지 않고 두면 그것만으로 크레딧이 빠집니다.

6. 처음 들어가서 기본 설정

인스턴스 목록에서 class-server를 고르고 위의 연결 → EC2 인스턴스 연결(EC2 Instance Connect) 탭 → 사용자 이름 ubuntu → 연결. 브라우저 새 탭에 글자 창이 열립니다. 아래 상자를 하나씩 붙여 넣고 Enter를 누릅니다. 붙여넣기가 안 되면 Ctrl+Shift+V나 마우스 오른쪽 단추를 씁니다.

EC2 Instance Connect
ubuntu@ip-172-31-0-10:~$ ▌

ubuntu@…:~$ 가 명령을 넣는 자리입니다. 사용자 이름은 ubuntu입니다.

# ① 프로그램을 최신으로 (3~5분, 보라색 화면이 나오면 Enter)
sudo apt update && sudo apt upgrade -y
# ② 시계를 한국 시간으로, 서버 이름을 class-server로
sudo timedatectl set-timezone Asia/Seoul
sudo hostnamectl set-hostname class-server
# ③ 메모리가 모자랄 때 쓸 예비 공간(스왑) 2GB
sudo fallocate -l 2G /swapfile && sudo chmod 600 /swapfile
sudo mkswap /swapfile && sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
# ④ 창을 닫아도 일이 계속되게 하는 tmux
sudo apt install -y tmux

확인: date에 KST가, free -h의 Swap 줄에 2.0Gi가, hostname에 class-server가 보입니다. #으로 시작하는 줄은 설명이라 같이 붙여도 됩니다. ①이 끝나고 “재시작이 필요하다”(restart required)는 글이 보이면 sudo reboot 뒤 1분 기다려 다시 연결합니다.

7. Claude Code 설치와 로그인

curl -fsSL https://claude.ai/install.sh | bash
  1. 내려받는 동안 아무것도 표시되지 않아도 정상입니다. 1~3분 기다립니다.
  2. 끝나면 source ~/.bashrc 를 넣고(또는 창을 닫고 다시 연결), claude --version 으로 숫자가 나오는지 봅니다. 안 나오면 설치 끝에 나온 안내 줄(PATH 추가 명령)을 그대로 넣습니다.
  3. claude 를 넣고 글자 색을 고른 뒤, 로그인 방법 1. Claude account with subscription을 고릅니다.
  4. 서버에는 브라우저가 없으므로 화면에 긴 주소가 나옵니다. 그 주소를 내 PC 브라우저에 붙여 넣고, 구독 계정으로 로그인해 승인합니다.
  5. 브라우저에 나온 코드를 복사해 서버 창의 Paste code here 뒤에 붙여 넣고 Enter. Login successful이 나오면 됩니다.

8. Tailscale 연결

curl -fsSL https://tailscale.com/install.sh | sh
sudo tailscale up --ssh
  1. 두 번째 줄을 넣으면 To authenticate, visit: 뒤에 주소가 나옵니다. 내 PC 브라우저에서 열어 로그인합니다(구글 계정 등). Tailscale이 처음이면 이때 계정이 만들어집니다. 개인용은 무료입니다.
  2. 서버 창에 Success.가 나오면 서버 쪽은 끝입니다. 서버가 다시 켜져도 Tailscale은 저절로 이어집니다.
  3. 내가 쓸 기기마다 Tailscale 앱을 깔고 같은 계정으로 로그인합니다.
    Windows·Mac앱 설치 → 작업 표시줄(메뉴 막대)의 Tailscale 아이콘 → 로그인
    아이폰·안드로이드앱 설치 → 로그인 → VPN 구성 허용. SSH 앱은 Termius 등을 따로 깝니다.
  4. 관리 화면에서 서버 이름 class-server가 보이는지 확인합니다.
  5. PC의 PowerShell(또는 터미널)에서 접속합니다. 처음이면 브라우저에서 한 번 더 확인하라는 주소가 뜰 수 있습니다. 지문(fingerprint)을 믿느냐고 물으면 yes. 
    ssh ubuntu@class-server
  6. 휴대폰 Termius: 새 호스트 → 주소에 class-server(안 되면 관리 화면의 100.으로 시작하는 주소), 사용자 이름 ubuntu → 저장 → 연결.

확인: 내 PC에서 ssh ubuntu@class-server로 들어가 hostname이 보입니다. 이 확인이 끝나야 9단계로 갑니다.

9. 바깥 문 점검

Tailscale은 서버가 밖으로 나가는 연결만 쓰므로, 들어오는 문은 없어도 됩니다. 남겨 둘 문은 AWS 콘솔의 브라우저 연결(6단계) 하나뿐입니다. 이 문은 AWS 콘솔에 로그인(비밀번호 + MFA)해야만 쓸 수 있습니다.

  1. 인스턴스 목록에서 class-server → 아래 보안 탭 → 보안 그룹 이름(class-server-sg)을 누릅니다.
  2. 인바운드 규칙 탭에 규칙이 SSH 하나이고, 소스가 pl-로 시작하는 것(EC2 Instance Connect 목록)인지 봅니다.
  3. 소스가 0.0.0.0/0, ::/0 또는 내 IP라면 인바운드 규칙 편집 → 그 줄의 소스를 지우고 instance-connect를 넣어 com.amazonaws.ap-northeast-2.ec2-instance-connect로 바꿉니다 → 규칙 저장. 다른 규칙(HTTP 등)이 있으면 삭제합니다.
  4. 더 엄격하게 하려면 SSH 규칙까지 지워 들어오는 문을 0개로 둡니다. 그러면 콘솔 브라우저 연결은 안 되고, 필요할 때 위 규칙을 잠깐 다시 추가합니다.

확인: 내 PC에서 ssh ubuntu@class-server(Tailscale)가 여전히 되고, 인바운드 규칙에 0.0.0.0/0이나 ::/0인 줄이 없습니다. 아웃바운드 규칙은 그대로 둡니다. 서버가 밖으로 나가는 길이라 지우면 Tailscale도 끊깁니다.

10. 백업 (선택)

중요한 파일은 GitHub 비공개 저장소에 올려 두는 것이 가장 쉽습니다(쓰기). 서버 전체를 저장하려면 인스턴스 → 스토리지 탭 → 볼륨 ID → 작업 → 스냅샷 생성. 스냅샷은 GB당 월 $0.05가 크레딧에서 빠지므로(16GB면 많아야 월 $0.8), 큰 작업 전에 하나 만들고 오래된 것은 지웁니다.

파일 주고받기

서버의 작업 폴더를 GitHub 저장소로 만들어 두고, 서버와 내 PC에서 각각 가져오고 올리는 것이 가장 쉽습니다. Claude Code에게 “이 폴더를 내 GitHub 비공개 저장소로 올려 줘”라고 맡기면 됩니다. 한두 파일이면 내 PC에서 scp ubuntu@class-server:~/폴더/파일 . 처럼 바로 받아도 됩니다.

기기 관리

  • 새 기기는 Tailscale 앱을 깔고 같은 계정으로 로그인하면 끝입니다.
  • 기기를 잃어버리거나 학교 PC를 바꾸면 관리 화면에서 그 기기를 제거합니다. 바로 못 들어오게 됩니다.
  • 공용 PC에는 Tailscale을 깔지 않습니다. 같은 계정으로 로그인한 기기는 모두 서버에 들어올 수 있기 때문입니다.

쉬게 하기

방학처럼 오래 안 쓸 때는 인스턴스 → 인스턴스 상태 → 인스턴스 중지. 서버 값과 공인 IPv4 값이 멈추고 디스크 값(월 약 $1.5)만 나갑니다. 다시 쓸 때 인스턴스 시작을 누르면 Tailscale이 저절로 이어집니다. 공인 IP 주소는 바뀌지만 Tailscale로 들어가므로 상관없습니다.

정해진 시각에 돌리기, 점검

cron과 한 달 점검은 집 PC를 서버로의 7·8단계와 같습니다. 우분투의 보안 패치는 저절로 깔리므로, 한 달에 한 번 sudo apt update && sudo apt upgrade -y를 넣고, 맡긴 일이 없을 때 필요하면 sudo reboot합니다. 같은 날 크레딧 잔액도 봅니다.

6개월 뒤: 네 가지 길

3단계에서 걸어 둔 달력 알림(4개월 뒤)이 오면 아래 가운데 하나를 고릅니다.

그대로 계속 쓰기
  1. 콘솔에 로그인 → 플랜 업그레이드(콘솔 첫 화면이나 결제 화면에도 버튼이 있습니다)
  2. 얻는 기능을 확인하고 계정 업그레이드를 누릅니다. 계정과 서버는 그대로이고, 남은 크레딧은 이어서 쓰입니다.
  3. 크레딧이 다 떨어진 달부터 월 약 $20(부가세 별도)이 카드로 청구됩니다. 4단계의 예산 알림($25)이 이제부터 일합니다.
더 싸게 옮기기유료로 바꾸면 Lightsail을 쓸 수 있습니다. 2GB 서버가 월 $12 월정액(공인 IPv4 포함)이라 EC2보다 쌉니다. 파일을 GitHub에 올린 뒤, 핸드오프 파일을 AI에게 주고 “Lightsail 서울 $12 번들로 같은 구성을 새로 만들고 싶다”고 하면 Lightsail 화면에 맞춰 안내합니다. 새 서버가 되면 아래 “그만두기”로 EC2를 지웁니다.
그만두기
  1. 남길 파일을 GitHub이나 내 PC로 옮깁니다.
  2. 인스턴스 → 작업 → 인스턴스 설정 → 종료 방지 변경에서 끕니다.
  3. 인스턴스 상태 → 인스턴스 종료(삭제). 디스크도 함께 지워집니다. 만든 스냅샷이 있으면 스냅샷 메뉴에서 지웁니다.
  4. 무료 플랜은 유료로 바꾸지 않는 한 청구되지 않으므로, 이대로 두면 6개월째에 계정이 닫히고 90일 뒤 지워집니다.
집 PC로 옮기기파일을 GitHub으로 옮긴 뒤 집 PC를 서버로의 2부를 따라 하고, 위 “그만두기”를 합니다. Tailscale 계정은 그대로 씁니다.
놓쳤을 때서버가 멈췄다면 90일 안에 콘솔에 로그인해 유료로 바꾸면 계정과 서버가 돌아옵니다.

문제 해결

ssh가 안 됩니다
EC2 콘솔에서 인스턴스가 실행 중인지, 내 기기의 Tailscale 앱이 켜져 있는지 봅니다. 그다음 6단계처럼 콘솔의 EC2 인스턴스 연결로 들어가 tailscale status를 봅니다. 로그아웃되어 있으면 sudo tailscale up --ssh를 다시 넣습니다.
콘솔의 “EC2 인스턴스 연결”이 실패합니다
보안 그룹의 SSH 규칙 소스가 com.amazonaws.ap-northeast-2.ec2-instance-connect인지 봅니다(9단계). 내 IP로 되어 있으면 콘솔 연결은 막힙니다. 9단계에서 SSH 규칙을 지웠다면 그 규칙을 다시 추가합니다. 학교 망이 연결을 막을 수도 있으니 휴대폰 핫스팟으로도 해 봅니다.
인스턴스 유형 t4g.small이 안 보이거나 시작이 막힙니다
5단계 4번의 아키텍처가 64비트(Arm)인지 봅니다. t4g는 Arm용이라 x86 이미지와 같이 고를 수 없습니다. 그래도 막히면 아키텍처를 64비트(x86)로 바꾸고 t3.small을 고릅니다. 월 약 $24어치라 6개월을 채우려면 크레딧 활동을 하나 더(Lambda) 합니다.
서버가 느리거나 Claude Code가 갑자기 꺼집니다
메모리가 모자란 것일 수 있습니다. free -h를 봅니다. 동시에 돌리는 Claude Code를 하나로 줄이고, 쓰지 않는 tmux 방은 닫습니다(tmux kill-session -t 이름). 무료 플랜에서 더 큰 크기(c7i-flex.large, 4GB)로 바꾸면 크레딧이 두 달 만에 떨어지므로 권하지 않습니다.
크레딧이 예상보다 빨리 줄어듭니다
결제 화면의 청구서(Bills)에서 어느 서비스가 크레딧을 썼는지 봅니다. 흔한 원인: 붙이지 않은 탄력적 IP, 지우지 않은 스냅샷, 다른 리전의 서버(콘솔 위 리전을 바꿔 가며 EC2 인스턴스 확인), 크레딧 사양이 무제한인 경우. 모르는 서버가 있으면 계정을 빼앗긴 것일 수 있으니 바로 비밀번호를 바꾸고 AWS 지원(Support)에 알립니다.
크레딧 활동을 했는데 크레딧이 늘지 않았습니다
며칠 걸릴 수 있습니다. 일주일이 지나도 그대로면 Explore AWS 위젯에서 그 활동이 완료로 나오는지 봅니다. 늘지 않은 채라면 크레딧이 4.9개월쯤 떨어지므로, 4개월 알림 때 유료로 바꾸거나 옮길 곳을 정합니다.
재시작한 뒤 맡긴 일이 사라졌습니다
재시작하면 tmux 방도 사라집니다. 일을 맡기기 전에 결과를 파일로 남기게 하고, 업데이트 뒤 재시작은 맡긴 일이 없을 때 합니다.
Oracle 무료로 해 보고 싶습니다
핸드오프 파일을 AI에게 주고 “Oracle Cloud Always Free로 같은 구성을 만들고 싶다”고 하면, 같은 규칙(문 닫기, Tailscale만)으로 안내합니다. 서울에서 만들기가 실패하면 시간을 두고 다시 시도해야 하고, 놀고 있는 서버는 회수될 수 있다는 점을 알고 시작합니다.
