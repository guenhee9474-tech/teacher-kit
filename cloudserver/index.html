클라우드 서버 만들기

AWS Lightsail 서울에 작은 서버를 빌려 24시간 켜 두고, 학교 PC·집 PC·휴대폰 가운데 내가 로그인한 기기에서만 들어가 Claude Code에게 일을 맡깁니다. 집 PC를 켜 둘 필요가 없습니다.

AI에게 줄 핸드오프 파일 받기 만드는 순서

처음 설정 1시간 · 월 $7(부가세 별도, 대략 1만 원) · 새 AWS 계정은 가입 크레딧으로 처음 몇 달이 덜 듭니다

먼저 읽어 주세요

  • 학생 개인정보(성적, 상담, 출결, 연락처)는 서버에 두지 않습니다. 해외 사업자의 클라우드이며, 학교·교육청 지침이 먼저입니다.
  • 카드를 등록하는 유료 서비스입니다. 아래 2단계의 예산 알림을 반드시 걸고, 그만둘 때는 마지막 단계대로 지웁니다. 지우기 전까지 요금이 나갑니다.
  • 계정을 빼앗기면 남이 비싼 서버를 돌려 요금이 나올 수 있습니다. 2단계 인증(MFA)은 건너뛰지 않습니다.
  • 서버의 문(포트)은 모두 닫고, 들어가는 길은 Tailscale(내 계정으로 로그인한 기기끼리만 이어 주는 통로) 하나만 둡니다.

장점과 단점

여러 기기에서 늘 같은 작업실에 들어가야 하고 월 1만 원 안팎을 낼 수 있다면 집 PC보다 낫습니다. 돈을 쓰지 않으려면 집 PC를 서버로를 봅니다.

장점단점
상시 가동정전, 업데이트 재시작, 집 인터넷과 상관없이 늘 켜져 있습니다.AWS 쪽 점검이나 장애는 내가 어쩔 수 없습니다(드묾).
비용월정액이라 예측이 쉽습니다. 전송량도 넉넉히 포함됩니다.매달 돈이 나갑니다. 지우는 것을 잊으면 계속 나갑니다.
성능Claude Code는 대부분 답을 기다리는 일이라 작은 서버로 충분합니다.메모리 1GB라 무거운 프로그램(큰 빌드, 데이터 분석)은 느립니다.
보안문을 다 닫아도 Tailscale로 들어갑니다. 집 네트워크와 분리됩니다.AWS 계정이 털리면 요금 폭탄이 날 수 있어 MFA가 필수입니다.
접속어느 기기든 Tailscale만 깔면 같은 화면으로 이어집니다.화면(GUI)이 없는 글자 창 서버라 터미널에 익숙해져야 합니다.
배움클라우드, 방화벽, 원격 접속을 직접 다루며 이해합니다.처음 가입과 설정에 1시간쯤 듭니다.

왜 Lightsail인가

교사 한 명이 오래 쓰기에 쉽고, 요금이 예측되고, 서울에 있는 것을 골랐습니다. 2026년 10월에 각 회사의 공식 페이지를 보고 비교했습니다.

선택지요금판단
AWS Lightsail 서울 (추천)월 $7: 메모리 1GB, 2 vCPU, SSD 40GB, 전송 2TB, IPv4 포함화면이 단순하고 월정액입니다. 새 계정은 가입 크레딧(최대 $200, 대략 6개월)이 요금에 쓰입니다.
Oracle Cloud 무료계속 무료: Arm 2코어, 메모리 12GB사양은 가장 좋지만, 서울은 자리가 없어 만들기 실패가 잦다는 보고가 많고, 7일 동안 거의 놀면 회수될 수 있습니다(Claude Code 상주는 대부분 노는 시간). 가입과 화면도 어렵습니다. 시행착오를 견딜 수 있을 때의 대안입니다.
Google Cloud 무료계속 무료: e2-micro 1대미국 리전만 되고, 밖으로 나가는 전송이 월 1GB뿐이라 맞지 않습니다.
AWS EC2 무료 플랜크레딧 소진이나 약 6개월 뒤 끝무료 플랜은 끝나면 계정이 닫힙니다. 상주용으로 쓰려면 결국 유료이고, 같은 값이면 Lightsail이 쉽습니다.

메모리 1GB로 Claude Code 두세 개를 동시에 돌리면 빠듯할 수 있습니다. 그때는 $12(2GB) 번들로 옮깁니다(아래 문제 해결).

만드는 순서

1. AWS 가입과 2단계 인증

  1. aws.amazon.com에서 계정을 만듭니다. 개인 이메일과 카드를 씁니다.
  2. 플랜을 고르라고 하면 유료 플랜(Paid)을 고릅니다. 가입 크레딧은 유료 플랜에도 똑같이 쓰이고, 무료 플랜은 크레딧이 끝나면 계정이 닫혀 서버도 사라지기 때문입니다.
  3. 오른쪽 위 계정 이름 → 보안 자격 증명 → MFA 할당에서 휴대폰 인증 앱(Google Authenticator 등)을 연결합니다.
  4. 같은 화면의 액세스 키는 만들지 않습니다. 이 방법에는 필요 없습니다.

2. 예산 알림 걸기 (건너뛰지 않음)

  1. 콘솔 위 검색창에 Budgets → 예산 생성 → 템플릿 월별 비용 예산을 고릅니다.
  2. 금액은 $15, 알림 받을 이메일을 넣고 만듭니다. 서버 값의 두 배쯤이라, 알림이 오면 무언가 잘못된 것입니다.

확인: Budgets 목록에 예산이 하나 보입니다.

3. 서버 만들기

  1. lightsail.aws.amazon.com → 인스턴스 생성
  2. 위치: 서울(ap-northeast-2)
  3. 플랫폼 Linux/Unix → 블루프린트 OS 전용 → Ubuntu(가장 새 LTS)
  4. 네트워크 유형: 듀얼 스택(IPv4 포함). IPv6 전용은 싸지만 학교·집 망에 따라 접속이 안 될 수 있습니다.
  5. 플랜: $7(1GB). 이름은 알아보기 쉽게(예: class-server) → 인스턴스 생성

확인: 1~2분 뒤 상태가 실행 중이 됩니다.

4. 처음 들어가서 기본 설정

인스턴스의 연결(터미널 모양 아이콘)을 누르면 브라우저에 글자 창이 열립니다. 아래를 한 덩어리씩 붙여 넣습니다.

# 프로그램 최신으로
sudo apt update && sudo apt upgrade -y

# 시계를 한국 시간으로
sudo timedatectl set-timezone Asia/Seoul

# 메모리가 모자랄 때 쓸 예비 공간(스왑) 2GB
sudo fallocate -l 2G /swapfile && sudo chmod 600 /swapfile
sudo mkswap /swapfile && sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab

# 창을 닫아도 일이 계속되게 하는 tmux
sudo apt install -y tmux

확인: free -h에서 Swap이 2.0Gi로 보입니다. #으로 시작하는 줄은 설명이라 같이 붙여도 됩니다.

5. Claude Code 설치와 로그인

curl -fsSL https://claude.ai/install.sh | bash

설치가 끝나면 안내대로 창을 다시 열거나 source ~/.bashrc를 넣고, claude를 실행해 구독 계정으로 로그인합니다. 서버에는 브라우저가 없으므로, 화면에 나온 주소를 내 PC 브라우저에서 열어 로그인하고 받은 코드를 다시 서버 창에 붙여 넣습니다.

6. Tailscale 연결

curl -fsSL https://tailscale.com/install.sh | sh
sudo tailscale up --ssh
  1. 나온 주소를 내 PC 브라우저에서 열어 로그인합니다(구글 계정 등).
  2. 학교 PC, 집 PC, 휴대폰에 Tailscale 앱을 깔고 같은 계정으로 로그인합니다.
  3. 각 기기에서 접속합니다. 서버 이름은 관리 화면에 보입니다. 사용자 이름은 ubuntu입니다. 휴대폰은 Termius 같은 SSH 앱을 씁니다. 
    ssh ubuntu@서버이름
    처음에는 브라우저에서 한 번 더 확인하라는 창이 뜰 수 있습니다.

확인: 내 PC에서 ssh ubuntu@서버이름으로 들어가 hostname이 보입니다. 이 확인이 끝나야 7단계로 갑니다.

7. 바깥 문 닫기

Lightsail은 처음에 SSH(22)와 HTTP(80) 문을 모든 주소에 열어 둡니다. Tailscale로 들어가게 됐으니 닫습니다.

  1. 인스턴스 → 네트워킹 탭 → IPv4 방화벽
  2. HTTP(80) 규칙을 지웁니다.
  3. SSH(22) 규칙을 편집해 IP 주소로 제한을 켜고 Lightsail 브라우저 SSH/RDP 허용만 남깁니다. 이 선택지가 보이지 않으면 SSH 규칙도 지웁니다(브라우저 연결이 필요할 때 규칙을 잠깐 다시 추가하면 됩니다).
  4. 아래 IPv6 방화벽에서도 똑같이 합니다. 두 방화벽은 따로 움직입니다.

확인: 내 PC에서 ssh ubuntu@서버이름(Tailscale)이 여전히 됩니다. 방화벽 목록에 “모든 IP 주소”가 남은 규칙이 없습니다.

8. 백업 (선택)

인스턴스 → 스냅샷 탭 → 자동 스냅샷을 켜면 매일 서버 전체를 저장합니다. 스냅샷은 용량만큼 요금이 붙습니다(40GB 디스크면 대략 월 $2). 중요한 파일만 GitHub 비공개 저장소에 올려 두는 방법도 있습니다.

쓰기

어느 기기에서든 같은 작업실로

방 만들기tmux new -s work → 그 안에서 claude → 일을 맡깁니다.
빠져나오기Ctrl+b를 누르고 손을 뗀 뒤 d. 접속을 끊어도 일은 계속됩니다.
다른 기기에서 이어서ssh ubuntu@서버이름 → tmux attach -t work. 학교에서 맡긴 일을 집이나 휴대폰에서 그대로 봅니다.

기기 관리

  • 새 기기는 Tailscale 앱을 깔고 같은 계정으로 로그인하면 끝입니다.
  • 기기를 잃어버리거나 학교 PC를 바꾸면 관리 화면에서 그 기기를 제거합니다. 바로 못 들어오게 됩니다.
  • 공용 PC에는 Tailscale을 깔지 않습니다. 같은 계정으로 로그인한 기기는 모두 서버에 들어올 수 있기 때문입니다.

정해진 시각에 돌리기, 점검

cron과 한 달 점검은 집 PC를 서버로의 7·8단계와 같습니다. 서버의 우분투 업데이트는 보안 패치만 자동으로 깔리므로, 한 달에 한 번 sudo apt update && sudo apt upgrade -y를 넣고 필요하면 sudo reboot합니다.

그만둘 때 (요금 멈추기)

  1. 남길 파일을 옮깁니다.
  2. Lightsail에서 인스턴스 삭제, 스냅샷 탭의 스냅샷도 삭제합니다. 고정 IP를 만들었다면 그것도 해제합니다.
  3. 다음 달 Budgets와 청구서에서 $0인지 확인합니다.

문제 해결

ssh가 안 됩니다
Lightsail 콘솔에서 인스턴스가 실행 중인지, 내 기기의 Tailscale 앱이 켜져 있는지 봅니다. 7단계에서 브라우저 SSH를 남겼다면 연결 버튼으로 들어가 tailscale status를 봅니다. SSH 규칙을 지웠다면 SSH 규칙을 잠깐 다시 추가해 브라우저로 들어간 뒤 고치고, 다시 지웁니다.
서버가 느리거나 Claude Code가 갑자기 꺼집니다
메모리가 모자란 것일 수 있습니다. free -h를 봅니다. 동시에 돌리는 Claude Code 수를 줄이거나, 더 큰 번들로 옮깁니다: 스냅샷 탭에서 수동 스냅샷을 만들고 → 그 스냅샷으로 새 인스턴스 생성에서 $12(2GB)를 고른 뒤 → 새 서버에서 Tailscale이 되는지 확인하고 → 예전 인스턴스를 지웁니다.
예산 알림 메일이 왔습니다
Lightsail에 모르는 인스턴스가 있는지, 지우지 않은 스냅샷이 있는지 봅니다. 모르는 것이 있으면 계정이 털린 것일 수 있으니 바로 비밀번호를 바꾸고 AWS 지원(Support)에 알립니다.
재시작한 뒤 맡긴 일이 사라졌습니다
재시작하면 tmux 방도 사라집니다. 일을 맡기기 전에 결과를 파일로 남기게 하고, 업데이트 뒤 재시작은 맡긴 일이 없을 때 합니다.
Oracle 무료로 해 보고 싶습니다
핸드오프 파일을 AI에게 주고 “Oracle Cloud Always Free로 같은 구성을 만들고 싶다”고 하면, 같은 규칙(문 닫기, Tailscale만)으로 안내합니다. 서울에서 만들기가 실패하면 시간을 두고 다시 시도해야 하고, 놀고 있는 서버는 회수될 수 있다는 점을 알고 시작합니다.

AI와 같이 하기

이 페이지의 내용, 지켜야 할 규칙, 단계마다의 확인 방법을 담은 핸드오프 파일이 있습니다. 웹 채팅에는 파일을 첨부하고, Claude Code에는 작업 폴더에 두고 이렇게 시작합니다.

이 HANDOFF.md를 읽고, 3절의 질문부터 하나씩 물어봐 줘.
그다음 1단계부터 한 단계씩 같이 하자. 명령은 실행 전에 무엇을 하는지 먼저 설명해 줘.
