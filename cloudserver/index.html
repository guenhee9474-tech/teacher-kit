장단점무료 플랜만들기쓰기6개월 뒤문제 해결 핸드오프

클라우드 서버 만들기

AWS 무료 플랜으로 Lightsail 서울에 작은 서버를 빌려 24시간 켜 두고, 학교 PC·집 PC·휴대폰 가운데 내가 로그인한 기기에서만 들어가 Claude Code에게 일을 맡깁니다. 최대 6개월 동안 돈이 들지 않고, 그 뒤에 계속 쓸지 정합니다.

AI에게 줄 핸드오프 파일 받기 만드는 순서

처음 설정 1시간 · 무료 플랜 최대 6개월 $0 · 계속 쓰면 월 $7(부가세 별도, 대략 1만 원)

먼저 읽어 주세요

  • 학생 개인정보(성적, 상담, 출결, 연락처)는 서버에 두지 않습니다. AWS 약관도 무료 플랜 계정을 민감한 자료 처리에 쓰지 말라고 합니다. 학교·교육청 지침이 먼저입니다.
  • 가입할 때 카드를 등록하지만, 무료 플랜 동안에는 요금이 청구되지 않습니다. 유료로 바꾸는 순간부터 청구됩니다.
  • 무료 플랜은 가입 6개월 뒤 또는 크레딧을 다 쓰면 끝나고, 그때 계정이 정지되어 서버가 멈춥니다. 계속 쓰려면 그 전에 유료로 바꿉니다(6개월 뒤).
  • 서버의 문(포트)은 모두 닫고, 들어가는 길은 Tailscale(내 계정으로 로그인한 기기끼리만 이어 주는 통로) 하나만 둡니다.

장점과 단점

여러 기기에서 늘 같은 작업실에 들어가야 할 때, 6개월 동안 돈 없이 써 볼 수 있는 가장 쉬운 길입니다. 계속 쓰려면 그 뒤 월 1만 원 안팎이 듭니다. 돈을 전혀 쓰지 않으려면 집 PC를 서버로를 봅니다.

장점단점
비용무료 플랜 6개월 동안 $0. 서버 값($7×6 = $42)이 가입 크레딧($100) 안에 들어갑니다.6개월 뒤 계속 쓰려면 월 $7이 나갑니다. 유료로 바꾼 뒤 지우는 것을 잊으면 계속 나갑니다.
상시 가동정전, 업데이트 재시작, 집 인터넷과 상관없이 늘 켜져 있습니다.무료 플랜이 끝날 때 유료로 바꾸지 않으면 멈춥니다.
성능Claude Code는 대부분 답을 기다리는 일이라 작은 서버로 충분합니다.메모리 1GB라 무거운 프로그램(큰 빌드, 데이터 분석)은 느립니다.
보안문을 다 닫아도 Tailscale로 들어갑니다. 집 네트워크와 분리됩니다.AWS 계정을 빼앗기면 위험하므로 2단계 인증(MFA)이 필수입니다.
접속어느 기기든 Tailscale만 깔면 같은 작업실로 이어집니다.화면(GUI)이 없는 글자 창 서버라 터미널에 익숙해져야 합니다.
배움클라우드, 방화벽, 원격 접속을 직접 다루며 이해합니다.처음 가입과 설정에 1시간쯤 듭니다.

무료 플랜이 어떻게 돌아가나

2025년 7월 15일 이후 새로 만든 AWS 계정이 고를 수 있는 플랜입니다. 2026년 10월에 AWS 공식 문서로 확인한 내용입니다.

받는 것가입 크레딧 $100, 정해진 활동(예산 만들기 등)을 하면 최대 $100 더. Lightsail도 이 크레딧으로 씁니다.
기간가입 6개월 뒤 또는 크레딧을 다 쓴 때 가운데 먼저 오는 날까지. 이 서버만 쓰면 크레딧이 남으므로 6개월이 기준입니다.
요금무료 플랜 동안에는 청구되지 않습니다.
남은 날 확인AWS 콘솔 첫 화면의 비용 및 사용량 위젯에 크레딧 잔액과 남은 날이 나옵니다. 끝날 무렵에는 AWS가 이메일로도 알립니다.
끝나면계정이 정지되고 서버가 멈춥니다. 만료 통보 뒤 90일 안에 유료로 바꾸면 그대로 복구되고, 90일이 지나면 계정과 자료가 영구 삭제됩니다.
유료 전환같은 계정 그대로 언제든 바꿀 수 있고, 남은 크레딧은 이어서 쓰입니다.

날짜별로 할 일

가입한 날아래 1~10단계. 휴대폰 달력에 5개월 뒤 알림을 겁니다(3단계).
5개월 뒤계속 쓸지 정합니다: 유료로 바꾸기, 그만두기, 집 PC로 옮기기(6개월 뒤).
6개월 뒤바꾸지 않았다면 서버가 멈춥니다. 90일 안에는 복구할 수 있습니다.

왜 Lightsail인가

교사 한 명이 쓰기에 쉽고, 요금이 예측되고, 서울에 있는 것을 골랐습니다. 2026년 10월 각 회사 공식 페이지 기준입니다.

선택지요금판단
AWS Lightsail 서울 (추천)무료 플랜 6개월 $0, 그 뒤 월 $7: 메모리 1GB, 2 vCPU, SSD 40GB, 전송 2TB, IPv4 포함화면이 단순하고 월정액입니다. AWS 문서에 무료 티어 크레딧으로 시작할 수 있다고 되어 있습니다.
AWS EC2같은 크레딧으로 씀되지만 보안 그룹, 키, 공인 IP 요금 등 챙길 것이 많습니다. 같은 일이면 Lightsail이 쉽습니다.
Oracle Cloud 무료계속 무료: Arm 2코어, 메모리 12GB사양은 가장 좋지만, 서울은 자리가 없어 만들기 실패가 잦다는 보고가 많고, 7일 동안 거의 놀면 회수될 수 있습니다(Claude Code 상주는 대부분 노는 시간). 가입과 화면도 어렵습니다.
Google Cloud 무료계속 무료: e2-micro 1대미국 리전만 되고, 밖으로 나가는 전송이 월 1GB뿐이라 맞지 않습니다.

만드는 순서

열 단계입니다. 각 단계 끝의 확인이 되면 다음으로 갑니다. 콘솔 화면의 글자와 순서는 AWS가 바꿀 수 있으니, 다르면 비슷한 이름을 찾거나 핸드오프 파일을 AI에게 주고 화면을 설명해 함께 찾습니다.

1. AWS 가입 (무료 플랜)

  1. aws.amazon.com 오른쪽 위 계정 생성(Create an AWS Account)을 누릅니다.
  2. 루트 사용자 이메일(개인 메일)과 계정 이름(예: 내이름-class)을 넣고, 메일로 온 확인 코드를 넣습니다.
  3. 루트 비밀번호를 정합니다. 다른 곳에서 쓰지 않는 긴 비밀번호로 하고, 비밀번호 관리자나 수첩에 적어 둡니다.
  4. 플랜 선택에서 무료(Free)를 고릅니다.
  5. 연락처 정보에서 개인을 고르고 주소와 전화번호를 영어로 넣습니다.
  6. 결제 정보에 개인 카드를 넣습니다. 본인 확인용으로 소액 승인이 잡혔다가 취소될 수 있습니다. 무료 플랜 동안에는 청구되지 않습니다.
  7. 전화 인증: 문자나 음성으로 온 숫자를 넣습니다.
  8. 지원 플랜을 묻는다면 기본 지원 - 무료(Basic)를 고르고 가입을 마칩니다.
  9. 루트 사용자로 콘솔에 로그인합니다. 오른쪽 위 언어를 한국어로 바꿔도 됩니다.

확인: 콘솔 첫 화면이 열리고, 비용 및 사용량 위젯(또는 결제 화면)에 크레딧 $100과 남은 날이 보입니다. 화면 순서는 바뀔 수 있습니다.

2. 2단계 인증(MFA) 걸기

  1. 휴대폰에 인증 앱(Google Authenticator, Microsoft Authenticator 등)을 깝니다.
  2. 콘솔 오른쪽 위 계정 이름 → 보안 자격 증명(Security credentials)
  3. MFA 할당 → 디바이스 이름(예: my-phone) → 인증 관리자 앱 → 다음
  4. 화면의 QR 코드를 앱으로 찍고, 앱에 나오는 6자리 숫자를 연달아 두 번(MFA 코드 1, 2) 넣습니다.
  5. 같은 화면의 액세스 키는 만들지 않습니다. 이 방법에는 필요 없고, 새어 나가면 위험합니다.

확인: 로그아웃했다가 다시 로그인하면 비밀번호 다음에 6자리 숫자를 묻습니다.

3. 남은 날 확인과 달력 알림

  1. 콘솔 첫 화면의 비용 및 사용량 위젯에서 크레딧 잔액과 무료 플랜 남은 날을 봅니다. 위젯이 안 보이면 위 검색창에 Billing을 넣어 결제 화면에서 봅니다.
  2. 휴대폰 달력에 가입일 + 5개월 날짜로 “AWS 계속 쓸지 정하기” 알림을 겁니다. 서버가 멈추기 한 달 전에 정할 시간을 줍니다.

4. 예산 알림 만들기 (크레딧 $20 추가)

무료 플랜 동안에는 청구가 없지만, 나중에 유료로 바꾼 뒤를 위한 안전장치입니다. AWS 크레딧 활동 가운데 하나라서, 만들면 크레딧이 더 쌓입니다.

  1. 콘솔 위 검색창에 Budgets → 예산 생성
  2. 템플릿 월별 비용 예산(Monthly cost budget)
  3. 예산 이름(예: monthly-15), 금액 $15, 알림 받을 이메일 → 예산 생성

확인: Budgets 목록에 예산이 하나 보입니다. 며칠 안에 크레딧이 늘었는지 3단계 위젯에서 봅니다. 콘솔 첫 화면에 다른 크레딧 활동도 안내되지만, 이 서버에는 필요 없습니다.

5. 서버(인스턴스) 만들기

  1. lightsail.aws.amazon.com을 엽니다(콘솔 검색창에 Lightsail). 처음이면 언어와 안내 화면이 나오니 넘깁니다.
  2. 인스턴스 생성(Create instance)
  3. 인스턴스 위치: 서울, 영역 A(ap-northeast-2a). 다른 리전이 골라져 있으면 AWS 리전 변경으로 바꿉니다.
  4. 플랫폼 Linux/Unix → 블루프린트 OS 전용 → Ubuntu(숫자가 가장 큰 LTS)
  5. SSH 키 쌍, 자동 스냅샷 등 선택 항목은 기본값 그대로 둡니다.
  6. 네트워크 유형: 듀얼 스택(IPv4 포함). IPv6 전용은 싸지만 학교·집 망에 따라 접속이 안 될 수 있습니다.
  7. 인스턴스 플랜: $7 USD(메모리 1GB, 2 vCPU, SSD 40GB)
  8. 이름: 알아보기 쉽게(예: class-server). 영어 소문자와 하이픈만 씁니다. → 인스턴스 생성

확인: 1~2분 뒤 인스턴스 카드의 상태가 실행 중(Running)이 됩니다. 인스턴스는 “중지”해도 크레딧(요금)이 나갑니다. 쓰지 않을 때는 지워야 멈춥니다.

6. 처음 들어가서 기본 설정

인스턴스 카드의 터미널 모양 아이콘(또는 이름을 누르고 SSH를 사용하여 연결)을 누르면 브라우저에 글자 창이 열립니다. 아래 상자를 하나씩 붙여 넣고 Enter를 누릅니다. 붙여넣기가 안 되면 Ctrl+Shift+V나 마우스 오른쪽 단추를 씁니다.

Lightsail 브라우저 SSH
ubuntu@ip-172-26-0-10:~$ ▌

ubuntu@…:~$ 가 명령을 넣는 자리입니다. 사용자 이름은 ubuntu입니다.

# ① 프로그램을 최신으로 (3~5분, 보라색 화면이 나오면 Enter)
sudo apt update && sudo apt upgrade -y
# ② 시계를 한국 시간으로
sudo timedatectl set-timezone Asia/Seoul
# ③ 메모리가 모자랄 때 쓸 예비 공간(스왑) 2GB
sudo fallocate -l 2G /swapfile && sudo chmod 600 /swapfile
sudo mkswap /swapfile && sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
# ④ 창을 닫아도 일이 계속되게 하는 tmux
sudo apt install -y tmux

확인: date에 KST가, free -h의 Swap 줄에 2.0Gi가 보입니다. #으로 시작하는 줄은 설명이라 같이 붙여도 됩니다.

7. Claude Code 설치와 로그인

curl -fsSL https://claude.ai/install.sh | bash
  1. 내려받는 동안 아무것도 표시되지 않아도 정상입니다. 1~3분 기다립니다.
  2. 끝나면 source ~/.bashrc 를 넣고(또는 창을 닫고 다시 연결), claude --version 으로 숫자가 나오는지 봅니다. 안 나오면 설치 끝에 나온 안내 줄(PATH 추가 명령)을 그대로 넣습니다.
  3. claude 를 넣고 글자 색을 고른 뒤, 로그인 방법 1. Claude account with subscription을 고릅니다.
  4. 서버에는 브라우저가 없으므로 화면에 긴 주소가 나옵니다. 그 주소를 내 PC 브라우저에 붙여 넣고, 구독 계정으로 로그인해 승인합니다.
  5. 브라우저에 나온 코드를 복사해 서버 창의 Paste code here 뒤에 붙여 넣고 Enter. Login successful이 나오면 됩니다.
  6. 폴더를 믿느냐고 물으면 Yes. “안녕”이라고 쳐서 답이 오면 /exit로 닫습니다.

로그인 화면은 Claude Code 설치와 로그인의 그림과 같습니다.

8. Tailscale 연결

curl -fsSL https://tailscale.com/install.sh | sh
sudo tailscale up --ssh
  1. 두 번째 줄을 넣으면 To authenticate, visit: 뒤에 주소가 나옵니다. 내 PC 브라우저에서 열어 로그인합니다(구글 계정 등). Tailscale이 처음이면 이때 계정이 만들어집니다. 개인용은 무료입니다.
  2. 서버 창에 Success.가 나오면 서버 쪽은 끝입니다.
  3. 내가 쓸 기기마다 Tailscale 앱을 깔고 같은 계정으로 로그인합니다.
    Windows·Mac앱 설치 → 작업 표시줄(메뉴 막대)의 Tailscale 아이콘 → 로그인
    아이폰·안드로이드앱 설치 → 로그인 → VPN 구성 허용. SSH 앱은 Termius 등을 따로 깝니다.
  4. 관리 화면에서 서버 이름(예: class-server)을 확인합니다.
  5. PC의 PowerShell(또는 터미널)에서 접속합니다. 처음이면 브라우저에서 한 번 더 확인하라는 창이 뜰 수 있습니다. 지문(fingerprint)을 믿느냐고 물으면 yes. 
    ssh ubuntu@class-server
  6. 휴대폰 Termius: 새 호스트 → 주소에 서버 이름(안 되면 관리 화면의 100.으로 시작하는 주소), 사용자 이름 ubuntu → 저장 → 연결.

확인: 내 PC에서 ssh ubuntu@서버이름으로 들어가 hostname이 보입니다. 이 확인이 끝나야 9단계로 갑니다. 9단계에서 바깥 문을 닫으면 Tailscale이 유일한 길이 되기 때문입니다.

9. 바깥 문 닫기

Lightsail은 처음에 SSH(22)와 HTTP(80) 문을 모든 주소에 열어 둡니다. Tailscale로 들어가게 됐으니 닫습니다. Tailscale은 서버가 밖으로 나가는 연결만 쓰므로 문을 닫아도 됩니다.

  1. 인스턴스 이름 → 네트워킹 탭 → IPv4 방화벽
  2. HTTP(80) 줄 끝의 휴지통을 눌러 지웁니다.
  3. SSH(22) 줄의 연필(편집) → IP 주소로 제한을 켜고 Lightsail 브라우저 SSH/RDP 허용만 남깁니다 → 저장. 이 선택지가 보이지 않으면 SSH 줄도 지웁니다(브라우저 연결이 필요할 때 잠깐 다시 추가하면 됩니다).
  4. 아래 IPv6 방화벽에서도 똑같이 합니다. 두 방화벽은 따로 움직입니다.

확인: 내 PC에서 ssh ubuntu@서버이름(Tailscale)이 여전히 됩니다. 두 방화벽 어디에도 “모든 IP 주소”(Any IPv4/IPv6 address)인 줄이 남아 있지 않습니다. 같은 문에 규칙이 여럿이면 가장 넓은 규칙이 이기므로 하나라도 남으면 열린 것입니다.

10. 백업 (선택)

인스턴스 이름 → 스냅샷 탭 → 자동 스냅샷을 켜면 매일 서버 전체를 저장합니다. 쓰는 용량 GB당 월 $0.05가 크레딧에서 빠집니다(대략 월 $1 안팎). 중요한 파일만 GitHub 비공개 저장소에 올려 두는 방법도 있습니다.

쓰기

어느 기기에서든 같은 작업실로

들어가기ssh ubuntu@서버이름
방 만들기tmux new -s work → 그 안에서 claude → 일을 맡깁니다.

방 목록tmux ls

파일 주고받기

서버의 작업 폴더를 GitHub 저장소로 만들어 두고, 서버와 내 PC에서 각각 가져오고 올리는 것이 가장 쉽습니다. Claude Code에게 “이 폴더를 내 GitHub 비공개 저장소로 올려 줘”라고 맡기면 됩니다. 한두 파일이면 내 PC에서 scp ubuntu@서버이름:~/폴더/파일 . 처럼 바로 받아도 됩니다.

기기 관리

  • 새 기기는 Tailscale 앱을 깔고 같은 계정으로 로그인하면 끝입니다.
  • 기기를 잃어버리거나 학교 PC를 바꾸면 관리 화면에서 그 기기를 제거합니다. 바로 못 들어오게 됩니다.
  • 공용 PC에는 Tailscale을 깔지 않습니다. 같은 계정으로 로그인한 기기는 모두 서버에 들어올 수 있기 때문입니다.

정해진 시각에 돌리기, 점검

cron과 한 달 점검은 집 PC를 서버로의 7·8단계와 같습니다. 우분투의 보안 패치는 저절로 깔리므로, 한 달에 한 번 sudo apt update && sudo apt upgrade -y를 넣고, 맡긴 일이 없을 때 필요하면 sudo reboot합니다.

6개월 뒤: 세 가지 길

3단계에서 걸어 둔 달력 알림(5개월 뒤)이 오면 아래 가운데 하나를 고릅니다.

계속 쓰기
  1. 콘솔에 로그인 → 플랜 업그레이드(콘솔 첫 화면이나 결제 화면에도 버튼이 있습니다)
  2. 얻는 기능을 확인하고 계정 업그레이드를 누릅니다. 계정과 서버는 그대로이고, 남은 크레딧은 이어서 쓰입니다.
  3. 크레딧이 다 떨어진 달부터 월 $7(부가세 별도)이 카드로 청구됩니다. 4단계의 예산 알림이 이제부터 일합니다.
그만두기
  1. 남길 파일을 GitHub이나 내 PC로 옮깁니다.
  2. Lightsail에서 인스턴스 삭제, 스냅샷 탭의 스냅샷도 삭제합니다.
  3. 무료 플랜은 유료로 바꾸지 않는 한 청구되지 않으므로, 이대로 두면 6개월째에 계정이 정지되고 90일 뒤 지워집니다.
집 PC로 옮기기파일을 GitHub으로 옮긴 뒤 집 PC를 서버로의 2부를 따라 하고, 위 “그만두기”를 합니다. Tailscale 계정은 그대로 씁니다.
놓쳤을 때서버가 멈췄다면 만료 통보 뒤 90일 안에 콘솔에 로그인해 유료로 바꾸면 계정과 서버가 돌아옵니다.

문제 해결

ssh가 안 됩니다
Lightsail 콘솔에서 인스턴스가 실행 중인지, 내 기기의 Tailscale 앱이 켜져 있는지 봅니다. 9단계에서 브라우저 SSH를 남겼다면 터미널 아이콘으로 들어가 tailscale status를 봅니다. SSH 규칙을 지웠다면 SSH 규칙을 잠깐 다시 추가해 브라우저로 들어간 뒤 고치고, 다시 지웁니다.
Lightsail에서 “무료 플랜에서는 쓸 수 없다”는 안내가 나옵니다
AWS 문서에는 Lightsail을 무료 티어 크레딧으로 시작할 수 있다고 되어 있지만, 화면이 업그레이드를 요구하면 그 안내를 따라 유료로 바꿔야 합니다. 바꾸면 남은 크레딧이 먼저 쓰이고, 크레딧이 떨어진 뒤부터 월 $7이 청구됩니다. 바로 바꾸고 싶지 않다면 집 PC를 서버로를 먼저 해 봅니다.
서버가 느리거나 Claude Code가 갑자기 꺼집니다
메모리가 모자란 것일 수 있습니다. free -h를 봅니다. 동시에 돌리는 Claude Code 수를 줄이거나, 더 큰 번들로 옮깁니다: 스냅샷 탭에서 수동 스냅샷을 만들고 → 그 스냅샷의 메뉴에서 새 인스턴스 생성을 골라 $12(2GB)를 고른 뒤 → 새 서버에서 Tailscale이 되는지 확인하고(8단계 두 번째 줄을 다시 넣어야 할 수 있음) → 예전 인스턴스와 스냅샷을 지웁니다. 서버 값이 두 배가 되어도 6개월 동안은 크레딧 안에 들어갑니다($12×6 = $72).
크레딧이 예상보다 빨리 줄어듭니다
Lightsail에 모르는 인스턴스가 있는지, 지우지 않은 스냅샷이나 다른 리전의 서버가 있는지 봅니다(Lightsail 첫 화면 위의 리전 표시). 모르는 것이 있으면 계정을 빼앗긴 것일 수 있으니 바로 비밀번호를 바꾸고 AWS 지원(Support)에 알립니다.
재시작한 뒤 맡긴 일이 사라졌습니다
재시작하면 tmux 방도 사라집니다. 일을 맡기기 전에 결과를 파일로 남기게 하고, 업데이트 뒤 재시작은 맡긴 일이 없을 때 합니다.
Oracle 무료로 해 보고 싶습니다
핸드오프 파일을 AI에게 주고 “Oracle Cloud Always Free로 같은 구성을 만들고 싶다”고 하면, 같은 규칙(문 닫기, Tailscale만)으로 안내합니다. 서울에서 만들기가 실패하면 시간을 두고 다시 시도해야 하고, 놀고 있는 서버는 회수될 수 있다는 점을 알고 시작합니다.
