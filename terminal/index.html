터미널(PowerShell) 열기

코딩 도구 갈래의 모든 설치는 터미널에서 합니다. 처음이라면 여기부터 봅니다.

먼저: 터미널 열기

터미널은 글자로 명령을 넣는 창입니다. Windows에서는 PowerShell을 씁니다. 뒤의 모든 단계에서 이 창을 씁니다.

  1. 키보드의 Windows 키를 누르고 powershell이라고 칩니다. 맨 위에 Windows PowerShell이 나오면 Enter를 누릅니다.
    시작 메뉴 검색
    검색
    powershell

    1Windows PowerShell 앱 ← 이것을 엽니다

    Windows PowerShell ISE · 명령 프롬프트 ← 이것들은 아닙니다

    "관리자 권한으로 실행"은 누르지 않습니다. 그냥 엽니다.

  2. 파란색이나 검은색 창이 열리고, 맨 아래 줄 끝에서 커서가 깜빡입니다. 여기에 명령을 넣습니다.
    Windows PowerShell
    Windows PowerShell Copyright (C) Microsoft Corporation. All rights reserved. PS C:\Users\내이름> ▌

    PS C:\Users\내이름> 은 "지금 이 폴더에 있다"는 표시입니다. 이 뒤에 명령을 넣고 Enter를 누릅니다.

  3. 붙여넣기는 창 안에서 마우스 오른쪽 단추를 한 번 누르면 됩니다(Ctrl+V도 됩니다). 이 안내의 명령은 복사해서 붙여넣으세요. 손으로 치면 오타가 납니다.
명령을 넣은 뒤에는 창 안을 마우스로 누르지 않습니다. 왼쪽 단추로 누르면 Windows가 글자를 고르는 상태로 바꾸며 실행을 멈춥니다. 창 제목 앞에 “선택”이 붙어 있으면 이 경우이고, Esc를 누르면 이어서 진행합니다.
명령 프롬프트(cmd)와 다릅니다. 검은 창에 C:\Users\내이름> 만 있고 앞에 PS가 없으면 명령 프롬프트입니다. 닫고 PowerShell을 여세요. 이 안내의 명령은 PowerShell용입니다.
Mac에서는 Cmd+스페이스를 누르고 터미널(또는 terminal)을 쳐서 엽니다.
