3. GitHub 가입

GitHub는 코드를 올려 두는 곳이고, 학생용 페이지 주소도 여기서 나옵니다.

  1. 브라우저에서 github.com/signup을 엽니다.
  2. 네 가지를 넣고 Create account를 누릅니다.

    Username이 중요합니다. 학생 페이지 주소가 https://Username.github.io/… 가 됩니다. 학생에게 보여도 괜찮은 이름으로 정하세요. 이미 쓰는 사람이 있으면 빨간 글씨가 나오니 다른 이름을 넣습니다.

  3. 사람인지 확인하는 퍼즐이 나옵니다. 시키는 대로 그림을 고릅니다.
  4. 넣은 메일 주소로 숫자 코드가 옵니다. 메일함을 열어 그 숫자를 화면에 넣습니다. 메일이 안 보이면 스팸함을 봅니다.
    github.com/account_verifications

  5. 로그인 화면이 나오면 방금 만든 Username(또는 메일)과 비밀번호로 로그인합니다. 무엇을 할 건지 묻는 화면이 나오면 건너뛰어도 됩니다(Skip). 요금제를 묻는다면 Free를 고릅니다.
GitHub 비밀번호는 꼭 적어 두세요. 나중에 올릴 때 브라우저로 한 번 더 로그인합니다.

먼저: 터미널 열기

터미널은 글자로 명령을 넣는 창입니다. Windows에서는 PowerShell을 씁니다. 뒤의 모든 단계에서 이 창을 씁니다.

  1. 키보드의 Windows 키를 누르고 powershell이라고 칩니다. 맨 위에 Windows PowerShell이 나오면 Enter를 누릅니다.
    시작 메뉴 검색
    검색
    powershell

    1Windows PowerShell 앱 ← 이것을 엽니다

    Windows PowerShell ISE · 명령 프롬프트 ← 이것들은 아닙니다

    "관리자 권한으로 실행"은 누르지 않습니다. 그냥 엽니다.

  2. 파란색이나 검은색 창이 열리고, 맨 아래 줄 끝에서 커서가 깜빡입니다. 여기에 명령을 넣습니다.
    Windows PowerShell
    Windows PowerShell Copyright (C) Microsoft Corporation. All rights reserved. PS C:\Users\내이름> ▌

    PS C:\Users\내이름> 은 "지금 이 폴더에 있다"는 표시입니다. 이 뒤에 명령을 넣고 Enter를 누릅니다.

  3. 붙여넣기는 창 안에서 마우스 오른쪽 단추를 한 번 누르면 됩니다(Ctrl+V도 됩니다). 이 안내의 명령은 복사해서 붙여넣으세요. 손으로 치면 오타가 납니다.
명령 프롬프트(cmd)와 다릅니다. 검은 창에 C:\Users\내이름> 만 있고 앞에 PS가 없으면 명령 프롬프트입니다. 닫고 PowerShell을 여세요. 이 안내의 명령은 PowerShell용입니다.
Mac에서는 Cmd+스페이스를 누르고 터미널(또는 terminal)을 쳐서 엽니다.

1. VS Code 설치

VS Code는 폴더 안의 파일을 보고 고치는 프로그램입니다. 연수 실습은 VS Code 안에서 합니다.

  1. PowerShell에 아래 줄을 붙여넣습니다. 
    winget install -e --id Microsoft.VisualStudioCode --accept-package-agreements --accept-source-agreements
    Windows PowerShell
    PS C:\Users\내이름> winget install -e --id Microsoft.VisualStudioCode … 찾음 Microsoft Visual Studio Code [Microsoft.VisualStudioCode] 다운로드 중 … ██████████████████████████████ 100% 설치 성공

    1~2분 걸립니다. “설치 성공”이 나오면 됩니다. 이미 깔려 있으면 그렇다고 알려 줍니다.

    명령이 막히면 code.visualstudio.com에서 받아 설치합니다. 옵션은 기본값으로 두고 “다음”만 누릅니다. Mac도 여기서 받아 응용 프로그램 폴더로 옮깁니다.

2. Claude Code 설치

명령 한 줄입니다. 관리자 권한이 필요 없습니다.

  1. PowerShell을 열고 아래 줄을 복사해 붙여넣은 뒤 Enter를 누릅니다. 
    irm https://claude.ai/install.ps1 | iex
    Windows PowerShell
    PS C:\Users\내이름> irm https://claude.ai/install.ps1 | iex Setting up Claude Code... ✔ Claude Code successfully installed! Version: 2.x.x Location: C:\Users\내이름\.local\bin\claude.exe PS C:\Users\내이름> ▌

    1분쯤 걸립니다. 초록색 줄이 나오고 다시 PS …> 가 나오면 끝난 것입니다.

    Mac은 터미널에 curl -fsSL https://claude.ai/install.sh | bash 를 넣습니다.
  2. PowerShell 창을 닫고 새로 엽니다. 그리고 아래를 넣습니다. 숫자가 나오면 설치가 된 것입니다. 
    claude --version
    Windows PowerShell
    PS C:\Users\내이름> claude --version 2.x.x (Claude Code)
"claude 용어가 … 인식되지 않습니다"라고 나옵니다

창을 새로 열지 않았거나, 설치 폴더가 PATH(명령을 찾는 목록)에 들어가지 않은 것입니다.

  1. PowerShell 창을 모두 닫고 새로 열어 다시 해 봅니다.
  2. 그래도 안 되면 설치할 때 화면에 … is not in your PATH. Run: 이라는 줄과 그 아래 명령이 나왔는지 봅니다. 나왔으면 그 명령을 복사해 넣습니다.
  3. 그 줄을 놓쳤으면 아래를 넣고, 창을 새로 엽니다. 
    [Environment]::SetEnvironmentVariable("Path", [Environment]::GetEnvironmentVariable("Path","User") + ";$env:USERPROFILE\.local\bin", "User")
빨간 글씨로 오류가 나오고 설치가 안 됩니다

학교 망이나 보안 프로그램이 내려받기를 막은 경우가 많습니다. 집이나 휴대폰 핫스팟에서 다시 해 보세요. irm 이라는 말을 모른다고 나오면 PowerShell이 아니라 명령 프롬프트에 넣은 것입니다.

3. 구독 계정으로 로그인

Claude Code를 내 Claude 구독(Pro 또는 Max)에 잇는 단계입니다. API 키를 따로 발급받지 않습니다. 브라우저에서 한 번 승인하면 끝납니다.

  1. PowerShell에 claude 라고 넣고 Enter를 누릅니다. 처음이면 글자 색을 고르라고 합니다. 그냥 Enter를 누르면 됩니다.
    Windows PowerShell
    PS C:\Users\내이름> claude Welcome to Claude Code Let's get started. Choose the text style that looks best with your terminal ❯ 1. Dark mode ✔ 2. Light mode 3. Dark mode (colorblind-friendly) …

    ❯ 가 지금 고른 줄입니다. 위아래 화살표로 옮기고 Enter로 정합니다. 뒤의 화면도 모두 같은 방식입니다.

  2. 로그인 방법을 고릅니다. 맨 위의 1번 "Claude account with subscription" 입니다. 이미 1번에 ❯ 가 있으니 Enter를 누릅니다.
    Windows PowerShell
    Select login method: ❯ 1. Claude account with subscription · Pro, Max, Team, or Enterprise 2. Anthropic Console account · API usage billing 3. 3rd-party platform · …

    2번은 고르지 않습니다. 2번은 쓴 만큼 따로 돈이 나가는 방식입니다. 구독 중이면 1번이 맞습니다.

  3. 브라우저가 저절로 열립니다. claude.ai에 로그인되어 있지 않으면 먼저 로그인합니다. 그다음 승인 화면에서 승인(Authorize)을 누릅니다.
    claude.ai/oauth/authorize…

    Claude Code가 내 Claude 계정에 연결하려고 합니다

    내 구독으로 Claude Code를 쓸 수 있게 됩니다.

    1승인 (Authorize) 취소

    학교 계정과 개인 계정이 둘 다 있으면, 구독을 결제한 계정으로 로그인했는지 오른쪽 위에서 확인하세요.

  4. PowerShell로 돌아오면 Login successful. 이 보입니다. Enter를 누릅니다. 이어서 안내 글(Security notes)이 나오면 한 번 더 Enter를 누릅니다.
    Windows PowerShell
    Login successful. Press Enter to continue… Logged in as 내메일@example.com
  5. 마지막으로 이 폴더를 믿느냐고 묻습니다. 내가 만든 폴더나 연수에서 받은 폴더라면 Yes, I trust this folder 에서 Enter를 누릅니다.
    Windows PowerShell
    Quick safety check: Is this a project you created or one you trust? ❯ 1. Yes, I trust this folder 2. No, exit

    이 질문은 폴더마다 처음 한 번 나옵니다. 인터넷에서 받은 모르는 폴더라면 No를 고릅니다.

  6. 아래처럼 글을 넣는 칸이 나오면 준비가 끝난 것입니다. 한국어로 말을 걸면 됩니다. 끝낼 때는 /exit 을 넣거나 창을 닫습니다.
    Windows PowerShell

4. Antigravity CLI 설치와 로그인 (Claude Code 대신)

Gemini를 만든 Google의 코딩 도구입니다. Claude Code와 같은 일을 하고, 개인 구글 계정으로 로그인합니다. Claude Code를 설치했다면 이 부분은 건너뜁니다.

  1. PowerShell에 아래 줄을 붙여넣고 Enter를 누릅니다. 관리자 권한은 필요 없습니다. 
    irm https://antigravity.google/cli/install.ps1 | iex

    Mac은 터미널에 curl -fsSL https://antigravity.google/cli/install.sh | bash 를 넣습니다.

  2. PowerShell 창을 닫고 새로 엽니다. 아래를 넣어 숫자가 나오면 설치된 것입니다. 
    agy --version
  3. agy 를 넣습니다. 처음이면 로그인 방법을 묻습니다. 1. Google OAuth 를 고릅니다.
    Windows PowerShell — agy
    PS C:\Users\내이름> agy Welcome to the Antigravity CLI. You are currently not signed in. ❯ 1. Google OAuth 2. Use a Google Cloud project
  4. 브라우저가 열리면 개인 구글 계정으로 로그인합니다. 브라우저에 코드가 나오면 복사해 PowerShell에 붙여넣고 Enter를 누릅니다. 이어서 글자 색을 고르고 이용 약관에 동의합니다.
  5. 폴더를 믿느냐고 물으면 Yes, I trust this folder 에서 Enter를 누릅니다. 글을 넣는 칸이 나오면 준비가 끝난 것입니다. 끝낼 때는 /quit 를 넣습니다.
    Windows PowerShell — agy
    Do you trust the contents of this project? ❯ Yes, I trust this folder No, exit
이 화면은 Google의 안내 문서를 보고 그렸고, 직접 설치해 보지는 못했습니다. 글자가 조금 다를 수 있습니다. 학교 구글 계정(Workspace)은 관리자 설정으로 막혀 있을 수 있으니 개인 계정을 씁니다.
"agy 용어가 … 인식되지 않습니다"라고 나옵니다

창을 새로 열었는지 먼저 봅니다. 그래도 안 되면 설치 폴더 C:\Users\내이름\AppData\Local\agy\bin 이 PATH에 들어갔는지 확인해야 합니다. 화면의 오류 글자를 웹 채팅(Gemini나 claude.ai)에 붙여넣고 물어보세요.

막힐 때

무엇을 넣어야 할지 모르겠다화면의 글자를 그대로 복사해 AI에게 붙여넣고 "이게 무슨 뜻이야, 뭘 누르면 돼?"라고 묻습니다. 코딩 도구가 아직 안 되면 웹 채팅(Gemini, claude.ai)에 묻습니다.
빨간 글씨가 나왔다빨간 글씨 전체를 복사해 AI에게 붙여넣습니다. 대부분은 창을 새로 열면 풀립니다.
설치 사이트가 열리지 않는다학교 망에서 막힌 것입니다. 집이나 휴대폰 핫스팟에서 합니다.
아무 반응이 없다작업 표시줄에 깜빡이는 창(허용을 묻는 창)이 없는지 봅니다. 코딩 도구가 묻고 기다리는 중인지도 봅니다.
잘못 눌렀다터미널에서 Esc 를 누르면 Claude Code가 하던 일을 멈춥니다. 창을 닫아도 됩니다. 여기까지의 단계에는 되돌릴 수 없는 것이 없습니다.
