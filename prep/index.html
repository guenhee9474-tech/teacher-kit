연수 전에 꼭 (20분)

연수의 실습은 수행평가 페이지 본보기로 Claude Code를 처음 써 보는 것입니다. 아래를 해 오면 됩니다. 모두 명령을 붙여넣는 것으로 끝납니다. 화면 순서대로 따라 하려면 가입과 설치 따라 하기의 1, 3, 4, 5번을 보세요.

붙여넣을 명령 (Windows PowerShell)

PowerShell을 열고(Windows 키 → powershell → Enter) 위에서부터 차례로 넣습니다. 덩어리 하나를 넣은 뒤에는 PowerShell 창을 닫고 새로 엽니다.

# 1) Claude Code 설치
irm https://claude.ai/install.ps1 | iex
# 2) Claude Code 로그인: 켜고, 로그인 방법 1번을 고르고, 브라우저에서 승인. 끝나면 /exit
claude
# 3) VS Code 설치
winget install -e --id Microsoft.VisualStudioCode --accept-package-agreements --accept-source-agreements
# 4) 본보기 폴더를 '문서'에 받아 풀고, VS Code로 열기
cd $HOME\Documents
irm https://guenhee9474-tech.github.io/teacher-kit/downloads/english-writing-kit.zip -OutFile english-writing-kit.zip
Expand-Archive english-writing-kit.zip -DestinationPath . -Force
code $HOME\Documents\english-writing
Mac 터미널에서는
# 1) Claude Code 설치
curl -fsSL https://claude.ai/install.sh | bash

# 2) 로그인
claude

# 3) VS Code는 code.visualstudio.com 에서 받아 응용 프로그램 폴더로 옮김

# 4) 본보기 폴더 받아 풀고 열기
cd ~/Documents
curl -L -O https://guenhee9474-tech.github.io/teacher-kit/downloads/english-writing-kit.zip
unzip -o english-writing-kit.zip
open -a "Visual Studio Code" ~/Documents/english-writing

다 됐는지 확인

VS Code에 english-writing 폴더가 열려 있고, 터미널에서 claude 를 켜고 “안녕”이라고 쳤을 때 답이 오면 준비가 끝난 것입니다.

집이나 휴대폰 핫스팟에서 하는 것을 권합니다. 학교 망에서는 설치가 막힐 수 있습니다. 막혀서 못 했다면 그대로 오세요. 연수 시작 10분 전에 함께 봅니다. 연수 때 할 일은 실습: Claude Code 첫걸음에 있습니다.

연수 뒤에: 내 수업용으로 설치할 분 (선택)

수행평가 페이지를 내 계정에 올려 실제 수업에 쓰려면 아래가 더 필요합니다. 연수 날에는 없어도 됩니다. 수행평가 페이지 안내 · Claude Code와 일하는 법

Claude Code로 설치가 안 될 때: 직접 받는 곳
  • VS Code: code.visualstudio.com
  • Git: Windows는 git-scm.com(설치 옵션은 기본값), Mac은 터미널에서 git을 치면 설치 안내가 뜹니다.
  • Node.js LTS: nodejs.org
  • Python 3: python.org. Windows에서는 설치 첫 화면의 “Add python.exe to PATH”를 체크합니다.
