가입과 설치 따라 하기

처음 하는 분을 위한 순서입니다. 화면에 무엇이 나오고 무엇을 누르는지를 차례로 적었습니다. 모두 마치는 데 30분쯤 걸립니다.

연수 전에 꼭 할 것은 1, 3, 4번입니다. 2, 5, 6번은 연수 뒤에 수행평가 페이지를 내 수업용으로 설치할 때 합니다.

아래 그림은 실제 화면을 본떠 그린 예시입니다. 글자와 모양은 버전에 따라 조금 다를 수 있습니다. Windows 기준이고, Mac에서 다른 곳은 따로 적었습니다.

1. 터미널 열기

터미널은 글자로 명령을 넣는 창입니다. Windows에서는 PowerShell을 씁니다. 뒤의 모든 단계에서 이 창을 씁니다.

  1. 키보드의 Windows 키를 누르고 powershell이라고 칩니다. 맨 위에 Windows PowerShell이 나오면 Enter를 누릅니다.
    시작 메뉴 검색
    검색
    powershell

    1Windows PowerShell 앱 ← 이것을 엽니다

    Windows PowerShell ISE · 명령 프롬프트 ← 이것들은 아닙니다

    "관리자 권한으로 실행"은 누르지 않습니다. 그냥 엽니다.

  2. 파란색이나 검은색 창이 열리고, 맨 아래 줄 끝에서 커서가 깜빡입니다. 여기에 명령을 넣습니다.
    Windows PowerShell
    Windows PowerShell Copyright (C) Microsoft Corporation. All rights reserved. PS C:\Users\내이름> ▌

    PS C:\Users\내이름> 은 "지금 이 폴더에 있다"는 표시입니다. 이 뒤에 명령을 넣고 Enter를 누릅니다.

  3. 붙여넣기는 창 안에서 마우스 오른쪽 단추를 한 번 누르면 됩니다(Ctrl+V도 됩니다). 이 안내의 명령은 복사해서 붙여넣으세요. 손으로 치면 오타가 납니다.
명령 프롬프트(cmd)와 다릅니다. 검은 창에 C:\Users\내이름> 만 있고 앞에 PS가 없으면 명령 프롬프트입니다. 닫고 PowerShell을 여세요. 이 안내의 명령은 PowerShell용입니다.
Mac에서는 Cmd+스페이스를 누르고 터미널(또는 terminal)을 쳐서 엽니다.

2. GitHub 가입

GitHub는 코드를 올려 두는 곳입니다. 수행평가 페이지의 학생용 주소도 여기서 나옵니다. 무료입니다.

  1. 브라우저에서 github.com/signup을 엽니다.
  2. 네 가지를 넣고 Create account를 누릅니다.
    github.com/signup

    Sign up for GitHub

    1Email
    내 메일 주소
    2Password
    15자 이상, 또는 숫자와 소문자를 섞어 8자 이상
    3Username
    영문, 숫자, 하이픈(-)만
    4Your Country/Region
    South Korea
    Create account

    Username이 중요합니다. 학생 페이지 주소가 https://Username.github.io/… 가 됩니다. 학생에게 보여도 괜찮은 이름으로 정하세요. 이미 쓰는 사람이 있으면 빨간 글씨가 나오니 다른 이름을 넣습니다.

  3. 사람인지 확인하는 퍼즐이 나옵니다. 시키는 대로 그림을 고릅니다.
  4. 넣은 메일 주소로 숫자 코드가 옵니다. 메일함을 열어 그 숫자를 화면에 넣습니다. 메일이 안 보이면 스팸함을 봅니다.
    github.com/account_verifications

    Confirm your email address

    We have sent a code to 내 메일 주소

    Enter code
    1 2 3 4 5 6 7 8
    Continue
  5. 로그인 화면이 나오면 방금 만든 Username(또는 메일)과 비밀번호로 로그인합니다. 무엇을 할 건지 묻는 화면이 나오면 건너뛰어도 됩니다(Skip). 요금제를 묻는다면 Free를 고릅니다.
비밀번호는 꼭 적어 두세요. 뒤에서 Claude Code가 GitHub에 올릴 때 브라우저로 한 번 더 로그인합니다.

3. Claude Code 설치

명령 한 줄입니다. 관리자 권한이 필요 없습니다.

  1. PowerShell을 열고 아래 줄을 복사해 붙여넣은 뒤 Enter를 누릅니다. 
    irm https://claude.ai/install.ps1 | iex
    Windows PowerShell
    PS C:\Users\내이름> irm https://claude.ai/install.ps1 | iex Setting up Claude Code... ✔ Claude Code successfully installed! Version: 2.x.x Location: C:\Users\내이름\.local\bin\claude.exe PS C:\Users\내이름> ▌

    1분쯤 걸립니다. 초록색 줄이 나오고 다시 PS …> 가 나오면 끝난 것입니다.

    Mac은 터미널에 curl -fsSL https://claude.ai/install.sh | bash 를 넣습니다.
  2. PowerShell 창을 닫고 새로 엽니다. 그리고 아래를 넣습니다. 숫자가 나오면 설치가 된 것입니다. 
    claude --version
    Windows PowerShell
    PS C:\Users\내이름> claude --version 2.x.x (Claude Code)
"claude 용어가 … 인식되지 않습니다"라고 나옵니다

창을 새로 열지 않았거나, 설치 폴더가 PATH(명령을 찾는 목록)에 들어가지 않은 것입니다.

  1. PowerShell 창을 모두 닫고 새로 열어 다시 해 봅니다.
  2. 그래도 안 되면 설치할 때 화면에 … is not in your PATH. Run: 이라는 줄과 그 아래 명령이 나왔는지 봅니다. 나왔으면 그 명령을 복사해 넣습니다.
  3. 그 줄을 놓쳤으면 아래를 넣고, 창을 새로 엽니다. 
    [Environment]::SetEnvironmentVariable("Path", [Environment]::GetEnvironmentVariable("Path","User") + ";$env:USERPROFILE\.local\bin", "User")
빨간 글씨로 오류가 나오고 설치가 안 됩니다

학교 망이나 보안 프로그램이 내려받기를 막은 경우가 많습니다. 집이나 휴대폰 핫스팟에서 다시 해 보세요. irm 이라는 말을 모른다고 나오면 PowerShell이 아니라 명령 프롬프트에 넣은 것입니다.

4. 구독 계정으로 로그인

Claude Code를 내 Claude 구독(Pro 또는 Max)에 잇는 단계입니다. API 키를 따로 발급받지 않습니다. 브라우저에서 한 번 승인하면 끝납니다.

  1. PowerShell에 claude 라고 넣고 Enter를 누릅니다. 처음이면 글자 색을 고르라고 합니다. 그냥 Enter를 누르면 됩니다.
    Windows PowerShell
    PS C:\Users\내이름> claude Welcome to Claude Code Let's get started. Choose the text style that looks best with your terminal ❯ 1. Dark mode ✔ 2. Light mode 3. Dark mode (colorblind-friendly) …

    ❯ 가 지금 고른 줄입니다. 위아래 화살표로 옮기고 Enter로 정합니다. 뒤의 화면도 모두 같은 방식입니다.

  2. 로그인 방법을 고릅니다. 맨 위의 1번 "Claude account with subscription" 입니다. 이미 1번에 ❯ 가 있으니 Enter를 누릅니다.
    Windows PowerShell
    Select login method: ❯ 1. Claude account with subscription · Pro, Max, Team, or Enterprise 2. Anthropic Console account · API usage billing 3. 3rd-party platform · …

    2번은 고르지 않습니다. 2번은 쓴 만큼 따로 돈이 나가는 방식입니다. 구독 중이면 1번이 맞습니다.

  3. 브라우저가 저절로 열립니다. claude.ai에 로그인되어 있지 않으면 먼저 로그인합니다. 그다음 승인 화면에서 승인(Authorize)을 누릅니다.
    claude.ai/oauth/authorize…

    Claude Code가 내 Claude 계정에 연결하려고 합니다

    내 구독으로 Claude Code를 쓸 수 있게 됩니다.

    1승인 (Authorize) 취소

    학교 계정과 개인 계정이 둘 다 있으면, 구독을 결제한 계정으로 로그인했는지 오른쪽 위에서 확인하세요.

  4. PowerShell로 돌아오면 Login successful. 이 보입니다. Enter를 누릅니다. 이어서 안내 글(Security notes)이 나오면 한 번 더 Enter를 누릅니다.
    Windows PowerShell
    Login successful. Press Enter to continue… Logged in as 내메일@example.com
  5. 마지막으로 이 폴더를 믿느냐고 묻습니다. 내가 만든 폴더나 연수에서 받은 폴더라면 Yes, I trust this folder 에서 Enter를 누릅니다.
    Windows PowerShell
    Quick safety check: Is this a project you created or one you trust? ❯ 1. Yes, I trust this folder 2. No, exit

    이 질문은 폴더마다 처음 한 번 나옵니다. 인터넷에서 받은 모르는 폴더라면 No를 고릅니다.

  6. 아래처럼 글을 넣는 칸이 나오면 준비가 끝난 것입니다. 한국어로 말을 걸면 됩니다. 끝낼 때는 /exit 을 넣거나 창을 닫습니다.
    Windows PowerShell
    > 안녕, 한국어로 대답해 줘 ? for shortcuts
브라우저가 열리지 않습니다

PowerShell 화면에 Browser didn't open? Use the url below to sign in 과 긴 주소가 나옵니다. 그 주소를 복사해 브라우저 주소창에 붙여넣습니다. 승인하면 브라우저에 코드가 나오는데, 그것을 복사해 PowerShell의 Paste code here if prompted > 뒤에 붙여넣고 Enter를 누릅니다.

2번(Console)으로 잘못 들어갔습니다 / 계정을 바꾸고 싶습니다

Claude Code 안에서 /logout 을 넣어 나간 뒤, /login 으로 다시 들어가 1번을 고릅니다.

"구독이 필요하다"는 말이 나옵니다

무료 계정으로 로그인한 것입니다. claude.ai에서 Pro나 Max를 결제한 계정인지 확인하고, 그 계정으로 다시 로그인합니다.

5. 나머지 도구 설치: Claude Code에게 시키기

Git, Node.js, Python, VS Code는 직접 받으러 다니지 않습니다. 방금 설치한 Claude Code에게 시킵니다.

  1. PowerShell에서 claude 를 켜고, 아래 말을 그대로 붙여넣습니다. 
    Git, Node.js LTS, Python 3, VS Code가 이 PC에 깔려 있는지 확인하고, 없는 것만 설치해 줘.
설치가 끝나면 버전을 확인해서 알려 줘.
  2. Claude가 명령을 실행하기 전에 해도 되느냐고 묻습니다. 무엇을 하려는지 읽어 보고 1. Yes 에서 Enter를 누릅니다. 여러 번 묻습니다.
    Windows PowerShell — claude
    Bash command winget install --id Git.Git -e Git을 설치합니다 Do you want to proceed? ❯ 1. Yes 2. Yes, and don't ask again for winget install commands 3. No

    매번 묻는 것이 번거로우면 2번을 고릅니다. 같은 종류의 명령은 다시 묻지 않습니다.

  3. 설치 중에 화면이 어두워지며 아래 창이 뜰 수 있습니다. 예를 누릅니다. 도구마다 한 번씩 뜹니다.
    사용자 계정 컨트롤
    이 앱이 디바이스를 변경하도록 허용하시겠어요?

    Git for Windows · 확인된 게시자

    예아니요

    이 창이 작업 표시줄에서 깜빡이기만 하고 안 보일 때가 있습니다. 설치가 멈춘 것 같으면 작업 표시줄의 방패 모양 아이콘을 눌러 보세요.

  4. Claude가 "설치가 끝났습니다"와 함께 버전을 알려 주면, PowerShell 창을 닫고 새로 열어 아래를 한 줄씩 넣습니다. 네 줄 모두 숫자가 나오면 준비가 끝난 것입니다.
    Windows PowerShell
    PS C:\Users\내이름> git --version git version 2.47.0.windows.2 PS C:\Users\내이름> node -v v24.19.0 PS C:\Users\내이름> python --version Python 3.12.10 PS C:\Users\내이름> claude --version 2.x.x (Claude Code)

    숫자는 달라도 됩니다. "인식되지 않습니다"가 나오는 줄이 있으면, 그 줄을 그대로 Claude에게 붙여넣고 "이게 안 돼, 고쳐 줘"라고 하면 됩니다.

학교 PC에서는 막힐 수 있습니다. 보안 프로그램이나 관리자 설정 때문입니다. 그때는 연수 전 준비의 "직접 받는 곳"에서 설치 파일을 받아 설치합니다. 설치 옵션은 모두 기본값으로 두고 다음만 누르면 됩니다. Python만 첫 화면의 "Add python.exe to PATH"를 체크합니다.
Mac에서는 Claude가 Homebrew라는 도구로 설치합니다. Homebrew가 없으면 먼저 설치해도 되느냐고 묻고, 중간에 Mac 로그인 비밀번호를 묻습니다. 비밀번호를 칠 때는 화면에 아무것도 보이지 않는 것이 정상입니다.

6. VS Code 처음 쓰기

VS Code는 폴더 안의 파일을 보고 고치는 프로그램입니다. 터미널이 안에 들어 있어서, 파일 목록과 Claude Code를 한 창에서 봅니다.

  1. 시작 메뉴에서 Visual Studio Code를 엽니다. 처음에 색(테마)을 고르는 화면이 나오면 아무것이나 고릅니다.
  2. 위쪽 메뉴에서 파일(File) → 폴더 열기(Open Folder…)를 누르고, 작업할 폴더를 고릅니다. 예를 들면 압축을 푼 english-writing 폴더입니다.
    파일 하나가 아니라 폴더를 엽니다. 폴더 안으로 들어가서 "폴더 선택"을 누릅니다.
  3. "이 폴더에 있는 파일의 작성자를 신뢰합니까?"라고 묻습니다. 연수에서 받은 폴더라면 예, 작성자를 신뢰합니다를 누릅니다.
  4. 위쪽 메뉴에서 터미널(Terminal) → 새 터미널(New Terminal)을 누릅니다. 아래쪽에 터미널 칸이 열립니다. 단축키는 Ctrl+` 입니다(숫자 1 왼쪽의 키).
  5. 그 칸에 claude 를 넣고 Enter를 누릅니다. 4단계에서 로그인했으므로 바로 켜집니다. 폴더를 믿느냐고 물으면 Yes를 고릅니다.
    english-writing — Visual Studio Code
    탐색기▸ docs
    ▸ gas
    ▸ scripts
    ▸ tests
    CLAUDE.md
    README.md
    왼쪽에서 파일을 누르면 여기에 내용이 보입니다
    터미널 PS C:\Users\내이름\english-writing> claude > CLAUDE.md의 처음 설치를 진행해 줘

    왼쪽은 폴더의 파일 목록, 가운데는 파일 내용, 아래는 터미널입니다. Claude가 파일을 고치면 왼쪽 목록에서 그 파일 이름의 색이 바뀝니다.

메뉴가 영어입니다. 한국어로 바꾸고 싶습니다

왼쪽 세로 줄에서 네모 네 개 모양(Extensions)을 누르고 Korean 을 검색해 "Korean Language Pack for Visual Studio Code"를 설치합니다. 오른쪽 아래에 뜨는 다시 시작 단추를 누릅니다. Claude에게 "VS Code를 한국어로 바꿔 줘"라고 해도 됩니다.

VS Code 터미널에서 claude 가 인식되지 않는다고 나옵니다

VS Code를 완전히 닫았다가 다시 엽니다. 도구를 설치하기 전부터 열려 있던 창은 새로 깔린 것을 모릅니다.

막힐 때

무엇을 넣어야 할지 모르겠다화면의 글자를 그대로 복사해 Claude에게 붙여넣고 "이게 무슨 뜻이야, 뭘 누르면 돼?"라고 묻습니다. claude.ai 채팅에 물어도 됩니다.
빨간 글씨가 나왔다빨간 글씨 전체를 복사해 Claude에게 붙여넣습니다. 대부분은 창을 새로 열면 풀립니다.
설치 사이트가 열리지 않는다학교 망에서 막힌 것입니다. 집이나 휴대폰 핫스팟에서 합니다.
아무 반응이 없다작업 표시줄에 깜빡이는 창(허용을 묻는 창)이 없는지 봅니다. Claude가 묻고 기다리는 중인지도 봅니다.
잘못 눌렀다터미널에서 Esc 를 누르면 Claude가 하던 일을 멈춥니다. 창을 닫아도 됩니다. 여기까지의 단계에는 되돌릴 수 없는 것이 없습니다.
