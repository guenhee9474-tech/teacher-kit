# HANDOFF — 클라우드 서버 만들기 (AWS 무료 플랜 + Lightsail 서울)

이 파일은 AI(웹 채팅의 Claude, Claude Code, 다른 AI)에게 건네는 인수인계 문서입니다.
교사가 AWS **무료 플랜**(최대 6개월)으로 Lightsail 서울 서버를 24시간 켜 두고, 학교 PC·집 PC·휴대폰 가운데
**자기가 로그인한 기기에서만** 들어가 Claude Code에게 일을 맡기는 환경을 만들려고 합니다.
이 문서를 읽은 AI는 아래 순서와 규칙대로 함께 진행해 주세요.

설명 페이지: https://guenhee9474-tech.github.io/teacher-kit/cloudserver/
(돈을 쓰지 않는 집 PC 방식: https://guenhee9474-tech.github.io/teacher-kit/homeserver/)

---

## 1. AI에게: 이렇게 도와주세요

- **한 번에 한 단계씩** 진행합니다. 각 단계의 "확인"을 교사와 같이 통과한 뒤 다음으로 갑니다.
- 명령이나 콘솔 조작을 안내하기 전에 **무엇을 하는지 한두 문장으로** 먼저 설명합니다.
- 비밀번호, MFA 코드, 카드 번호, 로그인 코드, 토큰을 대화에 붙여 넣게 하지 않습니다.
- AWS 콘솔의 메뉴 이름과 순서는 바뀔 수 있습니다. 교사가 "그런 버튼이 없다"고 하면 화면에 보이는 글자를 말해 달라고 하고 맞춰 안내합니다.
- 오류가 나면 해결책을 늘어놓지 말고 **원인을 확인하는 명령이나 화면 하나**부터 묻습니다.
- 교사는 개발자가 아닙니다. 전문 용어는 처음 나올 때 한 줄로 풀어 줍니다.
- 크레딧이나 요금이 달라지는 선택(더 큰 번들, 스냅샷, 유료 전환)은 **금액을 먼저 말하고** 교사가 고르게 합니다.

## 2. 지켜야 할 규칙 (바꾸지 않음)

1. **학생 개인정보(성적, 상담, 출결, 연락처, 학번+이름)는 서버에 두지 않습니다.** AWS 무료 티어 약관도 무료 플랜 계정을 민감한 자료 처리에 쓰지 말라고 합니다. 학생 제출은 학교 구글 계정의 시트(Apps Script)에 둡니다.
2. **서버의 바깥 문은 모두 닫습니다.** 공개 SSH(22, 모든 IP), HTTP/HTTPS 공개, 포트 개방을 제안하지 않습니다. 들어가는 길은 Tailscale(+ 비상용 Lightsail 브라우저 SSH)뿐입니다.
3. **AWS 루트 계정에 MFA**를 걸고, **액세스 키는 만들지 않습니다.**
4. **무료 플랜으로 시작합니다.** 유료 전환은 교사가 결정할 때(보통 5개월째)만 안내합니다.
5. 학생이 여는 페이지는 이 서버에 두지 않고 GitHub Pages에 둡니다.
6. 학교·교육청 지침이 클라우드나 개인 결제 사용을 막으면 그 지침이 먼저입니다.
7. Tailscale은 공용 PC에 깔지 않습니다(같은 계정 기기는 모두 서버에 들어올 수 있음).

## 3. 시작 전에 교사에게 물을 것

1. AWS 계정을 만든 적이 있는가? (예전에 계정이 있었으면 무료 플랜·크레딧 대상이 아닐 수 있음 → 비용을 먼저 설명)
2. 어떤 기기에서 들어갈 것인가? 학교 PC에 프로그램 설치가 막혀 있는가? 휴대폰은 아이폰/안드로이드?
3. 이 서버로 하고 싶은 일은? Claude Code를 동시에 몇 개쯤 돌릴 것인가? (2개 이상 자주 → $12, 2GB 고려)
4. Claude 구독(Pro/Max)이 있는가?
5. 터미널(글자 창)을 써 본 적이 있는가?
6. 6개월 뒤 계속 쓴다면 월 $7(부가세 별도) 정도는 괜찮은가? (지금 결정할 필요는 없음)

## 4. 무료 플랜 규칙 (2026-10 AWS 공식 문서 기준, 바뀔 수 있음)

| 항목 | 내용 |
|---|---|
| 대상 | 2025-07-15 이후 새로 만든 AWS 계정. 예전 계정이 있었으면 대상 아님 |
| 크레딧 | 가입 $100 + 활동으로 최대 $100 (예산 만들기 등 5가지, 각 $20) |
| 기간 | 가입 6개월 뒤 또는 크레딧 소진 중 먼저 오는 날. Lightsail $7×6 = $42 → 보통 6개월이 기준 |
| 요금 | 무료 플랜 동안 청구 없음. 카드는 본인 확인용 |
| 확인 | 콘솔 첫 화면 "비용 및 사용량"(Cost and Usage) 위젯: 크레딧 잔액과 남은 날. 만료가 다가오면 이메일 알림 |
| 만료 | 계정 정지 → 서버 멈춤. 만료 통보 뒤 90일 안에 유료 전환하면 복구, 이후 영구 삭제 |
| 유료 전환 | 같은 계정 그대로 언제든. 남은 크레딧 유지. https://console.aws.amazon.com/billing/home?#/freetier/upgrade |
| Lightsail | Lightsail FAQ: "AWS Free Tier로 무료로 시작"(크레딧). 무료 플랜 화면이 Lightsail을 막고 업그레이드를 요구하면, 교사에게 비용을 설명하고 결정을 맡김 |

## 5. 왜 Lightsail인가

| 선택지 | 판단 |
|---|---|
| **AWS Lightsail 서울 (기본안)** | 단순한 화면, 월정액 $7(1GB, 2 vCPU, SSD 40GB, 전송 2TB, IPv4 포함), 서울. 크레딧으로 6개월 |
| AWS EC2 | 같은 크레딧으로 가능하나 보안 그룹·키·공인 IP 요금 등 챙길 것이 많음 |
| Oracle Cloud Always Free | 무료 A1(Arm) 2 OCPU, 12GB. 서울 A1은 자리 부족으로 생성 실패 보고가 많고, 7일간 사용률이 낮으면 회수될 수 있음(상주 Claude Code는 대부분 대기). 가입·화면 난도 높음 |
| Google Cloud e2-micro | 미국 리전만, 월 아웃바운드 1GB → 맞지 않음 |

## 6. 만드는 순서

### 1단계. AWS 가입 (무료 플랜)
- aws.amazon.com → 계정 생성 → 루트 이메일(개인), 계정 이름 → 메일 확인 코드 → 루트 비밀번호(다른 곳과 다른 긴 것).
- **플랜: 무료(Free).** 연락처: 개인, 영어 주소. 결제 정보: 개인 카드(소액 승인 후 취소될 수 있음). 전화 인증. 지원 플랜: 기본(무료).
- **확인:** 콘솔 첫 화면이 열리고 크레딧 $100과 남은 날이 보인다.

### 2단계. MFA
- 인증 앱 설치 → 계정 이름 → 보안 자격 증명 → MFA 할당 → 인증 관리자 앱 → QR → 연속 두 코드.
- 액세스 키는 만들지 않음.
- **확인:** 재로그인 때 6자리 코드를 묻는다.

### 3단계. 남은 날 확인과 달력 알림
- "비용 및 사용량" 위젯(없으면 Billing 화면)에서 크레딧·남은 날 확인.
- 휴대폰 달력에 **가입일 + 5개월** "AWS 계속 쓸지 정하기".

### 4단계. 예산 알림 (크레딧 $20 활동)
- Budgets → 예산 생성 → 월별 비용 예산 → $15, 알림 이메일.
- 무료 플랜 동안은 청구가 없지만 유료 전환 후의 안전장치이고, 크레딧 활동 하나.
- **확인:** 예산 1개. 며칠 뒤 크레딧 증가 확인.

### 5단계. Lightsail 인스턴스
- lightsail.aws.amazon.com → 인스턴스 생성 → 서울(ap-northeast-2a) → Linux/Unix → OS 전용 → Ubuntu(최신 LTS) → 선택 항목 기본값 → 듀얼 스택(IPv4 포함) → $7 → 이름(예: class-server).
- IPv6 전용은 학교·집 망에서 접속 불가일 수 있어 권하지 않음.
- **중지해도 요금(크레딧)이 나감. 지워야 멈춤.**
- **확인:** 상태 "실행 중".

### 6단계. 기본 설정 (인스턴스의 터미널 아이콘 = 브라우저 SSH, 사용자 ubuntu)
```
sudo apt update && sudo apt upgrade -y
sudo timedatectl set-timezone Asia/Seoul
sudo fallocate -l 2G /swapfile && sudo chmod 600 /swapfile
sudo mkswap /swapfile && sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
sudo apt install -y tmux
```
- 업그레이드 중 보라색 화면(서비스 재시작 묻기)이 나오면 Enter.
- **확인:** `date`에 KST, `free -h`에 Swap 2.0Gi.

### 7단계. Claude Code
```
curl -fsSL https://claude.ai/install.sh | bash
```
- 내려받는 동안 표시가 없어도 정상(1~3분). `source ~/.bashrc` → `claude --version`.
- `claude` → 로그인 방법 1(구독) → 표시된 주소를 교사 PC 브라우저에서 열어 승인 → 코드를 서버 창에 붙여 넣기.
- **확인:** `claude`가 대화 화면으로 열린다.

### 8단계. Tailscale
```
curl -fsSL https://tailscale.com/install.sh | sh
sudo tailscale up --ssh
```
- 표시된 주소로 로그인 → `Success.`. 교사의 다른 기기에도 앱 설치, 같은 계정. 휴대폰은 Tailscale + Termius(호스트: 서버 이름 또는 100.x 주소, 사용자 ubuntu).
- 접속: `ssh ubuntu@서버이름`. 처음엔 브라우저 확인 창, 지문 질문엔 yes.
- **확인:** 교사 PC에서 Tailscale로 ssh 성공. **이것이 되기 전에는 9단계로 가지 않음.**

### 9단계. 방화벽 닫기
- 네트워킹 → IPv4 방화벽: HTTP(80) 삭제, SSH(22)는 "IP 주소로 제한" + "Lightsail 브라우저 SSH/RDP 허용"만. 그 선택지가 없으면 SSH 규칙 삭제(필요할 때 잠시 다시 추가).
- IPv6 방화벽도 똑같이(두 방화벽은 독립).
- 같은 포트에 규칙이 여럿이면 가장 넓은 규칙이 적용 → "모든 IP 주소" 규칙이 하나도 남지 않게.
- **확인:** Tailscale ssh는 여전히 됨. "모든 IP 주소" 규칙 없음.

### 10단계. 백업 (선택)
- 스냅샷 탭 → 자동 스냅샷(사용 용량 GB당 월 $0.05, 크레딧에서 차감). 또는 중요한 파일만 GitHub 비공개 저장소로.

## 7. 쓰기

- `ssh ubuntu@서버이름` → `tmux new -s work` → `claude` → 일 맡기기 → Ctrl+b, d → 접속 끊어도 계속.
- 다른 기기에서: `tmux attach -t work`. 목록: `tmux ls`.
- 파일 주고받기: 작업 폴더를 GitHub 비공개 저장소로. 한두 개는 `scp`.
- 잃어버린 기기는 Tailscale 관리 화면에서 제거.
- cron(정해진 시각 작업)은 crontab 줄을 먼저 보여 주고 승인받은 뒤 걸고, 반드시 로그 파일을 남김.
- 한 달에 한 번 `sudo apt update && sudo apt upgrade -y`, 맡긴 일이 없을 때 필요하면 `sudo reboot`.

## 8. 6개월 뒤 (5개월째 달력 알림이 오면)

| 길 | 할 일 |
|---|---|
| 계속 쓰기 | 플랜 업그레이드 → 계정 업그레이드. 서버·계정 그대로, 남은 크레딧 유지. 크레딧 소진 후 월 $7+부가세 청구. 예산 알림이 이때부터 일함 |
| 그만두기 | 파일 옮기기 → 인스턴스·스냅샷 삭제. 무료 플랜은 청구 없이 만료 → 정지 → 90일 뒤 삭제 |
| 집 PC로 옮기기 | 파일을 GitHub으로 → homeserver 페이지 2부 → 그만두기 |
| 놓쳤을 때 | 만료 통보 뒤 90일 안에 유료 전환하면 복구 |

## 9. 자주 막히는 곳

| 증상 | 먼저 볼 것 |
|---|---|
| ssh 안 됨 | 인스턴스 "실행 중"? 기기의 Tailscale 켜짐? 브라우저 SSH로 들어가 `tailscale status` |
| 무료 플랜이라 Lightsail을 못 쓴다는 안내 | 교사에게 비용(크레딧 먼저, 이후 월 $7)을 설명하고 전환 여부를 맡김. 원하지 않으면 집 PC 방식 |
| 느림, Claude Code가 꺼짐 | `free -h`. 동시 실행 줄이기 또는 스냅샷 → $12(2GB) 새 인스턴스($12×6=$72, 크레딧 안) → 확인 후 예전 것 삭제 |
| 크레딧이 빨리 줄어듦 | 모르는 인스턴스·스냅샷·다른 리전 서버? 모르는 것이 있으면 비밀번호 변경 + AWS 지원 |
| 재시작 뒤 tmux 방이 없음 | 재시작하면 사라짐. 결과는 파일로 남기게 함 |

## 10. 이 문서 밖으로 가지 않을 것

- 공개 웹 서비스, 도메인 연결, 학생 대상 서비스, 데이터베이스 공개는 범위가 아닙니다. 교사가 원하면 2절의 이유를 먼저 설명하고, 학교 정보 담당자와 상의하도록 권합니다.
