# HANDOFF — 클라우드 서버 만들기 (AWS 무료 플랜 + EC2 서울)

이 파일은 AI(웹 채팅의 Claude, Claude Code, 다른 AI)에게 건네는 인수인계 문서입니다.
교사가 AWS **무료 플랜**(최대 6개월)으로 EC2 서울 서버(t4g.small)를 24시간 켜 두고, 학교 PC·집 PC·휴대폰 가운데
**자기가 로그인한 기기에서만** 들어가 Claude Code에게 일을 맡기는 환경을 만들려고 합니다.
이 문서를 읽은 AI는 아래 순서와 규칙대로 함께 진행해 주세요.

설명 페이지: https://guenhee9474-tech.github.io/teacher-kit/cloudserver/
(돈을 쓰지 않는 집 PC 방식: https://guenhee9474-tech.github.io/teacher-kit/homeserver/)

---

## 1. AI에게: 이렇게 도와주세요

- **한 번에 한 단계씩** 진행합니다. 각 단계의 "확인"을 교사와 같이 통과한 뒤 다음으로 갑니다.
- 명령이나 콘솔 조작을 안내하기 전에 **무엇을 하는지 한두 문장으로** 먼저 설명합니다.
- 비밀번호, MFA 코드, 카드 번호, 로그인 코드, 토큰, 키 파일(.pem) 내용을 대화에 붙여 넣게 하지 않습니다.
- AWS 콘솔의 메뉴 이름과 순서는 바뀔 수 있습니다. 교사가 "그런 버튼이 없다"고 하면 화면에 보이는 글자를 말해 달라고 하고 맞춰 안내합니다.
- 오류가 나면 해결책을 늘어놓지 말고 **원인을 확인하는 명령이나 화면 하나**부터 묻습니다.
- 교사는 개발자가 아닙니다. 전문 용어는 처음 나올 때 한 줄로 풀어 줍니다.
- 크레딧 사용량이 달라지는 선택(더 큰 서버, 스냅샷, 탄력적 IP, 유료 전환)은 **월 금액을 먼저 말하고** 교사가 고르게 합니다.

## 2. 지켜야 할 규칙 (바꾸지 않음)

1. **학생 개인정보(성적, 상담, 출결, 연락처, 학번+이름)는 서버에 두지 않습니다.** AWS 무료 티어 약관도 무료 플랜 계정을 민감한 자료 처리에 쓰지 말라고 합니다. 학생 제출은 학교 구글 계정의 시트(Apps Script)에 둡니다.
2. **들어오는 문은 EC2 Instance Connect 접두사 목록의 SSH 하나만** 둡니다(또는 0개). `0.0.0.0/0`·`::/0` SSH, HTTP/HTTPS 공개, 포트 개방을 제안하지 않습니다. 평소에 들어가는 길은 Tailscale입니다.
3. **AWS 루트 계정에 MFA**를 걸고, **액세스 키는 만들지 않습니다.**
4. **무료 플랜으로 시작합니다.** 유료 전환은 교사가 결정할 때(보통 4개월째)만 안내합니다.
5. 학생이 여는 페이지는 이 서버에 두지 않고 GitHub Pages에 둡니다.
6. 학교·교육청 지침이 클라우드나 개인 결제 사용을 막으면 그 지침이 먼저입니다.
7. Tailscale은 공용 PC에 깔지 않습니다(같은 계정 기기는 모두 서버에 들어올 수 있음).

## 3. 시작 전에 교사에게 물을 것

1. AWS 계정을 만든 적이 있는가? (예전에 계정이 있었으면 무료 플랜·크레딧 대상이 아님 → 비용을 먼저 설명)
2. 어떤 기기에서 들어갈 것인가? 학교 PC에 프로그램 설치가 막혀 있는가? 휴대폰은 아이폰/안드로이드?
3. 이 서버로 하고 싶은 일은? Claude Code를 동시에 몇 개쯤 돌릴 것인가? (메모리 2GB라 한 번에 하나가 기본)
4. Claude 구독(Pro/Max)이 있는가?
5. 터미널(글자 창)을 써 본 적이 있는가?
6. 6개월 뒤 계속 쓴다면 월 $12~20(부가세 별도) 정도는 괜찮은가? (지금 결정할 필요는 없음)

## 5. 왜 EC2 t4g.small인가

| 선택지 | 판단 |
|---|---|
| **EC2 t4g.small 서울 (기본안)** | 무료 플랜에서 고를 수 있는 2GB 가운데 최저가(월 약 $20어치). Arm(Graviton)이지만 Ubuntu 24.04, Claude Code(linux-arm64), Tailscale 모두 지원 |
| EC2 t3.small | 같은 2GB, x86, 월 약 $24어치 → 크레딧 활동 하나 더(Lambda) 필요. t4g가 막힐 때 대안 |
| EC2 t4g.micro | 월 약 $13어치, 1GB → Claude Code에는 빠듯 |
| EC2 c7i-flex.large | 4GB(Claude Code 공식 권장 4GB+ 충족)지만 월 약 $75어치 → 크레딧 두 달 |
| Lightsail | 무료 플랜에서 막힘. 유료 전환 뒤 $12(2GB, IPv4 포함) 월정액으로 옮겨 갈 곳 |
| Oracle Cloud Always Free | A1(Arm) 2 OCPU, 12GB 무료. 춘천에는 A1이 없고 서울 A1은 자리 부족으로 생성 실패 보고가 많음. 7일간 사용률이 낮으면 회수될 수 있음(상주 Claude Code는 대부분 대기). 가입·화면 난도 높음 |
| Google Cloud e2-micro | 미국 리전만, 월 아웃바운드 1GB → 맞지 않음 |

주의: Claude Code 공식 권장 메모리는 4GB 이상입니다. 2GB + 스왑 2GB로 쓰므로 한 번에 하나씩 맡기는 것을 기본으로 안내합니다.

## 6. 만드는 순서

### 1단계. AWS 가입 (무료 플랜)
- aws.amazon.com → 계정 생성 → 루트 이메일(개인), 계정 이름 → 메일 확인 코드 → 루트 비밀번호(다른 곳과 다른 긴 것).
- **플랜: 무료(Free).** 연락처: 개인, 영어 주소. 결제 정보: 개인 카드(소액 승인 후 취소될 수 있음). 전화 인증. 지원 플랜: 기본(무료).
- **확인:** 콘솔 첫 화면이 열리고 크레딧 $100과 남은 날이 보인다.

### 2단계. MFA
- 인증 앱 설치 → 계정 이름 → 보안 자격 증명 → MFA 할당 → 인증 관리자 앱 → QR → 연속 두 코드.
- 액세스 키는 만들지 않음.
- **확인:** 재로그인 때 6자리 코드를 묻는다.

### 3단계. 크레딧 확인과 달력 알림
- "비용 및 사용량" 위젯(없으면 Billing 화면)에서 크레딧·남은 날 확인.
- 휴대폰 달력: **매달 가입한 날** "AWS 크레딧 확인", **가입일 + 4개월** "AWS 계속 쓸지 정하기".

### 4단계. 크레딧 활동 두 가지 (+$40, 필수)
- **Budgets**: 예산 생성 → 월별 비용 예산 → $25, 알림 이메일. 유료 전환 뒤의 안전장치이기도 함.
- **Bedrock playground**: Bedrock → 플레이그라운드(채팅) → Amazon Nova 모델(예: Nova Micro) → "안녕" 실행. 비용 1센트 안팎(크레딧 차감). 다른 회사 모델은 사용 신청서가 필요할 수 있어 Amazon 모델 사용.
- EC2 활동은 이 서버로 하지 않음(안내가 끝에 인스턴스 삭제까지 감). Lambda·RDS는 불필요(t3.small을 쓸 때만 Lambda 추가).
- **확인:** Explore AWS 위젯에 두 활동 완료 표시, 며칠 안에 크레딧 $140.

### 5단계. EC2 인스턴스
- 리전: **아시아 태평양(서울) ap-northeast-2**. EC2 → 인스턴스 시작.
- 이름 `class-server`. AMI: Ubuntu Server 24.04 LTS(프리 티어 사용 가능), 아키텍처 **64비트(Arm)**. 유형 **t4g.small**.
- 키 페어: 새로 생성 `class-key`, RSA, .pem → 비상용으로 교사 PC에 보관(저장소·메신저에 올리지 않음).
- 네트워크 설정 → 편집: 퍼블릭 IP 자동 할당 **활성화**. 보안 그룹 생성 `class-server-sg`. SSH 규칙 소스 유형 **사용자 지정**, 소스 `com.amazonaws.ap-northeast-2.ec2-instance-connect`(접두사 목록, `instance-connect`로 검색). 안 보이면 임시로 "내 IP" → 9단계에서 수정. **"위치 무관(0.0.0.0/0)" 금지.** HTTP/HTTPS 허용 끔.
- 스토리지 16 GiB gp3.
- 고급 세부 정보: **종료 방지 활성화**, **크레딧 사양 표준**(Standard. 무제한이면 CPU 몰릴 때 추가 차감).
- 탄력적 IP는 만들지 않음(붙이지 않은 탄력적 IP도 과금).
- **확인:** 상태 "실행 중", 상태 검사 모두 통과.

### 6단계. 기본 설정 (콘솔 → 연결 → EC2 인스턴스 연결 탭, 사용자 ubuntu)
```
sudo apt update && sudo apt upgrade -y
sudo timedatectl set-timezone Asia/Seoul
sudo hostnamectl set-hostname class-server
sudo fallocate -l 2G /swapfile && sudo chmod 600 /swapfile
sudo mkswap /swapfile && sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
sudo apt install -y tmux
```
- 업그레이드 중 보라색 화면(서비스 재시작 묻기)이 나오면 Enter. "restart required"가 보이면 `sudo reboot` 후 1분 뒤 재연결.
- hostname을 바꾸는 이유: Tailscale 기기 이름이 `ip-172-31-…` 대신 `class-server`가 되게.
- **확인:** `date`에 KST, `free -h`에 Swap 2.0Gi, `hostname`에 class-server.

### 7단계. Claude Code
```
curl -fsSL https://claude.ai/install.sh | bash
```
- 내려받는 동안 표시가 없어도 정상(1~3분). `source ~/.bashrc` → `claude --version`.
- `claude` → 로그인 방법 1(구독) → 표시된 주소를 교사 PC 브라우저에서 열어 승인 → 코드를 서버 창에 붙여 넣기.
- **확인:** `claude`가 대화 화면으로 열린다.

### 8단계. Tailscale
```
curl -fsSL https://tailscale.com/install.sh | sh
sudo tailscale up --ssh
```
- 표시된 주소로 로그인 → `Success.`. 교사의 다른 기기에도 앱 설치, 같은 계정. 휴대폰은 Tailscale + Termius(호스트: class-server 또는 100.x 주소, 사용자 ubuntu).
- 접속: `ssh ubuntu@class-server`. 처음엔 브라우저 확인 주소, 지문 질문엔 yes.
- **확인:** 교사 PC에서 Tailscale로 ssh 성공. **이것이 되기 전에는 9단계로 가지 않음.**

### 9단계. 바깥 문 점검
- 인스턴스 → 보안 탭 → 보안 그룹 → 인바운드 규칙: **SSH 하나, 소스 `pl-…`(EC2 Instance Connect)**만 있어야 함.
- 소스가 0.0.0.0/0, ::/0, 내 IP면 접두사 목록으로 바꿈. 다른 규칙은 삭제.
- 더 엄격하게: SSH 규칙도 삭제(인바운드 0개). 그러면 콘솔 브라우저 연결은 불가, 필요 시 규칙 재추가.
- 아웃바운드 규칙은 건드리지 않음(Tailscale이 씀).
- **확인:** Tailscale ssh는 여전히 됨. 0.0.0.0/0·::/0 인바운드 없음.

### 10단계. 백업 (선택)
- 중요한 파일은 GitHub 비공개 저장소. 전체 백업은 볼륨 → 스냅샷 생성(GB당 월 $0.05, 크레딧 차감), 오래된 것은 삭제.

## 7. 쓰기

- `ssh ubuntu@class-server` → `tmux new -s work` → `claude` → 일 맡기기 → Ctrl+b, d → 접속 끊어도 계속.
- 다른 기기에서: `tmux attach -t work`. 목록: `tmux ls`.
- Claude Code는 한 번에 하나가 기본(2GB). 길게 맡길 때 권한 질문에서 멈출 수 있으니 허락할 범위를 미리 정함.
- 파일 주고받기: 작업 폴더를 GitHub 비공개 저장소로. 한두 개는 `scp`.
- 잃어버린 기기는 Tailscale 관리 화면에서 제거.
- 오래 안 쓸 때: 인스턴스 중지 → 서버·IPv4 값 멈춤, 디스크(월 약 $1.5)만. 다시 시작하면 Tailscale 자동 재연결(공인 IP는 바뀌어도 무관).
- cron(정해진 시각 작업)은 crontab 줄을 먼저 보여 주고 승인받은 뒤 걸고, 반드시 로그 파일을 남김.
- 한 달에 한 번 `sudo apt update && sudo apt upgrade -y`, 맡긴 일이 없을 때 필요하면 `sudo reboot`. 같은 날 크레딧 잔액 확인.

## 8. 6개월 뒤 (4개월째 달력 알림이 오면)

| 길 | 할 일 |
|---|---|
| 그대로 계속 | 플랜 업그레이드 → 계정 업그레이드. 서버·계정 그대로, 남은 크레딧 유지. 크레딧 소진 후 월 약 $20+부가세. 예산 알림($25)이 이때부터 일함 |
| 더 싸게 옮기기 | 유료 전환 후 Lightsail 서울 $12(2GB, IPv4 포함) 새로 만들기 → 6~9단계를 Lightsail 화면에 맞춰(브라우저 SSH, IPv4·IPv6 방화벽 둘 다 닫기, Lightsail은 중지해도 과금) → 새 서버 확인 후 EC2 그만두기 |
| 그만두기 | 파일 옮기기 → 종료 방지 끄기 → 인스턴스 종료(삭제) → 스냅샷 삭제. 무료 플랜은 청구 없이 만료 → 계정 닫힘 → 90일 뒤 삭제 |
| 집 PC로 옮기기 | 파일을 GitHub으로 → homeserver 페이지 2부 → 그만두기 |
| 놓쳤을 때 | 90일 안에 유료 전환하면 복구 |

| 증상 | 먼저 볼 것 |
|---|---|
| ssh 안 됨 | 인스턴스 "실행 중"? 기기의 Tailscale 켜짐? 콘솔 EC2 인스턴스 연결로 들어가 `tailscale status` |
| 콘솔 연결 실패 | SSH 규칙 소스가 EC2 Instance Connect 접두사 목록인가(내 IP면 콘솔 연결 불가)? 규칙을 지웠으면 재추가. 학교 망이면 핫스팟 |
| t4g.small 안 보임/시작 막힘 | AMI 아키텍처가 Arm인가? 안 되면 x86 + t3.small(월 약 $24 → Lambda 활동 추가) |
| 느림, Claude Code가 꺼짐 | `free -h`. 동시 실행 하나로, 안 쓰는 tmux 방 닫기. c7i-flex.large는 크레딧 두 달이라 비권장 |
| 크레딧이 빨리 줄어듦 | Billing → 청구서에서 서비스별 확인. 붙이지 않은 탄력적 IP, 스냅샷, 다른 리전 인스턴스, 크레딧 사양 무제한? 모르는 리소스면 비밀번호 변경 + AWS 지원 |
| 활동 크레딧이 안 들어옴 | 며칠 대기 → 위젯 완료 표시 확인. 끝내 안 들어오면 4.9개월에 소진 → 4개월 알림 때 결정 |
| 재시작 뒤 tmux 방이 없음 | 재시작하면 사라짐. 결과는 파일로 남기게 함 |

## 10. 이 문서 밖으로 가지 않을 것

- 공개 웹 서비스, 도메인 연결, 학생 대상 서비스, 데이터베이스 공개는 범위가 아닙니다. 교사가 원하면 2절의 이유를 먼저 설명하고, 학교 정보 담당자와 상의하도록 권합니다.
