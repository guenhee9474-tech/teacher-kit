# HANDOFF — 클라우드 서버 만들기 (AWS Lightsail 서울)

이 파일은 AI(웹 채팅의 Claude, Claude Code, 다른 AI)에게 건네는 인수인계 문서입니다.
교사가 월 1만 원 안팎의 클라우드 서버를 24시간 켜 두고, 학교 PC·집 PC·휴대폰 가운데
**자기가 로그인한 기기에서만** 들어가 Claude Code에게 일을 맡기는 환경을 만들려고 합니다.
이 문서를 읽은 AI는 아래 순서와 규칙대로 함께 진행해 주세요.

설명 페이지: https://guenhee9474-tech.github.io/teacher-kit/cloudserver/
(돈을 쓰지 않는 집 PC 방식: https://guenhee9474-tech.github.io/teacher-kit/homeserver/)

---

## 1. AI에게: 이렇게 도와주세요

- **한 번에 한 단계씩** 진행합니다. 각 단계의 "확인"을 교사와 같이 통과한 뒤 다음으로 갑니다.
- 명령이나 콘솔 조작을 안내하기 전에 **무엇을 하는지 한두 문장으로** 먼저 설명합니다.
- 비밀번호, MFA 코드, 카드 번호, 로그인 코드, 토큰을 대화에 붙여 넣게 하지 않습니다.
- AWS 콘솔의 메뉴 이름은 바뀔 수 있습니다. 교사가 "그런 버튼이 없다"고 하면 화면에 보이는 것을 말해 달라고 하고 맞춰 안내합니다.
- 오류가 나면 해결책을 늘어놓지 말고 **원인을 확인하는 명령이나 화면 하나**부터 묻습니다.
- 교사는 개발자가 아닙니다. 전문 용어는 처음 나올 때 한 줄로 풀어 줍니다.
- 요금이 달라지는 선택(더 큰 번들, 스냅샷, 고정 IP 등)은 **월 금액을 먼저 말하고** 교사가 고르게 합니다.

## 2. 지켜야 할 규칙 (바꾸지 않음)

1. **학생 개인정보(성적, 상담, 출결, 연락처, 학번+이름)는 서버에 두지 않습니다.** 학생 제출은 학교 구글 계정의 시트(Apps Script)에 둡니다.
2. **서버의 바깥 문은 모두 닫습니다.** 공개 SSH(22, 모든 IP), HTTP/HTTPS 공개, 포트 개방을 제안하지 않습니다. 들어가는 길은 Tailscale(+ 비상용 Lightsail 브라우저 SSH)뿐입니다.
3. **AWS 루트 계정에 MFA**를 걸고, **액세스 키는 만들지 않습니다.**
4. **예산 알림(월 $15)** 을 서버보다 먼저 겁니다.
5. 학생이 여는 페이지는 이 서버에 두지 않고 GitHub Pages에 둡니다.
6. 학교·교육청 지침이 클라우드나 개인 결제 사용을 막으면 그 지침이 먼저입니다.
7. Tailscale은 공용 PC에 깔지 않습니다(같은 계정 기기는 모두 서버에 들어올 수 있음).

## 3. 시작 전에 교사에게 물을 것

1. AWS 계정이 이미 있는가? 있다면 언제 만들었고, 무료(Free) 플랜인가 유료(Paid) 플랜인가?
2. 월 얼마까지 낼 수 있는가? (기본안: $7/월 + 부가세)
3. 어떤 기기에서 들어갈 것인가? 학교 PC에 프로그램 설치가 막혀 있는가? 휴대폰은 아이폰/안드로이드?
4. 이 서버로 하고 싶은 일은? Claude Code를 동시에 몇 개쯤 돌릴 것인가? (2개 이상 자주 → $12, 2GB 고려)
5. Claude 구독(Pro/Max)이 있는가?
6. 터미널(글자 창)을 써 본 적이 있는가?

## 4. 왜 Lightsail인가 (2026-10 공식 페이지 기준, 바뀔 수 있음)

| 선택지 | 요금 | 판단 |
|---|---|---|
| **AWS Lightsail 서울 (기본안)** | $7/월: 1GB, 2 vCPU, SSD 40GB, 전송 2TB, IPv4 포함 | 단순한 화면, 월정액, 서울. 새 계정 가입 크레딧(최대 $200, 대략 6개월)이 요금에 쓰임 |
| Oracle Cloud Always Free | 무료: A1(Arm) 2 OCPU, 12GB (홈 리전) | 사양 최고. 단 서울 A1은 자리 부족으로 생성 실패 보고가 많고, 7일간 CPU·네트워크·메모리 사용이 낮으면 회수될 수 있음(상주 Claude Code는 대부분 대기). 춘천 리전은 A1 불가. 가입·화면 난도 높음 |
| Google Cloud e2-micro | 무료 1대 | 미국 리전만, 월 아웃바운드 1GB → 맞지 않음 |
| AWS EC2 무료 플랜 | 크레딧 소진 또는 약 6개월 뒤 종료 | 종료 시 계정 정지(90일 안에 유료 전환하면 복구). 상주에는 결국 유료 |

교사가 "꼭 무료로" 원하면 Oracle 경로를 같은 규칙(2절)으로 안내하되, 위 단점을 먼저 말합니다.

## 5. 만드는 순서

### 1단계. AWS 가입과 MFA
- aws.amazon.com에서 개인 이메일·카드로 가입.
- 플랜은 **유료(Paid)** 권장: 가입 크레딧은 유료 플랜에도 적용됨. 무료(Free) 플랜도 같은 계정 그대로 언제든 유료 전환 가능(남은 크레딧 유지). 단 전환하지 않고 6개월 경과 또는 크레딧 소진 시 계정 정지 → 서버 멈춤. 정지 후 90일 안에 유료 전환하면 복구, 이후 영구 삭제. 이미 무료 플랜이면 만료 전에 전환하도록 안내.
- 계정 메뉴 → 보안 자격 증명 → MFA 할당(인증 앱).
- 액세스 키는 만들지 않음.
- **확인:** 다시 로그인할 때 MFA 코드를 묻는다.

### 2단계. 예산 알림
- Budgets → 예산 생성 → 월별 비용 예산 → $15, 알림 이메일.
- **확인:** Budgets 목록에 예산 1개.

### 3단계. 인스턴스 생성
- lightsail.aws.amazon.com → 인스턴스 생성 → 서울(ap-northeast-2) → Linux/Unix → OS 전용 → Ubuntu(최신 LTS) → 듀얼 스택(IPv4 포함) → $7 번들 → 이름(예: class-server).
- IPv6 전용 번들은 싸지만 학교·집 망이 IPv6를 지원하지 않으면 접속 불가 → 권하지 않음.
- **확인:** 상태 "실행 중".

### 4단계. 기본 설정 (Lightsail "연결" 버튼 = 브라우저 SSH)
```
sudo apt update && sudo apt upgrade -y
sudo timedatectl set-timezone Asia/Seoul
sudo fallocate -l 2G /swapfile && sudo chmod 600 /swapfile
sudo mkswap /swapfile && sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
sudo apt install -y tmux
```
- **확인:** `free -h`에 Swap 2.0Gi.

### 5단계. Claude Code
```
curl -fsSL https://claude.ai/install.sh | bash
```
- `source ~/.bashrc` 또는 창 다시 열기 → `claude` → 구독 로그인. 서버에 브라우저가 없으므로 표시된 주소를 교사의 PC 브라우저에서 열고, 받은 코드를 서버 창에 붙여 넣음.
- **확인:** `claude`가 대화 화면으로 열린다.

### 6단계. Tailscale
```
curl -fsSL https://tailscale.com/install.sh | sh
sudo tailscale up --ssh
```
- 표시된 주소로 로그인. 교사의 다른 기기에도 Tailscale 앱 설치, 같은 계정.
- 접속: `ssh ubuntu@서버이름` (이름은 login.tailscale.com/admin/machines). 휴대폰은 Termius 등.
- **확인:** 교사 PC에서 Tailscale로 ssh 접속 성공. **이것이 되기 전에는 7단계로 가지 않음.**

### 7단계. 방화벽 닫기
- 인스턴스 → 네트워킹 → IPv4 방화벽: HTTP(80) 삭제, SSH(22)는 "IP 주소로 제한" + "Lightsail 브라우저 SSH/RDP 허용"만. 그 선택지가 없으면 SSH 규칙 삭제(필요할 때 잠시 다시 추가).
- IPv6 방화벽도 똑같이(두 방화벽은 독립).
- 같은 포트에 규칙이 여럿이면 가장 넓은 규칙이 적용되므로, "모든 IP 주소" 규칙이 남지 않게 함.
- **확인:** Tailscale ssh는 여전히 됨. 방화벽 목록에 "모든 IP 주소" 규칙 없음.

### 8단계. 백업 (선택)
- 스냅샷 탭 → 자동 스냅샷(용량만큼 요금, 40GB면 대략 월 $2). 또는 중요한 파일만 GitHub 비공개 저장소로.

## 6. 쓰기

- `tmux new -s work` → `claude` → 일 맡기기 → Ctrl+b, d → 접속 끊어도 계속.
- 다른 기기에서: `ssh ubuntu@서버이름` → `tmux attach -t work`.
- 잃어버린 기기는 Tailscale 관리 화면에서 제거.
- cron(정해진 시각 작업)은 crontab 줄을 먼저 보여 주고 승인받은 뒤 걸고, 반드시 로그 파일을 남김.
- 한 달에 한 번 `sudo apt update && sudo apt upgrade -y`, 필요하면 맡긴 일이 없을 때 `sudo reboot`.

## 7. 그만둘 때

1. 남길 파일 옮기기 → 2. 인스턴스 삭제, 스냅샷 삭제, (만들었다면) 고정 IP 해제 → 3. 다음 달 청구서 $0 확인.

## 8. 자주 막히는 곳

| 증상 | 먼저 볼 것 |
|---|---|
| ssh 안 됨 | 인스턴스 "실행 중"? 기기의 Tailscale 켜짐? 브라우저 SSH로 들어가 `tailscale status` |
| 느림, Claude Code가 꺼짐 | `free -h`. 동시 실행 줄이기 또는 스냅샷 → $12(2GB) 새 인스턴스 → 확인 후 예전 것 삭제 |
| 예산 알림 메일 | 모르는 인스턴스·스냅샷? 모르는 것이 있으면 비밀번호 변경 + AWS 지원에 연락 |
| 재시작 뒤 tmux 방이 없음 | 재시작하면 사라짐. 결과는 파일로 남기게 함 |

## 9. 이 문서 밖으로 가지 않을 것

- 공개 웹 서비스, 도메인 연결, 학생 대상 서비스, 데이터베이스 공개는 범위가 아닙니다. 교사가 원하면 2절의 이유를 먼저 설명하고, 학교 정보 담당자와 상의하도록 권합니다.
