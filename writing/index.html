영어 쓰기 수행평가 페이지

학생이 태블릿에서 영어 글쓰기 수행평가를 두 번에 나눠 치르는 웹 페이지입니다. 제출물은 선생님 구글 드라이브에 PDF와 시트로 쌓입니다. 실제 수업에 쓰던 것을 값을 비워 본보기로 만들었습니다.

체험해 보기 압축 파일 받기

구글 계정 · GitHub 계정 · Claude Code 필요 (설치할 때) · 97KB

어떻게 진행되나요

1회차예시 문단 분석 → 브레인스토밍(이때는 검색 허용) → 초안 쓰기(잠금) → 초안 제출
2회차같은 학번·이름으로 로그인하면 초안이 그대로 열리고(수정 불가), 최종본만 씁니다(잠금) → 제출
잠금 단계에서붙여넣기와 자동 완성이 막히고, 다른 앱·탭으로 나가면 횟수와 시각이 제출물에 기록됩니다. 단어 사전(단어 하나씩)만 허용됩니다.
선생님 쪽제출물은 반별 폴더에 PDF로, 진행 상황은 시트(총괄·반별 탭)와 교사 현황 화면에 보입니다.

체험해 보기

설치 없이 학생 흐름을 끝까지 해 볼 수 있습니다. 체험 페이지는 서버에 연결되어 있지 않아, 쓴 내용이 이 기기에만 남습니다.

  1. 체험 페이지를 엽니다. 제한 시간을 조사 2분, 초안 5분, 최종 5분으로 줄여 두었습니다.
  2. 아무 학번(예: 10101)과 이름으로 시작합니다.
  3. 조사 단계에서 초안 쓰기 시작을 누르고, 문장을 몇 개 쓴 뒤 제출합니다. 다른 탭으로 나갔다 오면 이탈이 기록되는 것도 볼 수 있습니다.
  4. 페이지를 새로 고치고 같은 학번·이름으로 다시 들어가면 2회차(최종본)가 열립니다.

처음부터 다시 하려면 로그인 화면 아래 교사 → PIN 0000 → 데이터 삭제. 체험 페이지에서는 사전, 교사 현황 화면, PDF 저장이 동작하지 않습니다.

설치 준비 ① GitHub 가입

GitHub는 코드를 올려 두는 곳입니다. 수행평가 페이지의 학생용 주소도 여기서 나옵니다. 무료입니다.

  1. 브라우저에서 github.com/signup을 엽니다.
  2. 네 가지를 넣고 Create account를 누릅니다.
    github.com/signup

    Sign up for GitHub

    1Email
    내 메일 주소
    2Password
    15자 이상, 또는 숫자와 소문자를 섞어 8자 이상
    3Username
    영문, 숫자, 하이픈(-)만
    4Your Country/Region
    South Korea
    Create account

    Username이 중요합니다. 학생 페이지 주소가 https://Username.github.io/… 가 됩니다. 학생에게 보여도 괜찮은 이름으로 정하세요. 이미 쓰는 사람이 있으면 빨간 글씨가 나오니 다른 이름을 넣습니다.

  3. 사람인지 확인하는 퍼즐이 나옵니다. 시키는 대로 그림을 고릅니다.
  4. 넣은 메일 주소로 숫자 코드가 옵니다. 메일함을 열어 그 숫자를 화면에 넣습니다. 메일이 안 보이면 스팸함을 봅니다.
    github.com/account_verifications

    Confirm your email address

    We have sent a code to 내 메일 주소

    Enter code
    1 2 3 4 5 6 7 8
    Continue
  5. 로그인 화면이 나오면 방금 만든 Username(또는 메일)과 비밀번호로 로그인합니다. 무엇을 할 건지 묻는 화면이 나오면 건너뛰어도 됩니다(Skip). 요금제를 묻는다면 Free를 고릅니다.
비밀번호는 꼭 적어 두세요. 뒤에서 Claude Code가 GitHub에 올릴 때 브라우저로 한 번 더 로그인합니다.

설치 준비 ② 나머지 도구: Claude Code에게 시키기

Git, Node.js, Python은 직접 받으러 다니지 않습니다. 방금 설치한 Claude Code에게 시킵니다.

  1. PowerShell에서 claude 를 켜고, 아래 말을 그대로 붙여넣습니다. 
    Git, Node.js LTS, Python 3이 이 PC에 깔려 있는지 확인하고, 없는 것만 설치해 줘.
설치가 끝나면 버전을 확인해서 알려 줘.
  2. Claude가 명령을 실행하기 전에 해도 되느냐고 묻습니다. 무엇을 하려는지 읽어 보고 1. Yes 에서 Enter를 누릅니다. 여러 번 묻습니다.
    Windows PowerShell — claude
    Bash command winget install --id Git.Git -e Git을 설치합니다 Do you want to proceed? ❯ 1. Yes 2. Yes, and don't ask again for winget install commands 3. No

    매번 묻는 것이 번거로우면 2번을 고릅니다. 같은 종류의 명령은 다시 묻지 않습니다.

  3. 설치 중에 화면이 어두워지며 아래 창이 뜰 수 있습니다. 예를 누릅니다. 도구마다 한 번씩 뜹니다.
    사용자 계정 컨트롤
    이 앱이 디바이스를 변경하도록 허용하시겠어요?

    Git for Windows · 확인된 게시자

    예아니요

    이 창이 작업 표시줄에서 깜빡이기만 하고 안 보일 때가 있습니다. 설치가 멈춘 것 같으면 작업 표시줄의 방패 모양 아이콘을 눌러 보세요.

  4. Claude가 "설치가 끝났습니다"와 함께 버전을 알려 주면, PowerShell 창을 닫고 새로 열어 아래를 한 줄씩 넣습니다. 네 줄 모두 숫자가 나오면 준비가 끝난 것입니다.
    Windows PowerShell
    PS C:\Users\내이름> git --version git version 2.47.0.windows.2 PS C:\Users\내이름> node -v v24.19.0 PS C:\Users\내이름> python --version Python 3.12.10 PS C:\Users\내이름> claude --version 2.x.x (Claude Code)

    숫자는 달라도 됩니다. "인식되지 않습니다"가 나오는 줄이 있으면, 그 줄을 그대로 Claude에게 붙여넣고 "이게 안 돼, 고쳐 줘"라고 하면 됩니다.

학교 PC에서는 막힐 수 있습니다. 보안 프로그램이나 관리자 설정 때문입니다. 그때는 아래에서 설치 파일을 받아 설치합니다. 옵션은 모두 기본값으로 두고 다음만 누르면 됩니다.
직접 받는 곳
  • Git: Windows는 git-scm.com, Mac은 터미널에서 git을 치면 설치 안내가 뜹니다.
  • Node.js LTS: nodejs.org
  • Python 3: python.org. Windows에서는 설치 첫 화면의 “Add python.exe to PATH”를 체크합니다.
Mac에서는 Claude가 Homebrew라는 도구로 설치합니다. Homebrew가 없으면 먼저 설치해도 되느냐고 묻고, 중간에 Mac 로그인 비밀번호를 묻습니다. 비밀번호를 칠 때는 화면에 아무것도 보이지 않는 것이 정상입니다.

내 수업에 쓰려면 (설치)

제출물을 받으려면 선생님의 구글 계정에 서버(Apps Script)를, GitHub에 학생 페이지를 올려야 합니다. 1시간쯤 걸리고, 대부분 Claude Code가 진행합니다.

설치와 수정은 Claude Code와 말로 진행합니다. 이 페이지가 어떤 구조인지(프론트엔드, 백엔드, 데이터, 배포)를 알고 말하면 훨씬 수월합니다. 틀과 물어볼 것은 발표 정리: 구조와 계획에 있습니다.

준비

  • 구글 계정, GitHub 계정 (위의 설치 준비 ①)
  • PC에 Claude Code와 VS Code, 본보기 폴더 (연수 전 준비와 실습에서 한 것)
  • Git, Node.js LTS, Python 3 (위의 설치 준비 ②)

순서

  1. 본보기 폴더를 VS Code로 엽니다. PowerShell에 code $HOME\Documents\english-writing 을 넣습니다.
  2. VS Code의 터미널(Ctrl+`)에서 claude를 실행합니다.
  3. 이렇게 말합니다: CLAUDE.md의 "처음 설치"를 진행해 줘.

Claude Code가 아래를 차례로 진행하고, 브라우저에서 눌러야 하는 것만 물어봅니다.

값 정하기token과 교사 PIN (받은 파일에는 CHANGE_ME, 0000으로 들어 있습니다)
서버 올리기clasp 설치, 구글 로그인, Apps Script 프로젝트 연결, 코드 올리기
권한 승인편집기에서 testSubmit을 한 번 실행합니다. 내 드라이브에 제출물 폴더와 시트가 만들어집니다.
웹 앱 배포나온 주소를 학생 페이지와 교사 화면에 넣습니다.
페이지 올리기GitHub 저장소를 만들고 Pages를 켭니다(/docs 폴더).
마무리교사 현황 화면 열쇠 만들기, 테스트, 첫 배포

설치 중에 만나는 것

  • 권한 승인 때 "확인되지 않은 앱" 경고가 뜨고, 드라이브·메일·외부 연결 권한을 한꺼번에 묻습니다. 본인 계정에 본인이 올린 스크립트라서 뜨는 것입니다.
  • 학교 구글 계정은 "모든 사용자"에게 웹 앱을 여는 것이 관리자 설정으로 막혀 있을 수 있습니다. 막히면 개인 계정을 쓰세요.
  • 이 설치 순서는 새 계정에서 처음부터 끝까지 돌려 보지는 못했습니다. 막히는 단계가 있으면 알려 주세요.

과제 내용 바꾸기

docs/index.html 맨 위의 CONFIG 한 곳만 고치면 됩니다. Claude Code에게 "예시 문단을 이걸로 바꿔 줘"처럼 말로 시켜도 됩니다.

title, subtitle과제 제목
assignmentId과제 이름표. 과제를 새로 낼 때마다 다른 값으로 바꿉니다. 안 바꾸면 같은 주소에서 지난 과제의 상태가 그대로 열립니다.
phases단계별 제한 시간(분)
requiredSentences 등필요한 문장 수, Word Bank 표현 수
example, step1Parts예시 문단과 구분 항목
step2Items, ideaBank브레인스토밍 항목과 참고 목록
step3Parts초안 구성과 문장 틀
wordBank표현과 자동 감지 규칙

들어 있는 예시 과제(제목, 예시 문단, Word Bank)는 본보기입니다. 본인 수업 내용으로 바꿔 쓰세요.

폴더 구성과 배포 규칙

english-writing/
├── docs/index.html     학생 페이지 (GitHub Pages가 이 폴더를 보여 줌)
├── docs/teacher.html   교사 현황 화면
├── gas/Code.gs         Apps Script 웹 앱 (저장, PDF, 시트, 사전)
├── tests/              자동 시험
├── scripts/deploy.sh   GitHub 올리기와 Apps Script 재배포를 한 번에
└── CLAUDE.md           Claude Code가 읽는 설명서와 규칙

배포 규칙

  • 배포는 선생님이 “배포해 줘”라고 말할 때만 Claude Code가 deploy.sh로 합니다.
  • 수업 전날까지 마치고, 태블릿으로 로그인 화면 아래 버전 글자를 확인합니다. 수업 당일 아침에는 배포하지 않습니다.
  • Apps Script 편집기에 코드를 직접 붙여넣지 않습니다. 폴더의 코드와 어긋납니다.
  • GitHub 저장소는 공개입니다. 학생 정보와 비밀값을 넣지 않습니다.

수업 운영

  • 학생은 주소(또는 QR)로 들어와 학번과 이름으로 로그인합니다. 글은 1분마다 서버에 자동 저장되어, 기기가 바뀌어도 이어집니다.
  • 수업 중에는 교사 현황 화면에서 반별로 누가 어느 단계인지, 이탈이 있었는지 봅니다.
  • 시간 추가, 잠금 해제, 제출 취소는 학생 화면 아래 교사 버튼(PIN)으로 합니다.
  • 코드를 고쳤으면 수업 전날 배포하고, 태블릿으로 로그인 화면 아래 버전 글자를 확인합니다. 당일 아침에는 배포하지 않습니다.
  • 문제가 보이면 제출명단 시트의 오류 탭을 먼저 봅니다.

알아 둘 것

  • 교사 PIN과 token은 페이지 소스에서 누구나 볼 수 있습니다. 실수 방지용일 뿐, 보안 장치가 아닙니다.
  • 제한 시간은 주소 뒤에 값을 붙이면 바뀝니다. 학생이 주소창을 쓰지 못하게 하려면 홈 화면 앱으로만 열게 하고(requireHomeScreen) 기기에서 앱 고정을 쓰세요.
  • 학번은 학년 1자리 + 반 2자리 + 번호 2자리(예: 10315)를 전제합니다. 반별 폴더와 탭이 이 규칙으로 나뉩니다.
  • 영어 글쓰기 전용입니다. 문장 수 세기, 한글 입력 감지, 사전이 모두 영어를 전제합니다.
  • 1인 1기기를 전제합니다. 공용 기기에서 학번을 잘못 넣으면 그 기기에 남아 있던 다른 학생의 글이 열릴 수 있습니다.
  • 학생 이름·학번·글이 선생님 구글 드라이브에 저장됩니다. 학교 개인정보 지침을 먼저 확인하세요.
