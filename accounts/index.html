계정 세 가지: GitHub · Apps Script · 구글 시트

학생이 여는 페이지(GitHub), 제출을 받는 프로그램(Apps Script), 제출이 쌓이는 표(구글 시트·드라이브)를 준비합니다. 10분이면 됩니다.

세 곳이 하는 일

실습의 마지막 단계에서 내 과목 평가 페이지를 실제 인터넷에 올리고, 제출이 내 시트에 쌓이게 합니다. 그때 아래 세 곳을 씁니다. 각각 웹 서비스의 네 층 가운데 하나를 맡습니다. 웹 채팅과 코딩 도구 두 갈래 모두 필요합니다.

서비스하는 일네 층영어 수행평가 페이지에서
GitHub코드를 올려 두는 곳. Pages를 켜면 그 파일에 누구나 여는 주소가 생김배포, 프론트엔드학생이 여는 페이지 주소 아이디.github.io/…
구글 Apps Script구글 계정 안에서 도는 작은 프로그램. 서버를 따로 빌리지 않음백엔드제출을 받아 확인하고, 시트에 쓰고, PDF를 만듦
구글 시트, 드라이브표와 파일을 두는 곳. 교사가 직접 열어 볼 수 있음데이터학생별 한 줄(시트), 반별 제출 PDF(드라이브)

모두 무료입니다. 실습 4단계에서 셋 모두에 직접 올려 봅니다.

1. 구글 계정 정하기

개인 구글 계정을 권합니다. 학교 계정은 관리자 설정 때문에 “모든 사용자”에게 웹 앱을 여는 것이 막혀 있을 수 있습니다. 그러면 학생이 제출할 수 없습니다.

2. 드라이브와 Apps Script 열어 보기

  1. drive.google.com 에 그 계정으로 들어가 내 드라이브가 열리는지 봅니다. 제출물 폴더와 시트가 나중에 여기에 생깁니다.
  2. script.google.com 에 들어가 왼쪽 위 새 프로젝트를 누릅니다. 코드 편집기가 열리면 됩니다. 만든 프로젝트는 지워도 됩니다.
    script.google.com

    제목 없는 프로젝트

    Code.gs
    function myFunction() { }
    ▷ 실행
  3. 코딩 도구로 본보기 전체를 올릴 때 필요: script.google.com/home/usersettings 에서 Google Apps Script API 를 사용으로 켭니다. Claude Code가 내 PC의 코드를 Apps Script로 올릴 때 필요합니다.
    script.google.com/home/usersettings

    설정

    Google Apps Script API
    사용 ●

3. GitHub 가입

GitHub는 코드를 올려 두는 곳이고, 학생용 페이지 주소도 여기서 나옵니다.

  1. 브라우저에서 github.com/signup을 엽니다.
  2. 네 가지를 넣고 Create account를 누릅니다.
    github.com/signup

    Sign up for GitHub

    1Email
    내 메일 주소
    2Password
    15자 이상, 또는 숫자와 소문자를 섞어 8자 이상
    3Username
    영문, 숫자, 하이픈(-)만
    4Your Country/Region
    South Korea
    Create account

    Username이 중요합니다. 학생 페이지 주소가 https://Username.github.io/… 가 됩니다. 학생에게 보여도 괜찮은 이름으로 정하세요. 이미 쓰는 사람이 있으면 빨간 글씨가 나오니 다른 이름을 넣습니다.

  3. 사람인지 확인하는 퍼즐이 나옵니다. 시키는 대로 그림을 고릅니다.
  4. 넣은 메일 주소로 숫자 코드가 옵니다. 메일함을 열어 그 숫자를 화면에 넣습니다. 메일이 안 보이면 스팸함을 봅니다.
    github.com/account_verifications

    Confirm your email address

    We have sent a code to 내 메일 주소

    Enter code
    1 2 3 4 5 6 7 8
    Continue
  5. 로그인 화면이 나오면 방금 만든 Username(또는 메일)과 비밀번호로 로그인합니다. 무엇을 할 건지 묻는 화면이 나오면 건너뛰어도 됩니다(Skip). 요금제를 묻는다면 Free를 고릅니다.
GitHub 비밀번호는 꼭 적어 두세요. 나중에 올릴 때 브라우저로 한 번 더 로그인합니다.
