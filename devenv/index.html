기본은 Claude 앱에서 하고, 내 PC의 파일이나 프로그램이 필요한 일만 내 PC에서 합니다. 코드를 오래 맡겨 둘 일은 클라우드 세션을 씁니다. 여기서 클라우드 세션은 Claude Code가 Anthropic 서버에서 도는 것을 말합니다(구글 드라이브가 아닙니다).

연수에서 다루지 않는 부분에는 구상 표시를 붙였습니다. 만든 사람이 앞으로 해 보려는 것이라, 참고로만 보세요.

비밀키저장소에 넣지 않습니다. coolwatch의 노션 키는 학교 PC의 환경변수에 둡니다. 수행평가 페이지의 token과 교사 PIN은 페이지 소스에 보이는 값이라 비밀이 아닙니다.

학생 정보를 구글 드라이브, 노션 같은 외부 서비스에 두기 전에는 학교 개인정보 지침을 먼저 확인하세요.

교사 업무를 작업대별로 모았습니다. 작업대를 골라 그곳에서 하는 일만 볼 수 있습니다.

연수에서 실제로 하는 것

준비물과 설치 확인은 연수 전 준비에 있습니다. 앞 단계만 해도 바로 쓸 수 있습니다.

  1. Claude 계정과 앱

    Pro 또는 Max 요금제로 로그인되는지 확인합니다. “수업자료”처럼 일의 종류별로 프로젝트를 만듭니다.

  2. coolwatch

    학교 PC에서 설치.bat을 한 번 실행하고 처음 설정을 마칩니다. Claude 요약과 노션 연결은 선택입니다. 설명서

  3. 수행평가 페이지 체험

    설치 없이 학생 흐름을 끝까지 해 봅니다. 수행평가 페이지 안내

  4. 직접 설치 (원하는 분)

    본보기 폴더를 VS Code로 열고 Claude Code에게 “CLAUDE.md의 처음 설치를 진행해 줘”라고 말합니다. 1시간쯤 걸립니다.

수행평가 본보기의 구조

english-writing/
├── docs/index.html     학생 페이지 (GitHub Pages가 이 폴더를 보여 줌)
├── docs/teacher.html   교사 현황 화면
├── gas/Code.gs         Apps Script 웹 앱 (저장, PDF, 시트, 사전)
├── tests/              지어낸 자료로 하는 자동 테스트
├── scripts/deploy.sh   GitHub 올리기와 Apps Script 재배포를 한 번에
└── CLAUDE.md           Claude Code가 읽는 설명서와 규칙

학생 페이지는 한 파일이고 외부 라이브러리를 쓰지 않습니다. 글만 받아 PDF와 시트로 저장합니다. 정해진 시각에 도는 작업은 없고, 현황은 학생이 쓰는 동안 저절로 갱신됩니다. 무료 GitHub 계정에서는 Pages를 켜려면 저장소가 공개여야 하므로, 이 저장소에는 학생 정보와 비밀키를 넣지 않습니다.

배포 규칙

배포는 선생님이 “배포해 줘”라고 말할 때만 Claude Code가 deploy.sh로 합니다. 수업 전날까지 마치고, 태블릿으로 로그인 화면 아래 버전 글자를 확인합니다. 수업 당일 아침에는 배포하지 않습니다. Apps Script 편집기에 코드를 직접 붙여넣지 않습니다(폴더의 코드와 어긋납니다).

읽기 차단 설정 (예시)

CLAUDE.md의 규칙은 부탁이고, 폴더의 .claude/settings.json은 Claude의 파일 읽기 도구를 막습니다. 완전한 잠금은 아니므로 실제 자료는 저장소에 넣지 않는 것이 먼저입니다.

{
  "permissions": {
    "deny": [
      "Read(./.env)",
      "Read(./data/real/**)",
      "Read(./**/credentials*.json)"
    ]
  }
}

하루의 흐름

구조도가 실제 일과에서 움직이는 순서입니다.

  1. 근무 중업무 메시지는 coolwatch가 카드로 정리합니다. 새 글이 오면 아이콘에 주황 점이 붙습니다. 노션 연결을 했다면 받은 업무함에도 올라가 폰에서 봅니다.
  2. 공강 시간앱에서 수업자료. 수업 내용을 주고 슬라이드와 학습지를 만듭니다.
  3. 수업 전날수행평가 페이지를 고쳤다면 이날 배포합니다. “테스트 돌리고 배포해 줘”라고 말하고, 태블릿으로 버전 글자를 확인합니다.
  4. 수업 중학생 글이 PDF와 시트로 쌓입니다. 교사 현황 화면에서 반별 진행과 이탈을 봅니다.
  5. 퇴근 전 구상범위가 분명한 코드 수정을 클라우드 세션에 맡깁니다. 다음 날 결과 브랜치로 PR을 만들어 읽고 병합합니다. PR은 자동으로 열리지 않습니다.

도구 목록

연수에서 쓰는 것과 나중에 넓혀 갈 것을 나누었습니다. 설치 명령은 연수 전 준비와 같습니다.

나중에 넓혀 갈 것 구상

아래는 연수에서 다루지 않습니다. 만든 사람이 앞으로 해 보려는 것이고, 끝까지 써 보지 않은 부분이 섞여 있습니다. 따라 하기 전에 작은 것으로 먼저 시험하세요.

클라우드 세션에 코드 맡기기

claude.ai/code에서 GitHub를 연결하면, 저장소의 코드를 Anthropic 서버에서 고치게 하고 결과를 브랜치로 받습니다. Pro·Max 같은 유료 요금제가 필요합니다.

정해진 시각에 시키기

노션·메일 정리는 앱의 예약 작업, 저장소 코드 작업은 Routines를 생각하고 있습니다. 둘 다 요금제와 시기에 따라 없을 수 있으니 미리 확인합니다.

노션 DB 늘리기

수업 설계, 수행평가 운영(학생 점수는 넣지 않음), 잘 통한 지시문 노트. 업무 목록은 받은 업무함의 ‘내 할 일’·캘린더 보기로 충분해 따로 옮기지 않습니다.

실제 명단을 다루는 스크립트

지어낸 명단으로 Claude와 스크립트를 완성하고, 실제 명단·나이스 엑셀·서술형 답안은 내 PC에서 선생님이 직접 실행합니다.

Mac 터미널 환경

tmux, uv, gh로 여러 작업을 터미널에서 돌립니다. 연수의 준비물(VS Code, pip)과는 다른 길입니다.

수업 안내 사이트

마크다운으로 쓴 안내와 루브릭을 MkDocs로 Pages 사이트로 만듭니다. 공개되므로 학생 정보는 올리지 않습니다.

구상 중인 작업 저장소 (비공개)

연수 본보기와는 다른 저장소입니다. 학생에게 보일 페이지는 공개 저장소에 따로 둡니다.

school-workshop/
├── CLAUDE.md                   학교 환경, 한국어, 데이터 규칙
├── .claude/
│   ├── settings.json           읽기 차단 규칙
│   ├── skills/                 루브릭, 수업 PPT, 공문 서식
│   └── agents/privacy-reviewer.md   부르면 개인정보를 점검
├── .mcp.json                   Playwright·Context7 (project 범위)
├── scripts/                    PPT 일괄 생성, 명단 처리, 집계
├── templates/                  학교 PPT 템플릿, HWPX 서식
├── fixtures/fake_students.csv  지어낸 명단
└── data/real/                  git에 올리지 않음, Claude 읽기 차단

coolwatch는 학교 PC 전용이라 따로 둡니다. 받은 압축 파일 안에 소스와 인수인계 문서(HANDOFF.md), 안전 규칙(CLAUDE.md)이 들어 있습니다.

용어

저장소코드 폴더와 그 변경 기록을 GitHub에 올려 둔 것.
브랜치 · PR · 병합브랜치는 원본을 건드리지 않고 고쳐 보는 갈래, PR은 “이 갈래를 원본에 합쳐 달라”는 요청, 병합은 실제로 합치는 일입니다.
배포고친 것을 학생이 쓰는 주소에 실제로 반영하는 일.
GitHub Pages저장소의 폴더를 웹 페이지로 보여 주는 GitHub 기능.
Apps Script 웹 앱구글 계정 안에서 도는 작은 프로그램. 학생 페이지가 보낸 글을 받아 드라이브와 시트에 저장합니다.
clasp내 PC의 Apps Script 코드를 구글에 올리는 도구. Claude Code가 대신 실행합니다.
커넥터 · MCPClaude가 노션·구글 드라이브 같은 바깥 서비스를 읽고 쓰게 잇는 연결. 앱에서는 커넥터, Claude Code에서는 MCP라고 부릅니다.
클라우드 세션Claude Code가 내 PC 대신 Anthropic 서버에서 도는 것. PC를 꺼도 계속됩니다.
Routines정해진 시각에 클라우드 세션을 자동으로 시작하는 기능.
tmux · uvtmux는 터미널 창을 여러 개로 나눠 켜 두는 도구, uv는 파이썬 라이브러리를 설치하는 도구입니다.

2026년 10월 8일 기준입니다. Claude 앱과 Claude Code의 기능, 설치 방법, 요금과 한도는 바뀔 수 있으니 공식 문서에서 다시 확인하세요. Claude 앱에서 링크로 공유하는 페이지는 교사와 동료용으로만 쓰고, 학생 제출 창구로는 쓰지 않습니다.
