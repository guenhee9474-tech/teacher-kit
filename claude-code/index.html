Claude Code 설치와 로그인

Claude 유료 구독(Pro 또는 Max)으로 쓰는 코딩 도구입니다. API 키는 필요 없습니다. 보통 10분이면 되고, 학교 망에서는 더 걸릴 수 있습니다.

한 번에 하기

익숙하다면 아래 둘이면 끝입니다. PowerShell에 한 덩어리씩 붙여넣고, 덩어리마다 창을 닫고 새로 엽니다. 처음이라면 아래 화면 순서를 따라 합니다.

# 1) 설치
irm https://claude.ai/install.ps1 | iex
# 2) 로그인: 아래를 넣고, 로그인 방법 1번을 고르고, 브라우저에서 승인
claude
Mac에서는

터미널(응용 프로그램 → 유틸리티 → 터미널)에 아래 줄을 넣습니다. 끝나면 터미널을 닫고 새로 연 뒤 claude --version 으로 숫자가 나오는지 봅니다. command not found: claude 가 나오면 설치 화면 끝에 나온 PATH 안내 줄을 그대로 넣고 터미널을 다시 엽니다.

curl -fsSL https://claude.ai/install.sh | bash

숫자가 나오면 claude 를 넣고 2. 구독 계정으로 로그인을 따라 합니다.

claude를 켜고 “안녕”이라고 쳤을 때 답이 오면 끝입니다. /exit 로 닫습니다.

학교 망에서는 설치가 막힐 수 있어 집에서 하는 것을 권합니다. 계속 안 되면 웹 채팅으로 먼저 해 봅니다.

1. 설치

명령 한 줄입니다. 관리자 권한이 필요 없습니다.

  1. PowerShell을 열고 아래 줄을 복사해 붙여넣은 뒤 Enter를 누릅니다. 
    irm https://claude.ai/install.ps1 | iex
    Windows PowerShell
    PS C:\Users\내이름> irm https://claude.ai/install.ps1 | iex Setting up Claude Code... ✔ Claude Code successfully installed! Version: 2.x.x Location: C:\Users\내이름\.local\bin\claude.exe PS C:\Users\내이름> ▌

    보통 1~3분, 망이 느리면 더 걸립니다. 내려받는 동안에는 아무것도 표시되지 않아 멈춘 것처럼 보이는 것이 정상입니다. 초록색 줄이 나오고 다시 PS …> 가 나오면 끝난 것입니다. 기다리는 동안 창 안을 마우스로 누르지 마세요(아래 “멈춘 것 같습니다” 2번).

    Mac은 터미널에 curl -fsSL https://claude.ai/install.sh | bash 를 넣습니다.
  2. PowerShell 창을 닫고 새로 엽니다. 그리고 아래를 넣습니다. 숫자가 나오면 설치가 된 것입니다. 
    claude --version
    Windows PowerShell
    PS C:\Users\내이름> claude --version 2.x.x (Claude Code)
"claude 용어가 … 인식되지 않습니다"라고 나옵니다

창을 새로 열지 않았거나, 설치 폴더가 PATH(명령을 찾는 목록)에 들어가지 않은 것입니다.

  1. PowerShell 창을 모두 닫고 새로 열어 다시 해 봅니다.
  2. 그래도 안 되면 설치할 때 화면에 … is not in your PATH. Run: 이라는 줄과 그 아래 명령이 나왔는지 봅니다. 나왔으면 그 명령을 복사해 넣습니다.
  3. 그 줄을 놓쳤으면 아래를 넣고, 창을 새로 엽니다. 
    [Environment]::SetEnvironmentVariable("Path", [Environment]::GetEnvironmentVariable("Path","User") + ";$env:USERPROFILE\.local\bin", "User")
설치 명령을 넣었는데 멈춘 것 같습니다

위에서부터 하나씩 확인합니다. 대부분 1~2번에서 풀립니다.

  1. 정말 멈췄는지 기다려 봅니다. 설치 명령은 프로그램을 내려받는 동안 진행 표시를 하지 않습니다. 파일이 커서 학교나 느린 망에서는 몇 분 걸립니다. 10분까지는 창을 그대로 둡니다. 10분이 넘으면 보통 오류 글자가 나옵니다.
  2. 창 제목 앞에 “선택”이 붙어 있는지 봅니다. 기다리는 동안 창 안을 마우스 왼쪽 단추로 누르면, Windows가 글자를 고르는 상태로 바꾸면서 실행을 일시정지합니다. 창 제목이 선택 Windows PowerShell처럼 바뀌어 있으면 이 경우입니다. 키보드의 Esc(또는 Enter)를 한 번 누르면 이어서 진행합니다. 붙여넣을 때는 오른쪽 단추만 쓰고, 그 뒤로는 창을 누르지 않습니다.
  3. 백신이 검사 중일 수 있습니다. 학교 PC의 백신(V3, 알약, Windows 보안 등)이 내려받은 파일을 검사하는 동안 멈춰 보입니다. 몇 분 더 기다립니다. The process cannot access the file … being used by another process 가 나오면 다른 PowerShell 창을 모두 닫고, 아래 두 줄을 넣어 처음부터 다시 합니다. 
    Remove-Item -Recurse -Force "$env:USERPROFILE\.claude\downloads"
irm https://claude.ai/install.ps1 | iex
  4. 망에서 막혔는지 확인합니다. 멈춘 창은 Ctrl+C로 끄고 닫은 뒤, 새 PowerShell 창에 아래를 넣습니다. 
    curl.exe -sI https://downloads.claude.ai/claude-code-releases/latest
    첫 줄이 HTTP/1.1 200 OK면 망은 괜찮습니다. 다른 숫자가 나오거나 한참 아무 답이 없으면 학교 망이 내려받기를 막은 것입니다. 휴대폰 핫스팟이나 집에서 설치 명령을 다시 넣습니다.
  5. “SSL/TLS 보안 채널을 만들 수 없습니다”(Could not create SSL/TLS secure channel)가 나오면, 오래된 PowerShell이 옛날 보안 방식을 쓰는 것입니다. 아래 줄을 먼저 넣고 같은 창에서 설치 명령을 다시 넣습니다. 
    [Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12
  6. 그래도 안 되면 다른 설치 방법을 씁니다. Windows에 들어 있는 winget으로 설치합니다. 
    winget install Anthropic.ClaudeCode
    이 방법은 저절로 업데이트되지 않으므로, 가끔 winget upgrade Anthropic.ClaudeCode 를 넣습니다.

어느 방법으로 설치했든 PowerShell 창을 닫고 새로 연 뒤 claude --version 으로 숫자가 나오는지 확인합니다. 설치 상태를 자세히 보려면 claude doctor 를 넣습니다.

빨간 글씨로 오류가 나오고 설치가 안 됩니다

학교 망이나 보안 프로그램이 내려받기를 막은 경우가 많습니다. 집이나 휴대폰 핫스팟에서 다시 해 보세요. irm 이라는 말을 모른다고 나오면 PowerShell이 아니라 명령 프롬프트(cmd)에 넣은 것입니다. PowerShell을 새로 열어 다시 넣거나, 명령 프롬프트 그대로 아래 줄을 넣습니다.

curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd

2. 구독 계정으로 로그인

Claude Code를 내 Claude 구독(Pro 또는 Max)에 잇는 단계입니다. API 키를 따로 발급받지 않습니다. 브라우저에서 한 번 승인하면 끝납니다.

  1. PowerShell에 claude 라고 넣고 Enter를 누릅니다. 처음이면 글자 색을 고르라고 합니다. 그냥 Enter를 누르면 됩니다.
    Windows PowerShell
    PS C:\Users\내이름> claude Welcome to Claude Code Let's get started. Choose the text style that looks best with your terminal ❯ 1. Dark mode ✔ 2. Light mode 3. Dark mode (colorblind-friendly) …

    ❯ 가 지금 고른 줄입니다. 위아래 화살표로 옮기고 Enter로 정합니다. 뒤의 화면도 모두 같은 방식입니다.

  2. 로그인 방법을 고릅니다. 맨 위의 1번 "Claude account with subscription" 입니다. 이미 1번에 ❯ 가 있으니 Enter를 누릅니다.
    Windows PowerShell
    Select login method: ❯ 1. Claude account with subscription · Pro, Max, Team, or Enterprise 2. Anthropic Console account · API usage billing 3. 3rd-party platform · …

    2번은 고르지 않습니다. 2번은 쓴 만큼 따로 돈이 나가는 방식입니다. 구독 중이면 1번이 맞습니다.

  3. 브라우저가 저절로 열립니다. claude.ai에 로그인되어 있지 않으면 먼저 로그인합니다. 그다음 승인 화면에서 승인(Authorize)을 누릅니다.
    claude.ai/oauth/authorize…

    Claude Code가 내 Claude 계정에 연결하려고 합니다

    내 구독으로 Claude Code를 쓸 수 있게 됩니다.

    1승인 (Authorize) 취소

    학교 계정과 개인 계정이 둘 다 있으면, 구독을 결제한 계정으로 로그인했는지 오른쪽 위에서 확인하세요.

  4. PowerShell로 돌아오면 Login successful. 이 보입니다. Enter를 누릅니다. 이어서 안내 글(Security notes)이 나오면 한 번 더 Enter를 누릅니다.
    Windows PowerShell
    Login successful. Press Enter to continue… Logged in as 내메일@example.com
  5. 마지막으로 이 폴더를 믿느냐고 묻습니다. 지금은 내 사용자 폴더에서 켰으니 Yes, I trust this folder 에서 Enter를 눌러도 됩니다. 나중에는 내가 만든 폴더나 이 사이트에서 받은 폴더에서만 Yes를 고릅니다.
    Windows PowerShell
    Quick safety check: Is this a project you created or one you trust? ❯ 1. Yes, I trust this folder 2. No, exit

    이 질문은 폴더마다 처음 한 번 나옵니다. 인터넷에서 받은 모르는 폴더라면 No를 고릅니다.

  6. 아래처럼 글을 넣는 칸이 나오면 준비가 끝난 것입니다. 한국어로 말을 걸면 됩니다. 끝낼 때는 /exit 을 넣거나 창을 닫습니다.
    Windows PowerShell
    > 안녕, 한국어로 대답해 줘 ? for shortcuts
브라우저가 열리지 않습니다

PowerShell 화면에 Browser didn't open? Use the url below to sign in 과 긴 주소가 나옵니다. 그 주소를 복사해 브라우저 주소창에 붙여넣습니다. 승인하면 브라우저에 코드가 나오는데, 그것을 복사해 PowerShell의 Paste code here if prompted > 뒤에 붙여넣고 Enter를 누릅니다.

2번(Console)으로 잘못 들어갔습니다 / 계정을 바꾸고 싶습니다

Claude Code 안에서 /logout 을 넣어 나간 뒤, /login 으로 다시 들어가 1번을 고릅니다.

"구독이 필요하다"는 말이 나옵니다

무료 계정으로 로그인한 것입니다. claude.ai에서 Pro나 Max를 결제한 계정인지 확인하고, 그 계정으로 다시 로그인합니다.
