실습: 영어 수행평가 페이지를 내 과목으로

영어 쓰기 수행평가 페이지를 본보기로, 학생이 되어 보고, AI와 뜯어보고, 마지막에 내 과목(지구과학, 일본어, 윤리…) 평가 페이지를 계획하고 만들어 봅니다.

연수에서 함께 합니다. 15분쯤 걸리고, 다 못 한 것은 연수 뒤에 이어서 합니다. 그림은 실제 화면을 본떠 그린 예시이고, 글자는 조금 다를 수 있습니다.

흐름

1. 보기 (2분)영어 수행평가 체험 페이지에서 학생이 되어 봅니다. 두 갈래 공통.
2. 뜯어보기 (5분)같은 페이지를 AI와 뜯어봅니다. A. 웹 채팅은 작게 새로 만들어 보고, B. Claude Code는 본보기 폴더를 열어 고쳐 봅니다.
3. 내 과목으로 (8분)그 틀로 내 과목 평가 페이지를 계획하고 만들어 봅니다. 두 갈래 공통. 가장 중요한 부분입니다.

1. 보기: 학생이 되어 보기

  1. 영어 수행평가 체험 페이지를 열고 아무 학번(예: 10101)과 이름으로 시작합니다. 조사 단계에서 초안 쓰기 시작을 누릅니다.
  2. 문장을 하나 써 보고, 다른 곳의 글을 붙여넣어 보고, 다른 탭에 다녀옵니다.
  3. 보면서 세 칸으로 나눠 메모합니다. 3단계에서 그대로 씁니다.
    내용제목, 예시문, Word Bank, 시간. 내 과목이면 무엇으로 바뀔까?
    흐름조사 → 초안 → 최종. 내 과목 평가도 이 순서가 맞을까?
    동작타이머, 붙여넣기 막기, 이탈 기록. 내 과목에도 필요할까, 더 필요한 것은?

체험 페이지는 서버 없이 이 기기에만 저장됩니다. 페이지 설명은 영어 쓰기 수행평가 페이지 카드에 있습니다.

2-A. 웹 채팅으로 뜯어보기

Gemini나 claude.ai 대화창에서 방금 본 영어 수행평가 학생 화면을 작게 다시 만들어 봅니다. 만들면서 이 페이지가 어떻게 짜여 있는지 알게 됩니다. 설치할 것은 없습니다.

  1. 대화창을 엽니다. 둘 가운데 하나를 고릅니다.
    Geminigemini.google.com 에 구글 계정으로 들어갑니다. 입력칸 아래의 Canvas 를 눌러 켭니다. 만든 화면이 오른쪽에 열립니다.
    Claudeclaude.ai 에 들어갑니다. 따로 켤 것은 없습니다. 화면을 만들어 달라고 하면 오른쪽에 열립니다.
    gemini.google.com
    > Gemini에게 물어보기 ＋ 도구 Canvas Deep Research

    배우는 것: 웹 채팅은 대화창 옆에 “미리보기 화면”이 있어서, 만든 웹 페이지를 그 자리에서 눌러 볼 수 있습니다. 학교 구글 계정에서 Gemini가 꺼져 있으면 개인 구글 계정이나 claude.ai를 씁니다.

  2. 계획부터 받습니다. 아래 말을 그대로 넣습니다. 
    영어 쓰기 수행평가를 학생 태블릿에서 치르는 페이지를 HTML 파일 하나로 만들고 싶어.
코드는 아직 쓰지 말고, 화면에 무엇이 있어야 하는지 정리해 줘.
다음 세 가지로 나눠서.
- 내용: 제목, Word Bank, 시간
- 흐름: 쓰기 → 제출
- 동작: 타이머, 붙여넣기 막기, 화면 이탈 기록

    배우는 것: 발표에서 본 “내용, 흐름, 동작”으로 나눠 물으면 답도 그렇게 나뉘어 옵니다. 빠진 것이 있으면 “○○도 넣어 줘”라고 이어서 말합니다.

  3. 만들게 합니다. 
    좋아. 이 계획대로 HTML 파일 하나로 만들어 줘.
- 제목은 My Dream School, Word Bank 단어 8개, 문장 칸 5개
- 남은 시간 20분 타이머
- 붙여넣기는 막고, 다른 탭에 다녀오면 이탈 횟수를 화면 윗줄에 보여 줘
- 제목, 단어, 시간은 코드 맨 위의 설정 한 곳에 모아 줘

    배우는 것: 오른쪽에 코드가 써지고 화면이 뜹니다. Gemini에서 코드만 보이면 오른쪽 위의 미리보기를 누릅니다. 설정을 한 곳에 모으게 하면 다음에 내용만 바꾸기 쉽습니다.

  4. 내 눈으로 확인합니다. 미리보기 화면에서 직접 해 봅니다.
    • 문장 칸에 영어 문장을 써 봅니다. 타이머가 줄어드는지 봅니다.
    • 다른 곳에서 글을 복사해 문장 칸에 붙여넣어 봅니다. 막히는지 봅니다.
    • 다른 탭에 갔다가 돌아옵니다. 윗줄의 이탈 횟수가 오르는지 봅니다.

    배우는 것: AI가 “만들었습니다”라고 해도 확인은 내가 합니다. 안 되는 것은 본 그대로 말합니다. 예: “붙여넣기가 그대로 들어가. 막아 줘.” 미리보기 창 안에서는 일부 동작이 실제와 다를 수 있습니다.

  5. 고치고, 되돌려 봅니다. 
    시간을 25분으로, 제목을 "Our School in 2035"로 바꿔 줘. 바꾼 곳만 먼저 짧게 알려 줘.
    마음에 안 들면 되돌립니다. 미리보기 위쪽의 이전 버전 단추를 쓰거나, “방금 바꾼 것을 되돌려 줘”라고 합니다.

    배우는 것: 웹 채팅은 고칠 때 파일 전체를 새로 쓰기도 합니다. 그래서 바꾸라고 하지 않은 곳이 바뀌지 않았는지 한 번 더 봅니다.

만든 화면을 내 PC에 파일로 남기려면

미리보기 위쪽의 내려받기(또는 공유 → 내보내기) 단추가 있으면 그것을 씁니다. 없으면 코드 창의 복사 단추로 코드를 복사해 메모장에 붙이고, 다른 이름으로 저장에서 파일 이름을 test.html, 인코딩을 UTF-8로 저장합니다. 저장한 파일을 두 번 누르면 브라우저로 열립니다.

웹 채팅에 넣은 내용은 그 회사의 서버로 갑니다. 실제 학생 이름이나 글은 넣지 않습니다. 지어낸 예시로 합니다.

2-B. Claude Code로 뜯어보기

방금 본 영어 수행평가 페이지의 본보기 폴더를 VS Code로 열고, 그 안에서 Claude Code를 켜서 묻고 고칩니다. 연수 전에 연수 전 준비의 B 갈래(VS Code와 Claude Code 설치, 로그인)를 해 온 분이 합니다. 터미널에서 claude 를 켜고 “안녕”이라고 쳤을 때 답이 오면 준비된 것입니다.

  1. 본보기 폴더를 받아 VS Code로 엽니다. PowerShell(Windows 키 → powershell)에 아래 네 줄을 한꺼번에 붙여넣습니다. 수행평가 페이지 본보기를 문서 폴더에 받아 풀고, VS Code로 엽니다. 
    cd $HOME\Documents
irm https://guenhee9474-tech.github.io/teacher-kit/downloads/english-writing-kit.zip -OutFile english-writing-kit.zip
Expand-Archive english-writing-kit.zip -DestinationPath . -Force
code english-writing

    VS Code가 열리며 작성자를 신뢰하느냐고 물으면 “예”를 누릅니다. 왼쪽에 docs, CLAUDE.md 같은 이름이 보이면 됩니다.

    Mac에서는 / code 를 모른다고 나오면

    Mac은 터미널에 아래를 넣습니다.

    cd ~/Documents
curl -L -O https://guenhee9474-tech.github.io/teacher-kit/downloads/english-writing-kit.zip
unzip -o english-writing-kit.zip
open -a "Visual Studio Code" english-writing

    Windows에서 code 를 모른다고 하면, VS Code를 직접 열고 파일 → 폴더 열기에서 문서 → english-writing 을 고릅니다.

  2. VS Code 안의 터미널에서 Claude Code를 켭니다. Ctrl+`(숫자 1 왼쪽의 키)를 눌러 아래쪽에 터미널을 열고, claude 를 넣습니다. 메뉴로는 터미널 → 새 터미널입니다.
    english-writing — Visual Studio Code
    탐색기▸ docs
    ▸ gas
    ▸ scripts
    ▸ tests
    CLAUDE.md
    README.md
    왼쪽에서 파일을 누르면 여기에 내용이 보입니다
    터미널 PS C:\Users\내이름\Documents\english-writing> claude Quick safety check: Is this a project you created or one you trust? ❯ 1. Yes, I trust this folder 2. No, exit

    배우는 것: Claude Code는 “지금 열린 폴더”를 봅니다. 터미널 앞머리에 english-writing 이 보이는지 확인하세요. 왼쪽은 파일 목록, 가운데는 파일 내용, 아래가 Claude Code입니다. 폴더를 믿느냐고 물으면 Yes에서 Enter를 누릅니다.

  3. 읽게 합니다. 아래 말을 그대로 넣습니다. 
    이 폴더가 무엇을 하는 프로젝트인지, CLAUDE.md를 읽고 세 줄로 알려 줘.
    VS Code 터미널 — claude
    > 이 폴더가 무엇을 하는 프로젝트인지, CLAUDE.md를 읽고 세 줄로 알려 줘. ● Read(CLAUDE.md) ⎿ Read 163 lines ● 영어 쓰기 수행평가를 학생 태블릿에서 치르는 웹앱입니다. …

    배우는 것: Claude는 폴더 안의 파일을 직접 읽고 답합니다. CLAUDE.md 는 Claude가 폴더를 열 때마다 읽는 설명서입니다. 파일을 읽는 것은 묻지 않고 합니다.

  4. 구조를 묻습니다. 발표에서 본 네 층을 이 폴더에서 찾아봅니다. 
    이 프로젝트의 프론트엔드, 백엔드, 데이터, 배포가 각각 어느 파일인지 표로 정리해 줘.
    학생이 초안 제출을 누르면 어떤 요청이 어디로 가고 무엇이 저장되는지 순서대로 설명해 줘.

    배우는 것: 코드를 직접 읽지 않아도, 구조를 가리키는 말로 물으면 됩니다. 모르는 낱말이 나오면 “그게 뭐야?”라고 이어서 묻습니다. 앞의 대화를 기억합니다.

  5. 고치기 전에, 지금 모습을 봅니다. Claude에게 열어 달라고 합니다. 
    docs/index.html을 브라우저로 열어 줘.
    Claude가 여는 명령을 실행해도 되느냐고 묻습니다. 1. Yes 에서 Enter를 누릅니다. 브라우저에 학생 페이지가 열리면 학번에 10101, 이름에 아무 이름이나 넣고 시작합니다.

    배우는 것: 파일 열기 같은 일도 말로 시킬 수 있습니다. 명령을 실행하기 전에는 무엇을 하려는지 보여 주고 묻습니다. 로그인 화면 아래에 “연습 모드”라고 나옵니다. 서버 없이 이 PC에만 저장됩니다. 과제 제목과 남은 시간을 눈여겨봐 두세요.

  6. 고치게 합니다. VS Code로 돌아와 아래 말을 넣습니다. 제목은 원하는 것으로 바꾸세요. 
    초안 쓰는 시간을 25분으로 바꾸고, 과제 제목을 "우리 학교에 필요한 것"으로 바꿔 줘.
    Claude가 고칠 곳을 찾아, 바뀔 부분을 보여 주고 해도 되느냐고 묻습니다. 빨간 줄이 지워질 것, 초록 줄이 새로 들어갈 것입니다. 읽어 보고 1. Yes 에서 Enter를 누릅니다.
    VS Code 터미널 — claude
    Edit file docs/index.html - phases: { research: 15, draft: 20, final: 20 }, + phases: { research: 15, draft: 25, final: 20 }, Do you want to make this edit to index.html? ❯ 1. Yes 2. Yes, allow all edits during this session 3. No, and tell Claude what to do differently (esc)

    배우는 것: 파일을 고치기 전에는 반드시 보여 주고 묻습니다. Yes를 누르면 왼쪽 파일 목록에서 index.html 의 색이 바뀝니다. 눌러 보면 바뀐 내용이 가운데에 보입니다. 마음에 안 들면 3번을 고르고 어떻게 다르게 할지 말하면 됩니다. 여러 군데를 고치면 여러 번 묻습니다.

  7. 내 눈으로 확인합니다. 브라우저로 가서 F5(새로고침)를 누릅니다. 제목이 바뀌었는지 봅니다. 시간은 다른 학번(예: 10102)으로 로그인해 초안 단계에 들어가 봅니다.

    배우는 것: Claude가 “했습니다”라고 해도 확인은 내가 합니다. 아까 쓰던 학번은 이미 시작한 시각이 이 PC에 남아 있어서, 새 학번으로 봐야 바뀐 시간이 보입니다. 발표에서 본 “상태는 기기에 남는다”가 이것입니다.

  8. 되돌려 봅니다. 
    방금 바꾼 두 가지를 원래대로 되돌려 줘.

    배우는 것: 잘못되면 말로 되돌릴 수 있습니다. 그래서 겁내지 않고 시켜 봐도 됩니다. 오래 작업할 때는 git이 이 역할을 더 확실히 합니다.

3. 내 과목 평가 페이지로

오늘 실습에서 가장 중요한 부분입니다. 영어 수행평가 페이지의 틀(단계, 시간, 잠금, 제출)을 빌려 내 과목 평가를 계획하고 만들어 봅니다. 1단계에서 적은 “내용, 흐름, 동작” 메모를 씁니다.

  1. 바꿀 것을 정합니다. 예시를 보고 내 과목 줄을 머릿속으로 채워 봅니다.
    과목평가 장면내용에서 바꿀 것흐름동작에서 따져 볼 것
    지구과학관측 자료를 읽고 해석 쓰기자료(표, 그래프 그림), 용어 목록자료 읽기 → 해석 초안 → 결론그림을 화면에 띄우기. 문장 수 대신 글자 수
    일본어짧은 일본어 작문예시문, 문형과 어휘 목록그대로 (조사 → 초안 → 최종)일본어 입력기로 써도 잠금이 오작동하지 않는지. 문장을 。로 세는지

    수학서술형 풀이 과정문제, 풀이 단계 틀이해 → 풀이 → 검토수식을 어떻게 입력할지 (칸 나누기, 사진)

말하는 요령 (두 갈래 공통)

  • 한국어로, 사람에게 부탁하듯 말합니다. 짧게 여러 번 나눠 말해도 됩니다.
  • 바라는 결과를 말합니다. “시간을 25분으로”처럼요. 어느 파일의 몇째 줄인지는 몰라도 됩니다.
  • 모르면 묻습니다. “방금 한 일을 쉽게 설명해 줘”, “이 화면에서 뭘 눌러야 해?”
  • 화면의 오류 글자는 그대로 복사해 붙여넣고 “이게 뭐야, 고쳐 줘”라고 합니다.
  • 대화가 길어져 엉키면 새 대화를 열고, 지금까지 정한 것을 짧게 다시 말해 줍니다.
