1. 보기: 학생이 되어 보기

이 단계 체크리스트 · 3분

본보기 페이지는 학생이 태블릿에서 영어 글쓰기를 두 번에 나눠 치르고, 제출물이 교사의 구글 드라이브에 PDF와 시트로 쌓이는 페이지입니다.

1회차예시 문단 분석 → 브레인스토밍(이때는 검색 허용) → 초안 쓰기(잠금) → 초안 제출
2회차같은 학번·이름으로 로그인하면 초안이 그대로 열리고(수정 불가), 최종본만 씁니다(잠금) → 제출
잠금 단계에서붙여넣기와 자동 완성이 막히고, 다른 앱·탭으로 나가면 횟수와 시각이 제출물에 기록됩니다. 단어 사전(단어 하나씩)만 허용됩니다.
선생님 쪽제출물은 반별 폴더에 PDF로, 진행 상황은 시트(총괄·반별 탭)와 교사 현황 화면에 보입니다.
  1. 체험 페이지를 열고 아무 학번(예: 10101)과 이름으로 시작합니다. 제한 시간을 조사 2분, 초안 5분, 최종 5분으로 줄여 두었습니다. 조사 단계에서 초안 쓰기 시작을 누릅니다.
  2. 문장을 하나 써 보고, 다른 곳의 글을 붙여넣어 보고, 다른 탭에 다녀옵니다.
  3. 보면서 세 칸으로 나눠 메모합니다. 3단계에서 그대로 씁니다.
    내용제목, 예시문, Word Bank, 시간. 내 과목이면 무엇으로 바뀔까?
    흐름조사 → 초안 → 최종. 내 과목 평가도 이 순서가 맞을까?
    동작타이머, 붙여넣기 막기, 이탈 기록. 내 과목에도 필요할까, 더 필요한 것은?
지금은 연습 모드입니다. 연수 날(10월 19일)에는 체험 페이지가 연수용 서버에 연결되어 교사 현황 화면과 사전을 함께 썼습니다. 그 연결은 연수가 끝나며 닫혔습니다. 이제 쓴 글은 이 기기에만 저장되고, 사전·교사 현황 화면·PDF 저장은 동작하지 않습니다. 이 기능들은 5단계에서 내 Apps Script를 연결하면 그대로 살아납니다.

로그인 화면 아래 버전 글자 옆에 “연습 모드”라고 나오면 정상입니다. 학번과 이름은 아무것이나 넣어도 됩니다. 같은 학번으로 새로 고쳐 들어가면 2회차(최종본)가 열립니다. 처음부터 다시 하려면 로그인 화면 아래 교사 → PIN 0000 → 데이터 삭제.

2-A. 웹 채팅으로 뜯어보기

A 갈래 체크리스트 · 4분

Gemini나 claude.ai 대화창에서 방금 본 영어 수행평가 학생 화면을 작게 다시 만들어 봅니다. 만들면서 이 페이지가 어떻게 짜여 있는지 알게 됩니다. 설치할 것은 없습니다.

  1. 대화창을 엽니다. 둘 가운데 하나를 고릅니다.
    Geminigemini.google.com 에 구글 계정으로 들어갑니다. 입력칸 아래의 Canvas 를 눌러 켭니다. 만든 화면이 오른쪽에 열립니다.
    Claudeclaude.ai 에 들어갑니다. 따로 켤 것은 없습니다. 화면을 만들어 달라고 하면 오른쪽에 열립니다.
    gemini.google.com
    > Gemini에게 물어보기 ＋ 도구 Canvas Deep Research
    배우는 것

    웹 채팅은 대화창 옆에 “미리보기 화면”이 있어서, 만든 웹 페이지를 그 자리에서 눌러 볼 수 있습니다. 학교 구글 계정에서 Gemini가 꺼져 있으면 개인 구글 계정이나 claude.ai를 씁니다.

  2. 계획부터 받습니다. 아래 말을 그대로 넣습니다. 
    영어 쓰기 수행평가를 학생 태블릿에서 치르는 페이지를 HTML 파일 하나로 만들고 싶어.
코드는 아직 쓰지 말고, 화면에 무엇이 있어야 하는지 정리해 줘.
다음 세 가지로 나눠서.
- 내용: 제목, Word Bank, 시간
- 흐름: 쓰기 → 제출
- 동작: 타이머, 붙여넣기 막기, 화면 이탈 기록
    배우는 것

    발표에서 본 “내용, 흐름, 동작”으로 나눠 물으면 답도 그렇게 나뉘어 옵니다. 빠진 것이 있으면 “○○도 넣어 줘”라고 이어서 말합니다.

  3. 만들게 합니다. 
    좋아. 이 계획대로 HTML 파일 하나로 만들어 줘.
- 제목은 My Dream School, Word Bank 단어 8개, 문장 칸 5개
- 남은 시간 20분 타이머
- 붙여넣기는 막고, 다른 탭에 다녀오면 이탈 횟수를 화면 윗줄에 보여 줘
- 제목, 단어, 시간은 코드 맨 위의 설정 한 곳에 모아 줘
    배우는 것

    오른쪽에 코드가 써지고 화면이 뜹니다. Gemini에서 코드만 보이면 오른쪽 위의 미리보기를 누릅니다. 설정을 한 곳에 모으게 하면 다음에 내용만 바꾸기 쉽습니다.

  4. 내 눈으로 확인합니다. 미리보기 화면에서 직접 해 봅니다.
    • 문장 칸에 영어 문장을 써 봅니다. 타이머가 줄어드는지 봅니다.
    • 다른 곳에서 글을 복사해 문장 칸에 붙여넣어 봅니다. 막히는지 봅니다.
    • 다른 탭에 갔다가 돌아옵니다. 윗줄의 이탈 횟수가 오르는지 봅니다.
    배우는 것

    AI가 “만들었습니다”라고 해도 확인은 내가 합니다. 안 되는 것은 본 그대로 말합니다. 예: “붙여넣기가 그대로 들어가. 막아 줘.” 미리보기 창 안에서는 일부 동작이 실제와 다를 수 있습니다.

  5. 고치고, 되돌려 봅니다. 
    시간을 25분으로, 제목을 "Our School in 2035"로 바꿔 줘. 바꾼 곳만 먼저 짧게 알려 줘.
    마음에 안 들면 되돌립니다. 미리보기 위쪽의 이전 버전 단추를 쓰거나, “방금 바꾼 것을 되돌려 줘”라고 합니다.
    배우는 것

    웹 채팅은 고칠 때 파일 전체를 새로 쓰기도 합니다. 그래서 바꾸라고 하지 않은 곳이 바뀌지 않았는지 한 번 더 봅니다.

만든 화면을 내 PC에 파일로 남기려면

미리보기 위쪽의 내려받기(또는 공유 → 내보내기) 단추가 있으면 그것을 씁니다. 없으면 코드 창의 복사 단추로 코드를 복사해 메모장에 붙이고, 다른 이름으로 저장에서 파일 이름을 test.html, 인코딩을 UTF-8로 저장합니다. 저장한 파일을 두 번 누르면 브라우저로 열립니다.

웹 채팅에 넣은 내용은 그 회사의 서버로 갑니다. 실제 학생 이름이나 글은 넣지 않습니다. 지어낸 예시로 합니다.

2-B. 코딩 도구로 뜯어보기

B 갈래 체크리스트 · 4분

방금 본 영어 수행평가 페이지의 본보기 폴더를 VS Code로 열고, 그 안에서 코딩 도구를 켜서 묻고 고칩니다. 코딩 도구 갈래의 준비(터미널, VS Code, 코딩 도구 설치)를 마친 뒤 합니다.

Claude CodeAntigravity CLI (Gemini 쪽)
켜는 명령claudeagy
폴더 설명서CLAUDE.md 를 스스로 읽음AGENTS.md 를 읽음. 본보기의 AGENTS.md 는 “CLAUDE.md를 읽어라”라는 안내
끝내기/exit/quit

아래 그림과 글은 Claude Code 화면입니다. Antigravity CLI는 화면 글자가 다르지만 순서와 넣을 말은 같습니다. claude 자리에 agy 를 넣으세요.

  1. 본보기 폴더를 받아 VS Code로 엽니다. PowerShell(Windows 키 → powershell)에 아래 네 줄을 한꺼번에 붙여넣습니다. 수행평가 페이지 본보기를 문서 폴더에 받아 풀고, VS Code로 엽니다. 
    cd $HOME\Documents
irm https://guenhee9474-tech.github.io/teacher-kit/downloads/english-writing-kit.zip -OutFile english-writing-kit.zip
Expand-Archive english-writing-kit.zip -DestinationPath . -Force
code english-writing

    VS Code가 열리며 작성자를 신뢰하느냐고 물으면 “예”를 누릅니다. 왼쪽에 docs, CLAUDE.md 같은 이름이 보이면 됩니다.

    Mac에서는 / code 를 모른다고 나오면

    Mac은 터미널에 아래를 넣습니다.

    cd ~/Documents
curl -L -O https://guenhee9474-tech.github.io/teacher-kit/downloads/english-writing-kit.zip
unzip -o english-writing-kit.zip
open -a "Visual Studio Code" english-writing

    Windows에서 code 를 모른다고 하면, VS Code를 직접 열고 파일 → 폴더 열기에서 문서 → english-writing 을 고릅니다.

  2. VS Code 안의 터미널에서 코딩 도구를 켭니다. Ctrl+`(숫자 1 왼쪽의 키)를 눌러 아래쪽에 터미널을 열고, claude(Antigravity CLI는 agy)를 넣습니다. 메뉴로는 터미널 → 새 터미널입니다.
    english-writing — Visual Studio Code

    README.md
    왼쪽에서 파일을 누르면 여기에 내용이 보입니다
    터미널 PS C:\Users\내이름\Documents\english-writing> claude Quick safety check: Is this a project you created or one you trust? ❯ 1. Yes, I trust this folder 2. No, exit
    배우는 것

    Claude Code는 “지금 열린 폴더”를 봅니다. 터미널 앞머리에 english-writing 이 보이는지 확인하세요. 왼쪽은 파일 목록, 가운데는 파일 내용, 아래가 Claude Code입니다. 폴더를 믿느냐고 물으면 Yes에서 Enter를 누릅니다. Antigravity CLI도 “Do you trust the contents of this project?”라고 묻습니다.

  3. 읽게 합니다. 아래 말을 그대로 넣습니다. 
    이 폴더가 무엇을 하는 프로젝트인지, CLAUDE.md를 읽고 세 줄로 알려 줘.
    VS Code 터미널 — claude
    > 이 폴더가 무엇을 하는 프로젝트인지, CLAUDE.md를 읽고 세 줄로 알려 줘. ● Read(CLAUDE.md) ⎿ Read 163 lines ● 영어 쓰기 수행평가를 학생 태블릿에서 치르는 웹앱입니다. …
    배우는 것

    Claude는 폴더 안의 파일을 직접 읽고 답합니다. CLAUDE.md 는 이 폴더의 설명서입니다. 파일을 읽는 것은 묻지 않고 합니다.

  4. 구조를 묻습니다. 발표에서 본 네 층을 이 폴더에서 찾아봅니다. 
    이 프로젝트의 프론트엔드, 백엔드, 데이터, 배포가 각각 어느 파일인지 표로 정리해 줘.
    학생이 초안 제출을 누르면 어떤 요청이 어디로 가고 무엇이 저장되는지 순서대로 설명해 줘.
    배우는 것

    코드를 직접 읽지 않아도, 구조를 가리키는 말로 물으면 됩니다. 모르는 낱말이 나오면 “그게 뭐야?”라고 이어서 묻습니다. 앞의 대화를 기억합니다.

  5. 고치기 전에, 지금 모습을 봅니다. Claude에게 열어 달라고 합니다. 
    docs/index.html을 브라우저로 열어 줘.
    Claude가 여는 명령을 실행해도 되느냐고 묻습니다. 1. Yes 에서 Enter를 누릅니다. 브라우저에 학생 페이지가 열리면 학번에 10101, 이름에 아무 이름이나 넣고 시작합니다.
    배우는 것

    파일 열기 같은 일도 말로 시킬 수 있습니다. 명령을 실행하기 전에는 무엇을 하려는지 보여 주고 묻습니다. 로그인 화면 아래에 “연습 모드”라고 나옵니다. 서버 없이 이 PC에만 저장됩니다. 과제 제목과 남은 시간을 눈여겨봐 두세요.

제출했는데 시트에 줄이 안 생깁니다
  • scriptUrl이 /exec 로 끝나는지 봅니다. /dev 로 끝나는 주소는 나만 쓸 수 있습니다.
  • 배포할 때 액세스를 모든 사용자로 했는지 봅니다. 학교 구글 계정은 이 항목이 없거나 막혀 있을 수 있습니다. 그러면 개인 계정으로 합니다.
  • Code.gs를 고쳤다면 배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포를 해야 새 코드가 돕니다. 저장만 하면 옛 코드가 돕니다.
  • Apps Script 편집기 왼쪽의 실행(시계 모양)에서 오류가 났는지 봅니다. 오류 글자를 AI에게 붙여넣습니다.

1~2분 더 기다렸다 새로 고칩니다. 파일 이름이 정확히 index.html 인지, Pages에서 Save를 눌렀는지 봅니다.

연습용입니다. 공개 저장소라 누구나 코드와 scriptUrl을 볼 수 있고, 그 주소로 누구나 시트에 줄을 보낼 수 있습니다(발표의 “어디를 믿을 것인가”). 실제 학생 정보는 넣지 않습니다. 끝나면 배포 → 배포 관리에서 그 배포를 보관(Archive)해 끕니다. 실제 평가에는 이런 빈틈을 막아 둔 본보기 폴더를 씁니다(5단계).

5. 실제 수업에 쓰기

4단계의 작은 판은 네 층이 이어지는 것을 보는 연습용입니다. 실제 평가에는 본보기 폴더 전체를 같은 세 곳에 올립니다. 작은 판에는 없고 본보기에는 있는 것:

  • 누가 보냈는지 확인: token과 기기 열쇠. 남이 대신 제출하거나 주소만 알고 줄을 보내는 것을 막습니다.
  • 잃지 않기: 1분마다 자동 저장, 기기가 바뀌어도 이어 쓰기, 1회차 초안과 2회차 최종본.
  • 교사 쪽: 반별 PDF 폴더, 교사 현황 화면, 시간 추가·잠금 해제·제출 취소 메뉴, 오류 기록 탭.

올리는 일에 쓰는 Git, Node.js, Python은 직접 받으러 다니지 않습니다. 코딩 도구에게 시킵니다.

  1. PowerShell에서 claude(또는 agy)를 켜고, 아래 말을 그대로 붙여넣습니다.

설치: 코딩 도구와 함께 (1시간쯤)

본보기 폴더(영어 그대로든, 내 과목으로 고친 것이든)를 위 표의 세 곳에 올립니다. 대부분 코딩 도구가 진행하고, 브라우저에서 눌러야 하는 것만 묻습니다.

위의 기능을 하나씩 대화창에서 더하면 파일이 여럿으로 늘고, 고칠 때마다 복사해 옮겨야 합니다. 이때부터는 본보기 폴더를 코딩 도구로 내 과목에 맞게 고치는 편이 빠릅니다(2-B, 3단계의 B 갈래).

  • 배포는 선생님이 “배포해 줘”라고 말할 때만 코딩 도구가 deploy.sh로 합니다.
  • 수업 전날까지 마치고, 태블릿으로 로그인 화면 아래 버전 글자를 확인합니다. 수업 당일 아침에는 배포하지 않습니다.
  • Apps Script 편집기에 코드를 직접 붙여넣지 않습니다. 폴더의 코드와 어긋납니다.
  • GitHub 저장소는 공개입니다. 학생 정보와 비밀값을 넣지 않습니다.

다른 과목으로 바꿀 때

틀(단계, 시간, 잠금, 제출)은 그대로 쓰고 CONFIG 의 내용을 바꿉니다. 다만 아래는 영어 과제에 맞춘 곳이라 과목에 따라 끄거나 고칩니다. 문장 세기와 한글 입력 감지는 설정이 아니라 코드라서, 코딩 도구에게 “내 과목에 맞게 고쳐 줘”라고 시킵니다.

lock.blockHangulSelection영어 칸에서 한글을 고르면 선택을 풀고 기록합니다(번역 메뉴 차단용). 한글이나 일본어로 쓰는 과목은 false 로 끕니다.

requiredSentences필요 문장 수입니다. 과목의 글 길이에 맞춥니다.
문장 세기, 한글 입력 감지영어 마침표와 알파벳을 전제한 코드입니다. 일본어(。), 한글 글쓰기 과목은 고쳐야 합니다.

수업 운영

  • 학생은 주소(또는 QR)로 들어와 학번과 이름으로 로그인합니다. 글은 1분마다 서버에 자동 저장되어, 기기가 바뀌어도 이어집니다.
  • 수업 중에는 교사 현황 화면에서 반별로 누가 어느 단계인지, 이탈이 있었는지 봅니다.
  • 시간 추가, 잠금 해제, 제출 취소는 학생 화면 아래 교사 버튼(PIN)으로 합니다.
  • 코드를 고쳤으면 수업 전날 배포하고, 태블릿으로 로그인 화면 아래 버전 글자를 확인합니다. 당일 아침에는 배포하지 않습니다.
  • 문제가 보이면 제출명단 시트의 오류 탭을 먼저 봅니다.

알아 둘 것

  • 교사 PIN과 token은 페이지 소스에서 누구나 볼 수 있습니다. 실수 방지용일 뿐, 보안 장치가 아닙니다.
  • 제한 시간은 주소 뒤에 값을 붙이면 바뀝니다. 학생이 주소창을 쓰지 못하게 하려면 홈 화면 앱으로만 열게 하고(requireHomeScreen) 기기에서 앱 고정을 쓰세요.
  • 학번은 학년 1자리 + 반 2자리 + 번호 2자리(예: 10315)를 전제합니다. 반별 폴더와 탭이 이 규칙으로 나뉩니다.
  • 본보기는 영어 글쓰기용입니다. 문장 수 세기, 한글 입력 감지, 사전이 영어를 전제합니다. 다른 과목은 다른 과목으로 바꿀 때를 봅니다.
  • 1인 1기기를 전제합니다. 공용 기기에서 학번을 잘못 넣으면 그 기기에 남아 있던 다른 학생의 글이 열릴 수 있습니다.
  • 학생 이름·학번·글이 선생님 구글 드라이브에 저장됩니다. 학교 개인정보 지침을 먼저 확인하세요.

요령

말하는 요령 (두 갈래 공통)

  • 한국어로, 사람에게 부탁하듯 말합니다. 짧게 여러 번 나눠 말해도 됩니다.
  • 바라는 결과를 말합니다. “시간을 25분으로”처럼요. 어느 파일의 몇째 줄인지는 몰라도 됩니다.
  • 모르면 묻습니다. “방금 한 일을 쉽게 설명해 줘”, “이 화면에서 뭘 눌러야 해?”

  • 대화가 길어져 엉키면 새 대화를 열고, 지금까지 정한 것을 짧게 다시 말해 줍니다.
