준비실습내 것 계획자주 쓰는 것

실습: 수행평가 페이지로 Claude Code 첫걸음

수행평가 페이지 본보기 폴더를 VS Code로 열고 그 안에서 Claude Code를 켜서, 묻고, 고치고, 확인하고, 내 것을 계획해 봅니다. Claude Code를 처음 쓰는 분을 위한 순서입니다.

연수에서 함께 합니다. 20분쯤 걸립니다. 그림은 실제 화면을 본떠 그린 예시이고, 글자는 조금 다를 수 있습니다.

준비 확인

연수 전에 해 온 두 가지입니다. 안 되어 있으면 연수 전 준비를 먼저 합니다.

VS Code설치되어 있습니다.
Claude Code터미널에서 claude 를 켜고 “안녕”이라고 쳤을 때 답이 옵니다.
준비가 안 된 분은 옆 사람 화면을 같이 보다가, 마지막 내 것 계획만 브라우저의 claude.ai에서 같이 합니다.

실습

  1. 본보기 폴더를 받아 VS Code로 엽니다. PowerShell(Windows 키 → powershell)에 아래 네 줄을 한꺼번에 붙여넣습니다. 수행평가 페이지 본보기를 문서 폴더에 받아 풀고, VS Code로 엽니다. 
    cd $HOME\Documents
irm https://guenhee9474-tech.github.io/teacher-kit/downloads/english-writing-kit.zip -OutFile english-writing-kit.zip
Expand-Archive english-writing-kit.zip -DestinationPath . -Force
code english-writing

    VS Code가 열리며 작성자를 신뢰하느냐고 물으면 “예”를 누릅니다. 왼쪽에 docs, CLAUDE.md 같은 이름이 보이면 됩니다.

    Mac에서는 / code 를 모른다고 나오면

    Mac은 터미널에 아래를 넣습니다.

    cd ~/Documents
curl -L -O https://guenhee9474-tech.github.io/teacher-kit/downloads/english-writing-kit.zip
unzip -o english-writing-kit.zip
open -a "Visual Studio Code" english-writing

    Windows에서 code 를 모른다고 하면, VS Code를 직접 열고 파일 → 폴더 열기에서 문서 → english-writing 을 고릅니다.

  2. VS Code 안의 터미널에서 Claude Code를 켭니다. Ctrl+`(숫자 1 왼쪽의 키)를 눌러 아래쪽에 터미널을 열고, claude 를 넣습니다. 메뉴로는 터미널 → 새 터미널입니다.
    english-writing — Visual Studio Code
    탐색기▸ docs
    ▸ gas
    ▸ scripts
    ▸ tests
    CLAUDE.md
    README.md
    왼쪽에서 파일을 누르면 여기에 내용이 보입니다
    터미널 PS C:\Users\내이름\Documents\english-writing> claude Quick safety check: Is this a project you created or one you trust? ❯ 1. Yes, I trust this folder 2. No, exit

    배우는 것: Claude Code는 “지금 열린 폴더”를 봅니다. 터미널 앞머리에 english-writing 이 보이는지 확인하세요. 왼쪽은 파일 목록, 가운데는 파일 내용, 아래가 Claude Code입니다. 폴더를 믿느냐고 물으면 Yes에서 Enter를 누릅니다.

  3. 읽게 합니다. 아래 말을 그대로 넣습니다. 
    이 폴더가 무엇을 하는 프로젝트인지, CLAUDE.md를 읽고 세 줄로 알려 줘.
    VS Code 터미널 — claude
    > 이 폴더가 무엇을 하는 프로젝트인지, CLAUDE.md를 읽고 세 줄로 알려 줘. ● Read(CLAUDE.md) ⎿ Read 163 lines ● 영어 쓰기 수행평가를 학생 태블릿에서 치르는 웹앱입니다. …

    배우는 것: Claude는 폴더 안의 파일을 직접 읽고 답합니다. CLAUDE.md 는 Claude가 폴더를 열 때마다 읽는 설명서입니다. 파일을 읽는 것은 묻지 않고 합니다.

  4. 구조를 묻습니다. 발표에서 본 네 층을 이 폴더에서 찾아봅니다. 
    이 프로젝트의 프론트엔드, 백엔드, 데이터, 배포가 각각 어느 파일인지 표로 정리해 줘.
    학생이 초안 제출을 누르면 어떤 요청이 어디로 가고 무엇이 저장되는지 순서대로 설명해 줘.

    배우는 것: 코드를 직접 읽지 않아도, 구조를 가리키는 말로 물으면 됩니다. 모르는 낱말이 나오면 “그게 뭐야?”라고 이어서 묻습니다. 앞의 대화를 기억합니다.

  5. 고치기 전에, 지금 모습을 봅니다. Claude에게 열어 달라고 합니다. 
    docs/index.html을 브라우저로 열어 줘.
    Claude가 여는 명령을 실행해도 되느냐고 묻습니다. 1. Yes 에서 Enter를 누릅니다. 브라우저에 학생 페이지가 열리면 학번에 10101, 이름에 아무 이름이나 넣고 시작합니다.

    배우는 것: 파일 열기 같은 일도 말로 시킬 수 있습니다. 명령을 실행하기 전에는 무엇을 하려는지 보여 주고 묻습니다. 로그인 화면 아래에 “연습 모드”라고 나옵니다. 서버 없이 이 PC에만 저장됩니다. 과제 제목과 남은 시간을 눈여겨봐 두세요.

  6. 고치게 합니다. VS Code로 돌아와 아래 말을 넣습니다. 제목은 원하는 것으로 바꾸세요. 
    초안 쓰는 시간을 25분으로 바꾸고, 과제 제목을 "우리 학교에 필요한 것"으로 바꿔 줘.
    Claude가 고칠 곳을 찾아, 바뀔 부분을 보여 주고 해도 되느냐고 묻습니다. 빨간 줄이 지워질 것, 초록 줄이 새로 들어갈 것입니다. 읽어 보고 1. Yes 에서 Enter를 누릅니다.
    VS Code 터미널 — claude
    Edit file docs/index.html - phases: { research: 15, draft: 20, final: 20 }, + phases: { research: 15, draft: 25, final: 20 }, Do you want to make this edit to index.html? ❯ 1. Yes 2. Yes, allow all edits during this session 3. No, and tell Claude what to do differently (esc)

    배우는 것: 파일을 고치기 전에는 반드시 보여 주고 묻습니다. Yes를 누르면 왼쪽 파일 목록에서 index.html 의 색이 바뀝니다. 눌러 보면 바뀐 내용이 가운데에 보입니다. 마음에 안 들면 3번을 고르고 어떻게 다르게 할지 말하면 됩니다. 여러 군데를 고치면 여러 번 묻습니다.

  7. 내 눈으로 확인합니다. 브라우저로 가서 F5(새로고침)를 누릅니다. 제목이 바뀌었는지 봅니다. 시간은 다른 학번(예: 10102)으로 로그인해 초안 단계에 들어가 봅니다.

    배우는 것: Claude가 “했습니다”라고 해도 확인은 내가 합니다. 아까 쓰던 학번은 이미 시작한 시각이 이 PC에 남아 있어서, 새 학번으로 봐야 바뀐 시간이 보입니다. 발표에서 본 “상태는 기기에 남는다”가 이것입니다.

  8. 되돌려 봅니다. 
    방금 바꾼 두 가지를 원래대로 되돌려 줘.

    배우는 것: 잘못되면 말로 되돌릴 수 있습니다. 그래서 겁내지 않고 시켜 봐도 됩니다. 오래 작업할 때는 git이 이 역할을 더 확실히 합니다.

내 것 계획하기

오늘 실습에서 가장 중요한 부분입니다. 내 수업에 쓰고 싶은 것을 하나 정해, 만들기 전에 계획부터 세워 봅니다. 코드는 쓰지 않습니다.

  1. 무엇을 만들고 싶은지 한 문장으로 정합니다. 예: 수학 서술형 풀이를 단계별로 받는 페이지, 독서 기록을 모으는 페이지, 실험 보고서 제출 페이지.
  2. 아래 말에서 ○○ 와 조건을 내 것으로 바꿔 넣습니다. 
    내 수업에 쓸 ○○를 만들고 싶어. 조건은 이래.
- 쓰는 사람: 우리 반 학생 30명, 태블릿으로
- 관리: 나 혼자, 무료로, 구글 계정 하나로
- 학생은 로그인 없이 학번과 이름만

코드는 아직 쓰지 말고, 프론트엔드·백엔드·데이터·배포를 각각 무엇으로 할지
선택지와 장단점을 표로 줘. 정해야 할 것은 나에게 하나씩 물어봐.
  3. Claude가 되묻는 질문에 답합니다. 이어서 이것도 물어봅니다. 
    학생 이름과 글은 어디에 저장되고, 어디로 나가? 내가 조심해야 할 것은?
    다 만들었다는 걸 무엇으로 확인하지? 고친 뒤에 멀쩡한지는 어떻게 시험해?
  4. 나온 계획을 옆 사람과 서로 보여 줍니다. 네 층이 각각 무엇으로 채워졌는지 말해 봅니다.
계획만 세우게 하는 방법이 하나 더 있습니다. 터미널에서 Shift+Tab 을 눌러 아래쪽에 plan mode on 이 보이게 하면, Claude는 파일을 고치지 않고 계획만 세웁니다. 다시 누르면 풀립니다.
Claude Code가 준비되지 않은 분은 브라우저의 claude.ai에 같은 말을 넣으면 됩니다.

자주 쓰는 것

Enter말을 보냅니다. 고르는 화면에서는 지금 줄로 정합니다.
↑ ↓고르는 화면에서 줄을 옮깁니다. 글 넣는 칸에서는 앞에 넣었던 말을 다시 불러옵니다.
EscClaude가 하던 일을 멈춥니다. 잘못 시켰을 때 누릅니다.
Shift+Tab방식을 바꿉니다. plan mode on 은 계획만, accept edits on 은 묻지 않고 고칩니다. 처음에는 기본 상태로 두세요.
/clear대화를 비우고 새로 시작합니다. 다른 일을 시작할 때 씁니다.
/exit끝냅니다. 창을 닫아도 됩니다.

VS Code에서 막힐 때

메뉴가 영어입니다. 한국어로 바꾸고 싶습니다

왼쪽 세로 줄에서 네모 네 개 모양(Extensions)을 누르고 Korean 을 검색해 "Korean Language Pack for Visual Studio Code"를 설치합니다. 오른쪽 아래에 뜨는 다시 시작 단추를 누릅니다. Claude에게 "VS Code를 한국어로 바꿔 줘"라고 해도 됩니다.

VS Code 터미널에서 claude 가 인식되지 않는다고 나옵니다

VS Code를 완전히 닫았다가 다시 엽니다. 도구를 설치하기 전부터 열려 있던 창은 새로 깔린 것을 모릅니다.

말하는 요령

  • 한국어로, 사람에게 부탁하듯 말합니다. 짧게 여러 번 나눠 말해도 됩니다.
  • 바라는 결과를 말합니다. “시간을 25분으로”처럼요. 어느 파일의 몇째 줄인지는 몰라도 됩니다.
  • 모르면 묻습니다. “방금 한 일을 쉽게 설명해 줘”, “이 화면에서 뭘 눌러야 해?”
  • 화면의 오류 글자는 그대로 복사해 붙여넣고 “이게 뭐야, 고쳐 줘”라고 합니다.
