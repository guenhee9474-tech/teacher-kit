Antigravity CLI 설치와 로그인

Gemini를 만든 Google의 코딩 도구입니다. 개인 구글 계정으로 로그인하며, 무료 계정은 주간 한도 안에서, Google AI Pro는 넉넉히 씁니다.

예전의 Gemini CLI(gemini 명령)는 2026년 6월 18일부터 무료와 Google AI Pro 계정에서 멈추고 Antigravity CLI로 옮겨 갔습니다. 새로 설치한다면 Antigravity CLI를 씁니다.

설치와 로그인

Claude Code와 같은 일을 하고, 개인 구글 계정으로 로그인합니다. Claude Code를 설치했다면 이 페이지는 건너뜁니다.

  1. PowerShell에 아래 줄을 붙여넣고 Enter를 누릅니다. 관리자 권한은 필요 없습니다. 
    irm https://antigravity.google/cli/install.ps1 | iex

    Mac은 터미널에 curl -fsSL https://antigravity.google/cli/install.sh | bash 를 넣습니다.

  2. PowerShell 창을 닫고 새로 엽니다. 아래를 넣어 숫자가 나오면 설치된 것입니다. 
    agy --version
  3. agy 를 넣습니다. 처음이면 로그인 방법을 묻습니다. 1. Google OAuth 를 고릅니다.
    Windows PowerShell — agy
    PS C:\Users\내이름> agy Welcome to the Antigravity CLI. You are currently not signed in. ❯ 1. Google OAuth 2. Use a Google Cloud project
  4. 브라우저가 열리면 개인 구글 계정으로 로그인합니다. 브라우저에 코드가 나오면 복사해 PowerShell에 붙여넣고 Enter를 누릅니다. 이어서 글자 색을 고르고 이용 약관에 동의합니다.
  5. 폴더를 믿느냐고 물으면 Yes, I trust this folder 에서 Enter를 누릅니다. 지금은 내 사용자 폴더에서 켰으니 Yes를 골라도 됩니다. 나중에는 내가 만든 폴더나 믿을 수 있는 곳에서 받은 폴더에서만 Yes를 고릅니다. 글을 넣는 칸이 나오면 준비가 끝난 것입니다. 끝낼 때는 /quit 를 넣습니다.
    Windows PowerShell — agy
    Do you trust the contents of this project? ❯ Yes, I trust this folder No, exit
설치 명령과 설치 폴더는 Google의 설치 스크립트로 확인했습니다. 화면 그림은 안내 문서를 보고 그린 것이라 글자가 조금 다를 수 있습니다. 학교 구글 계정(Workspace)은 관리자 설정으로 막혀 있을 수 있으니 개인 계정을 씁니다.
"agy 용어가 … 인식되지 않습니다"라고 나옵니다

창을 새로 열었는지 먼저 봅니다. 그래도 안 되면 설치 폴더 C:\Users\내이름\AppData\Local\agy\bin 이 PATH에 들어갔는지 확인해야 합니다. 화면의 오류 글자를 웹 채팅(Gemini나 claude.ai)에 붙여넣고 물어보세요.
